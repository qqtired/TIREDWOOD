встроенный инструмент `image_gen` с прозрачным фоном, один вызов на картинку, без правок руками. Обёртка вызова —
«Use your built-in image generation tool to generate the following image on a genuinely transparent background
(transparent_background true). Do not write code to draw it and do not edit any other files. <промпт> Then save the
generated image as <id>.png in the current working directory.» Стиль промптов — как у рыб и удочек: реалистичная
рисованная иллюстрация справочника, мягкий дневной свет, без текста, рамок и свечения.

WebP — как у прежних вещей лавки и рыб: проверка, что фон прозрачный (углы прозрачные, доля прозрачного 67–87 %),
обрезка по содержимому с полями, уменьшение до 192 px по высоте (вещи) или 320 px по ширине (кальмар), WebP с альфой
(headless Chrome, canvas `toBlob('image/webp')`). Каждую картинку посмотрели глазами: один предмет целиком, без текста,
в стиле соседних.
