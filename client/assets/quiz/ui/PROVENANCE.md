# Значки «Ракушки» в игре: тепло, мимо, угадал

Файлы `q-warm.png`, `q-miss.png`, `q-win.png` — копии без изменений из `lab/quiz/v2/img/`. Там же лежит полная запись
источника с промптами и номерами потоков: `lab/quiz/v2/img/PROVENANCE.md`.

Коротко: нарисованы 30.10.2026 через Codex CLI 0.162.1 (`codex exec -m gpt-6-astra`, встроенный `image_gen`, прозрачный
фон), одна картинка на вызов, без рисования кодом и правок руками; оригиналы 1254×1254 уменьшены до 256×256 PNG
(`sips -Z 256`). Общий стиль и обёртка — те же, что у иконок набора (`client/assets/ui/icons/PROVENANCE.md`).

- `q-warm.png` — мятная рукавичка с поднятым большим пальцем («тепло»);
- `q-miss.png` — коралловая рукавичка с опущенным большим пальцем («мимо»);
- `q-win.png` — мишень со стрелой в центре («угадал»).

Перед релизом их можно сжать в WebP 256×256 тем же `post.mjs`, что иконки набора (замер покажет, нужно ли).

Значки режимов («Загадка» — `scroll`, «Своя игра» — `bell`, «Крокодил» — `paint`, «Кто из нас?» — `online`, ничья —
`roulette`) — готовые иконки набора из `client/assets/ui/icons/`, новых картинок нет.
