# Правила для помощника (Астра) — TIREDWOOD

Ты дорабатываешь **TIREDWOOD** (https://game.tired.solutions; раньше называлась Game Opus — так по-прежнему называются папка,
пакет и служба `game-opus`, их не переименовывай) — игру для компании друзей владельца: 3D-набережная с желейками,
кафе с дураком и Blackjack, рыбалка, мини-режимы (пейнтбол, картинг, катера, «Выше облаков», прятки, крепость, Fight Club),
события шторма и пиратов, жетоны и уровни, общий чат и голос на V.
Папка: `/Users/tired/Desktop/tired.solutions/game-opus`. Это git-репозиторий https://github.com/qqtired/TIREDWOOD
(публичный): `data/`, токены и ключи не коммить; участники работают через ветки и Pull Request — [CONTRIBUTING.md](CONTRIBUTING.md). Стек: Node 24 (TypeScript без сборки на сервере), three.js, ws, Vite.

Сначала прочитай `README.md` (режимы, команды, флаги, раздел «Состояние»: что на сайте и что ещё нет), `docs/STATUS.md`
(что делать дальше) и `docs/design.md` (как сделано). Похожий готовый режим — лучший образец: Fight Club
(`shared/fight*.ts`, `server/fight/`, `client/fight/`), прятки (`shared/hide*.ts`, `server/hide/`, `client/hide/`) или картинг
(`client/race/`, `server/race/`).

## Как работать

- С владельцем говори **по-русски и просто**. Решения принимает он, код пишешь ты.
- **Одна задача — один план.** Перед кодом запиши короткий план в `docs/superpowers/plans/<дата>-<тема>.md` с
  галочками и разделом «Статус / что осталось» вверху. Обновляй его после каждого шага, чтобы работу мог продолжить
  другой помощник.
- **Новое — за флагом сервера, по умолчанию выключено.** Пример — `FIGHT` или `HIDE` в `server/main.ts`: без переменной
  режим включён только в `npm run dev`. Без флага игра должна вести себя ровно как раньше. Сейчас на сайте включены
  `FORTRESS`, `FIGHT`, `FISH2`, `SKILL`, `BOATRACE`, `HIDE`, `STORM`, `PIRATES`, `VOICE`, `GIFTS`, `LAB`, `JUKEBOX`, `ROULETTE` (`deploy/game-opus.service`).
  Исключение — `FISH2`: он включается только явной `1`, даже в `npm run dev`.
- **Своё — в новых файлах.** В общих файлах (`client/app.ts`, `client/lobby/scene.ts`, `server/hub.ts`,
  `shared/messages.ts`, `shared/maps/lobby.ts` и т. п.) — только короткие точечные подключения. Перед правкой
  перечитай файл: чужое не откатывай.
- **Решает сервер.** Жетоны, победы и рекорды считает сервер, клиенту не верим. Награды — в `shared/economy.ts`
  или рядом с режимом. Ориентир: 8–15 🪙 в минуту игры.
- **Десктоп главный, телефон не ломаем** (подробно — `AGENTS.md`). Кнопки — по образцу `client/touch.ts`, короткая
  проверка — в эмуляции телефона.
- **Не лагать.** Повторяющееся рисуй инстансами, без тяжёлых пост-эффектов.
- **Протокол.** Если меняешь формат сообщений, подними `PROTOCOL_VERSION` в `shared/constants.ts` (сейчас 13 и в коде,
  и на сайте). Сервер и клиент с разным протоколом выкладываются только вместе.
- **Голос** идёт через WebRTC и отдельный TURN (`deploy/voice-relay/`). Секрет TURN — такой же секрет, как токены.
- Не усложняй: сначала рабочее ядро, полировка — потом.

## Проверки — каждая задача заканчивается ими

```
npm run check && npm test && npm run build
```
Проверь свои тесты в `test/<тема>.test.ts` и коротко сыграй в браузере на `npm run dev`
(http://127.0.0.1:5190 или адрес, который напишет сервер). Перед выкладкой проверь боевую сборку под защитой сайта:
`tools/release/csp-proxy.mjs` и `tools/release/csp-check.mjs` (как запускать — написано в начале каждого файла).
В README — короткий раздел о новом и обновлённая строка о числе тестов.

Отчёт владельцу: что сделано, как посмотреть, что не проверено.

## Нельзя

- **Выкладывать на сайт и включать флаги на боевом сервере без «да» владельца.**
  Выкладка — `./deploy.sh`. Флаги — строки `Environment=…=1` в `deploy/game-opus.service`.
- Читать, печатать или просить токены, пароли и ключи. Писать их в код и журнал. Файлы в `/var/lib/game-opus/`
  с токенами не открывать.
- Трогать без «да» владельца: `chatgame/`, Jelly Arena на сервере, блок `/ctxai/` в nginx, защиту сервера.
- Трогать памятник: `statue*.ts`, `client/assets/statue`, `tools/statue`, `test/statue.test.ts`, всё со `STATUE`.
  Рядом с ним всё должно быть уважительным.
- Входить в игру на боевом сайте. Брать ник «Проверка»: он занят смоук-тестом. Для проверок бери, например, `Tester7`.
- Удалять данные игроков. Локальный сервер запускай с временной папкой: `DATA_DIR=$(mktemp -d)`.
- Запускать python3: на этой машине он сломан, бери node.
