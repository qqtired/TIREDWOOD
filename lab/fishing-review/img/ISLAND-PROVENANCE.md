# Картинки острова «Последний свет» для страницы ревью (10.10.2026)

Этап дизайна: картинки лежат только в `lab/fishing-review/img/`, в игру (`client/assets/`) пока не встроены. Дизайн —
`docs/superpowers/plans/2026-10-10-fishing-island.md` (разделы 5 и 8.2) и `...-fishing-island.json` (поле `species`).
Полные промпты, размеры, обрезка и SHA-256 каждой картинки — в `ISLAND-PROVENANCE.json`.

- Нарисовано: Codex CLI v0.153.4 (`codex exec`, модель gpt-6-astra), встроенный инструмент `image_gen`; рыбы — с прозрачным фоном
  (`transparent_background`), по одному вызову на картинку, без референсов и правок. Для скорости в вызове стоит
  `-c model_reasoning_effort="low"`. Одновременно шло не больше двух вызовов.
- Вызов: `codex exec --skip-git-repo-check -C <пустая рабочая папка> -c model_reasoning_effort="low" -o last.txt "<обёртка + промпт>"`,
  обёртка — как в `FISHECO-PROVENANCE.json`: «Use your built-in image generation tool to generate the following image on a genuinely
  transparent background … Then save the generated image as <id>.png in the current working directory».
- Стиль рыб — тот же шаблон, что у 52 существующих (`FISHECO-PROVENANCE.json`): полевая живопись, строгий профиль головой
  влево. Отличие одно: свет «чуть холоднее и туманнее» («slightly cool, misty pearl-grey cast»). Уточнения из дизайна: у анчоуса
  фотофоры — бледные нарисованные точки без свечения, у акулы-домового — розоватая кожа и длинное плоское рыло без оскала,
  у плащеносной — складчатые жабры и чуть приоткрытая пасть с мелкими зубами-трезубцами, без «монстра».
- Обработка (sharp, Node): рыбы — обрезка по непрозрачному с полем 1,2 %, уменьшение до 320 px по ширине, альфа ≥245 → 255 и ≤4 → 0,
  WebP 90; экран загрузки — вырез 16:9 из оригинала 1536×1024, 1280×720, WebP 62; доска — 1024×568, боковые полосы 345 и 425 px
  оригинала без искажений, середина с гладкими досками растянута, WebP 80.
- Оригиналы PNG лежат в `originals/`: для страницы ревью, в игру они не пойдут.
- Каждую картинку посмотрели глазами: тот вид, профиль головой влево, прозрачные углы, без надписей и лишних предметов.

## Экран загрузки «Последний свет» — `isle-loading.webp`

1280×720, 49.5 КБ (у существующих ~60 КБ). Маяк с красной полосой на скалистом мысу в жемчужном тумане,
тёплый луч, домики с горящими окнами, деревянный причал и мол, рыбацкая лодка с фонарями и два желейка в ней (оранжевый с фонарём
и красный с удочкой), тупики на камне и буи. Лодка красно-белая, без сине-жёлтого. Нижняя четверть кадра — спокойная вода: углы
остаются под текст интерфейса. Желейки добавлены, чтобы картинка была в одной серии с прежними экранами (там все с желейками).

Перегенерирован 1 раз: в первой попытке в нижнем правом углу были скалы с тупиками. Первая попытка оставлена запасным вариантом —
`isle-loading-alt.webp` (65.0 КБ): богаче и ярче, но с занятым правым нижним углом.

## Фон доски сезона острова — `isle-season-board.webp`

1024×568, 101.6 КБ. По образцу `client/assets/fishsign/season-board.webp`: серо-серебристые выбеленные доски (холоднее прежних),
витой канат по краю с морскими узлами, зелёная сеть с красно-белыми поплавками в двух углах, медный корабельный фонарь с тёплым
огоньком, сёмга слева и большеголов справа, звёзды, ракушки, мох и ракушечник, бухта каната. Середина (70 % × 75 %) чистая:
текст дорисует игра канвасом (Rubik). Попытка одна.
