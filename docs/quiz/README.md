# «Ракушка» — вход для следующего помощника

Квизы и игры с ведущим на набережной: летняя эстрада «Ракушка» в Приморском саду и режимы «Своя игра», «Загадка»,
«Крокодил», «Кто из нас?», паки вопросов (SIGame `.siq` и свой формат). Решения, правила режимов, числа и план —
в [brief.md](brief.md): это единая точка правды, правит её только ведущий.

## История
- 29.10.2026 — просьба владельца: «Своя игра» с ведущим, паками, выбором тем и загрузкой извне; режим «загадал —
  угадывают в чате — лайк/дизлайк»; придумать ещё режимы, как реализовать и как будет выглядеть. Вопросы ведущего
  и ответы: площадка — «Ракушка» на набережной со своим голосом внутри ограды; ведущий — живой + Затейник;
  паки — SIGame `.siq` + свой формат; в первую очередь ещё «Крокодил» и «Кто из нас?».
- 29.10.2026 — бриф, концепт-арт (Codex image_gen), страница-обзор `lab/quiz/` с живыми макетами на ките UI 2.0.
  Кода в игре нет: ждём «да» владельца по странице (AGENTS §4, «Большие задачи», шаг 5).
- 29.10.2026 — владелец отклонил страницу: «UI отвратительный у всех экранов… фон-подложка… Всё должно быть прямо
  в игре: кто загадывает — появляется на сцене, остальные сидят на стульях и отгадывают; чат общий внутри режима».
  Страница `lab/quiz/` осталась как v1 (что не делать: экраны поверх картинки). Начат этап 1 прямо в игре — ветка
  `mode/quiz`, рабочая копия `~/Desktop/game-opus-quiz`; условия приёмки — бриф, «Поправка владельца».
