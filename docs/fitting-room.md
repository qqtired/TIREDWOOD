# Примерочная TIREDWOOD

Отдельная лаборатория: референсы → отбор → 3D-примерка → готовность к переносу.
Игровые `ITEMS`, покупки, профили и сохранения игроков не меняются.

## Запуск

`npm run fitting:dev`, `npm run fitting:build`, `npm run fitting:preview`.
Локальный адрес — `http://127.0.0.1:5220/fitting-room/`.
Самостоятельная сборка — `dist-fitting-room/`, для `/fitting-room/` отдельного Lab.
Другой префикс: `FITTING_BASE=/нужный-путь/ npm run fitting:build`.
Общая сборка содержит `/lab/fitting-room/`, за флагом `LAB`; в Lab есть ссылка.
Выкладка и изменение nginx — только после разрешения владельца.

## Как пользоваться

1. **Задание на референсы:** выбрать слот, тему и число 1–40; скопировать задание
   в чат с Codex. Генерация не запускается кнопкой браузера. ImageGen создаёт каждый
   вариант отдельным изображением с `PROVENANCE.md`.
2. **Добавить референсы:** выбрать слот и загрузить до 40 PNG/JPEG/WebP за раз,
   до 8 МБ каждый. Можно перетащить файлы на страницу. Открыть изображение крупно,
   понравившееся отметить «Выбран для 3D».
3. **Создать 3D:** Codex моделирует выбранную вещь под желейку. В лабораторию
   добавляется фабрика модели или автономный GLB до 20 МБ с текстурами внутри.
   Внешние файлы и сжатие Draco/Meshopt не поддерживаются.
4. **Примерить:** цвет тела/узора, отдельная вещь или полный сет, студия и пирс,
   поворот камеры, ходьба, махание и танец. У GLB доступны положение, масштаб и
   повороты. Название, цена, редкость и заметка сохраняются отдельно.
5. **Решить:** «Доработать», «Не берём» или «Готово к переносу». Референс без модели
   не может быть готовым. Решение не добавляет вещь игрокам автоматически.
6. **Скачать проект:** JSON переносит каталог, отбор, наряд, сеты, локальные изображения
   и загруженные GLB. Импорт: «Добавить → Проект из файла». Размер копии до 512 МБ,
   одинаковый предел экспорта и импорта. Битые модели проверяются настоящим
   загрузчиком до записи проекта. Отдельные модели скачиваются кнопкой GLB.

Сохранение — IndexedDB этого браузера и адреса. Другой браузер, порт или домен
имеют отдельное хранилище. Скачай проект для переноса и резервной копии.
Локальные решения посетителя не меняют каталог у других посетителей.

## Слоты и границы

| Слот | Просмотр |
|---|---|
| Шапка, аксессуар, глаза | Крепления и деформация настоящего Avatar |
| Питомец | Игровой питомец или модель на плече |
| Узор | Игровой шейдер узора и второй цвет тела |
| Удочка, поплавок | Демонстрационная снасть, настоящие dressRig / dressFloat |
| Окно вываживания | Образец оформления, без настоящего улова и наград |
| Значок у ника | Игровая табличка Avatar и значок |

GLB подходит для шапок, аксессуаров, очков, питомцев, удочек и поплавков. Узоры,
окна и значки реализуются своим оформлением, без отдельной 3D-геометрии.
Импортированный GLB следует движениям и сжатию Avatar; собственные скелетные
клипы файла не проигрываются. Диорама не заменяет проверку будущей вещи во всех режимах.

## Стартовые материалы и добавление

68 игровых вещей читаются из `ITEMS`, цены — из `itemPrice`. Трофеи, подарки,
системные и джекпотные вещи подписаны «Не продаётся».
Шесть лабораторных моделей: портовая шапка, панама с цветком, сумка почтальона,
фотоаппарат туриста, круглые очки и краб на плече. Названия и цены предварительные.
Сет «После работы у моря» объединяет четыре вещи, цена — сумма цен участников.
Один пилотный ImageGen-референс шапки; источник и промпт —
`client/fitting-room/assets/PROVENANCE.md`.

Новая кодовая модель: фабрика `models.ts`, запись `BUILTIN_MODEL_SLOTS` и кандидат
в `catalog.ts`. Новый сет — `BUILTIN_SETS` либо «Сохранить наряд как сет».
Эти реестры принадлежат только лаборатории. Для переноса нужны отдельное решение
владельца, игровая идентичность, цена/способ выдачи и проверка наряда на сервере.
Экспорт — материал для этой работы, не исполняемый патч игры.

## Визуальная и функциональная проверка

Направление: три колонки, большой 3D-просмотр, светлые поверхности, оливковые действия,
карточка выбранной вещи справа. Сравнивались композиция, палитра, Rubik и размеры полей,
изображения, состояния кнопок, отбор и компактный экран. Визуальный концепт без букв;
реальные подписи созданы в коде по сценарию владельца. Осознанное отличие: настоящие
игровые геометрия и шейдер желейки, не фотореалистичный персонаж концепта. Небо,
вода и настил — из игры. Шапка и ремень сумки исправлены по снимкам собранной версии.

Проверки: `npm run check`, `npm test`, `npm run build`, `npm run fitting:build`.
Браузер — только headless Chrome. Сценарии: сохранение после перезагрузки, предмет/сет,
движение/окружение, 40 тестовых изображений, выбор, GLB, решение, полная копия и
восстановление в чистом хранилище. Телефон — эмуляция, физическое устройство не проверено.
