# Голос по удержанию V

Первая реализация запроса «TTS / touch to speak»: живой разговор, push-to-talk. Синтеза речи и записи разговоров нет. За флагом `VOICE`; сам голос не меняет профили, рыбалку и деньги. **Включён на production с релиза 20261003-090248; на сайте сейчас 20261003-122419 (лимит 6 мест). В коммите `65c0ba6` (ещё не выложен) отдельный лимит голоса снят — см. [voice-cap-removal-20261003.md](voice-cap-removal-20261003.md).** [Release receipt](release-prep/2026-10-03/REPORT-release.md); ограничения внешней голосовой связи остаются ниже.

## Как пользоваться

1. Открыть паузу Esc → «Голос» или нажать голосовую кнопку снизу слева.
2. «Включить голос» подключает к группе текущей серверной комнаты и позволяет слушать.
3. «Разрешить микрофон» запрашивает разрешение браузера. До этого захвата нет.
4. Вернуться в игру и удерживать **V**. Есть экранная кнопка удержания. Отпускание, потеря фокуса, скрытие вкладки, меню, чат, открытый диалог и переход в другой режим прекращают передачу. Повторное нажатие нужно делать заново.
5. Громкость голоса, отключение входящего звука и mute отдельных собеседников — в том же разделе. **M** глушит входящий голос вместе с игровым звуком; микрофон выключается отдельной кнопкой.

Группа — все добровольно подключившиеся игроки одной серверной комнаты, включая слушателей; отдельного лимита голоса нет (`VOICE_MAX_PEERS = 0`), действует только вместимость комнаты. На сайте до выкладки `65c0ba6` — ещё 6 мест. При переходе в другой режим старые соединения закрываются; включённый голос входит в группу нового режима, если есть место. При разрыве игры или выходе из голоса захват полностью останавливается. После переподключения требуется заново включить голос и микрофон. Заполненная группа показывает ошибку и кнопку повторной попытки, без автоматической очереди.

## Передача и инфраструктура

WebRTC с предпочтением **Opus**; запрашиваются mono, echo cancellation, noise suppression и AGC. Битрейт отправителя ограничивается 32 кбит/с на собеседника, если браузер поддерживает `setParameters`. Это целевой предел кодека, а не обещание точного сетевого расхода: есть RTP/DTLS/ICE и до пяти исходящих соединений. Отпущенная кнопка отключает audio track: могут передаваться пакеты тишины, микрофонный сигнал не передаётся. Полное выключение микрофона останавливает track.

WebSocket передаёт только SDP/ICE и состояние. Сервер проверяет авторизацию, точное совпадение комнаты, свежие voice-id, вместимость комнаты, только аудио, размер и частоту сообщений. Старые сообщения после перехода не подключают к прежней комнате. Медиаданные сервер игры не принимает и не хранит. P2P может раскрывать IP участников друг другу; предупреждение показано до включения. Для сокрытия прямых адресов нужен собственный TURN и `VOICE_RELAY_ONLY=1`.

| Переменная | Значение |
|---|---|
| `VOICE` | `1` включить; `0` отключить. Без переменной включено только с `--dev` |
| `VOICE_STUN_URLS` | STUN URI через пробел/запятую. По умолчанию `stun:stun.cloudflare.com:3478`; пустая строка отключает STUN, удобна для локального теста |
| `VOICE_TURN_URLS` | Необязательные `turn:` / `turns:` URI собственного TURN; максимум 8 ICE URI суммарно |
| `VOICE_TURN_SECRET` | Серверный секрет coturn REST/HMAC, 16–4096 символов, только через защищённое окружение. Не помещать в bundle, репозиторий или отчёты |
| `VOICE_RELAY_ONLY` | `1` разрешает только relay; требует настроенного TURN. По умолчанию `0` |

TURN получает временные HMAC-SHA1 credentials на 12 часов; username содержит срок и случайный nonce. Серверный секрет клиентам не передаётся. Клиент заранее обновляет конфигурацию. Это интеграция с coturn REST, а не автоматическая установка сервера или универсальный API любого платного провайдера. Неверная конфигурация даёт общее сообщение без печати значений.

Для микрофона требуется HTTPS либо localhost. Внешние сети с NAT/firewall могут не соединиться через один STUN: тогда нужен TURN. Не добавлялись платные сервисы, открытые серверные порты или изменения nginx. При отключённом VOICE начальная загрузка не создаёт голосовые UI/media/RTC.

Локальный запуск с отдельными тестовыми данными:

```sh
DATA_DIR=$(mktemp -d) VOICE=1 VOICE_STUN_URLS='' npm run dev
```

Для внешнего теста не отключайте STUN; сначала отдельно настройте и проверьте TURN при необходимости. Несколько вкладок одного origin используют один игровой профиль и вытесняют друг друга: для двух участников нужны разные браузерные профили/устройства.

## Проверки и откат

Результаты проверки конкретной сборки записываются в [voice-verification.md](voice-verification.md). Управляемые тесты проверяют разрешения, release, асинхронное завершение, лимиты, stale-id и конфигурацию. Браузерный тест использует настоящий RTC и синтетический сигнал; он не заменяет проверку физического микрофона, echo cancellation, внешних NAT и forced TURN на двух устройствах.

Самый простой откат функции — **`VOICE=0` и перезапуск согласованной новой сборки**. Клиенты переподключатся без голосового раздела; профили и другие изменения сохранятся. Протокол поднят с 9 до 10, поэтому клиент и сервер поставляются вместе. Для полного отката исходников есть отдельный pre-voice manifest в `../backups/game-opus-pre-voice-20261003-Cx3yd8`; не подменять файлы данных и старый сериализатор профилей.

При подготовке production отдельно закрыты S1–S6 из [отчёта для Opus](../../OPUS-GAME-STABILITY-OPTIMIZATION-2026-10-03.md): теперь любой обязательный JSON при переполнении очереди вызывает1013; one-shot selfReset также защищён. Дополнительные FPS-оптимизации остаются отдельной работой.
