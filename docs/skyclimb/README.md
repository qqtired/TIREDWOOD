# «Выше облаков» v3 — «Город вверх»: вход для следующего

История: 07.11.2026 владелец попросил полностью переделать каланчу — вместо прыжков по кругу вокруг одной башни
сделать долгую трассу вверх «как Chained Together / Only Up» с чекпоинтами и топом по времени. Решения и условия
приёмки — в [brief.md](brief.md) (правит ведущий).

## Что получилось

- Курс `sky-climb-v1`, флаг `SKILL_CLIMB=1` (в `npm run dev` включён). Старые курсы `sky-tower-v1` и
  `cloud-tower-185-v2` и их рекорды целы — флаг выключен, и всё как раньше.
- Серпантин из 7 отрезков: порт → крыши → колесо и канатка → стройка → провода над городом → шары над морем →
  облака и колокол. 28 флагов (0 — старт на причале, 27 — вершина), колокол на 307 м, путь ≈1,2 км.
- 217 опор, 31 подвижная площадка, 275 переходов (6 срезок). Бот со всеми ловушками — 6,22 мин.
- Медали: золото до 10:00, серебро до 16:00, бронза — любой финиш. Награды: 60 / 120 / 200 разово за ступень,
  «без падений» 100, первый подъём дня 40.
- Топ-10 времён трассы: табло у старта, карточка итогов, рекорд — строкой на вывеске у входа на площади.
  Отсечки на флагах против своего лучшего подъёма — в localStorage браузера.

## Что улучшить дальше

- Срезки, кроме маркиз, экономят мало (0,6–1,5 с) — добавить рискованные срезки мимо ожиданий колеса, канатки, клети.
- Откат кода на старый сервер теряет `skillArchive` (доску времён) — рекорды в профилях остаются.
- «Связка» как в Chained Together — отдельный режим на этой же трассе (цепь между двумя игроками).
