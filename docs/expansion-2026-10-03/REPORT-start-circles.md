# Круги старта

Готов `client/lobby/startcircles.ts`, без изменений общих файлов. Узкий TypeScript-check: PASS. Реальная игровая визуальная приёмка у ведущего.

```ts
const circle = new StartCircle(scene, {x,z,r,color:0x72b9aa,label:'Название',subtitle:'Подсказка'});
circle.setVisible(true); // constructor starts hidden
circle.status({left:3,n:2,max:8,phase:'countdown',hint:'Старт через 3 секунды'});
circle.update(dt); // no frame redraw required
circle.dispose();
```

Геометрия фиксирована: одна тонкая окружность, плоский полупрозрачный диск на земле, боковая табличка .98×.245м на тонкой опоре. Число отсчёта крупное на земле; прямоугольной панели перед участниками нет. При `left=3.2` отображается4; если3.1 не меняет целое отображаемое значение, canvas не перерисовывается. Canvas512²/768×192; геометрический текст/динамические меши не создаются. dispose удаляет группу и освобождает геометрии/материалы/текстуры.

Ведущий создаёт PB(0,-15.2,r1.35),Fort(11,-15.3,r1.2),Boat/HIDE по их общим координатам. Компонент не определяет таймеры, участников, флаги или серверные переходы. Браузер/сборка/скриншоты в этой подзадаче не выполнялись.

Визуальная поправка после скриншота ведущего `expansion-pb-circle.png`: исходная DoubleSide-плоскость зеркалила текст при подходе с юга. Табличка теперь состоит из двух FrontSide-граней с противоположным поворотом и разносом6мм. Обе используют одну геометрию/текстуру/материал; добавлено2треугольника и1draw call. Размер/опора/наклон сохранены. Скриншот фактически просмотрен; узкий typecheck после исправления PASS. Повторный браузерный кадр делает ведущий.
