# Библиотека TIREDWOOD

Открыть: index.html. Встроенный каталог работает через file:// и HTTP. Ссылки относительные.

Для модульных HTML: `node tools/visual-library/serve.mjs`, затем localhost:5389. TypeScript-стенды требуют установленного окружения Vite проекта; они обозначены отдельно.

Обновление: `TIREDWOOD_VISUAL_SOURCE=/путь/к/tired.solutions node tools/visual-library/collect.mjs --include-r8`. Без --include-r8 незавершённая r8 откладывается. Сборщик не меняет оригиналы и не выполняет Git-команды записи.

manifest.json содержит все исходные имена, категории, версии, хеши, зависимости, внешние адреса, пропуски и причины исключений. Совпадающий HTML сгруппирован; ссылки каждого origin сохранены, потому что одинаковые оболочки могут использовать различающиеся ресурсы.

Секреты и частные серверные URL скрываются в копиях; значения не попадают в журнал. Список обработанных файлов — redactions в manifest.

Библиотека лежит вне public/dist и не входит в игровые ресурсы Vite. Архивы .blend, базы и прочие неиспользуемые исходники не копируются.

Физическое содержимое дедуплицировано в objects/. files/ и previews/ содержат относительные символьные ссылки внутри библиотеки. Git должен сохранять symlink (обычное поведение macOS/Linux); при распаковке архива не разыменовывать их. Служебный кэш сборщика и устаревшие промежуточные копии исключены через .gitignore.

Финальная проверка текстовых объектов и перенос промежуточных копий: `node tools/visual-library/finish.mjs`. Значения чувствительных строк не выводятся; редактируются только библиотечные копии. Реальные отсутствующие href/src перечислены в verification/unresolved-links.json; шаблоны отмечены отдельно.
