С чего начать

Порядок по силе нынешней проблемы. Пакеты можно выбирать независимо.

  1. РегатаРуль, снос и камера → один приятный курс → простые варианты входа.
  2. КаланчаВысокая фиксированная трасса и личное время. Затем отдельная высота + время.
  3. АквапаркНовый вид и связки существующих модулей, прежнее движение.
  4. ОстальныеКартинг: личный призрак. Пейнтбол: цель на Причале. Бильярд: три задачи в тренировке.
Концепт ≠ готовый режим. Источники проверены по текущему коду; цели приёмки предложены. Изображения — настоящие ImageGen-референсы. Схемы объясняют механику, не симулируют игру.
