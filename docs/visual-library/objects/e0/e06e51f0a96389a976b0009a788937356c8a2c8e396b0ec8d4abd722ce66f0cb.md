# TIREDWOOD: десять направлений HUD

Открыть `./index.html` напрямую: автономная офлайн-страница, все игровые ресурсы встроены. Новые направления 6–10 сгруппированы отдельно, первые 1–5 сохранены, рядом контрольный main. A/B сравнивает на одном размере и одном наборе значений.

6 «Паспорт желейки» связывает портрет, профиль и сегментированный HP. 7 «Кромка» разносит HP и сгруппированный боезапас по краям. 8 «Время событий» показывает приоритет и срок сообщений. 9 «Нижняя палуба» собирает состояние/действия в нижний последовательный ряд. 10 «Прибор действия» держит одну точку и размер 220×120 для E и оружия.

Новые направления работают в сценах спокойной набережной, Крепости и нагруженной набережной. **Подземелье всегда отображает отдельный неизменный контрольный HUD, только для просмотра**. Выбор 1–10 не переодевает его. Центральных окон, меню, журнала, продажи и окна рыбалки на стенде нет.

HP/патроны/оружие появляются там, где они есть в режиме. В «Кромке» вертикальная шкала уменьшается сверху вниз, точное число остаётся; магазин показан группами по 5, большие — по 10. В «Времени событий» актуальное предупреждение связи не истекает вместе с наградой. Перезарядка и выбор оружия локальные: Маркер 30, Дробовик 8 — реальные размеры магазина из `shared/fortarsenal.ts`. Числа в сценах постановочные.

Новый портрет взят из локального farm-pack1. Контрольный бейдж main сохранён с ником. Контроль — схема основных элементов по исходникам, не запись запуска. Чистый фон по умолчанию снят ведущим с локального пакета 12.10.2026 при временно скрытом DOM HUD; это не заявление о выпуске пакета.

Официальные референсы и выводы — в `../../research/brief.md`, точные URLs screenshots — `../../research/sources.json`. Для каждого нового направления в HTML раскрывается пара первичных источников и пояснение переноса. Использованы просмотренные screenshots Hades, Dota 2, Terraria, Hollow Knight, Slime Rancher; поведение приоритета взято из документации Epic, фиксированное взаимодействие — из accessibility guide Rare. Перенос — дизайнерское предложение для TIREDWOOD.

Редактируемый код: `./source/app.js` / `styles.css` сохраняют исходную страницу; `next-data.js`, `next.js`, `next.css` добавляют 6–10. `data.js` — общие сценарии. `page.html` — оболочка. `{tokens,kit,combat,dungeon}.css` — сохранённая база существующей игры для контрольного вида. `assets/` — родные ресурсы.
