# Браузерный QA — подготовлен, не выполнен

Запускать только в root-owned Chrome после освобождения heavy runner и сборки финального принятого пакета. Этот worker браузер не запускал. Сценарий не измеряет winrate/FPS и не подтверждает визуальное качество моделей.

1. Открыть `../../index.html` и получить свежий snapshot. Убедиться, что видны event labs, controls и canvas; отсутствуют ошибки загрузки.
2. Передать `./source/qa-events.run-code.js` в имеющийся Playwright `run-code`. Код использует реальные DOM controls и читает состояние через API. Он не вызывает API управления `choose`, `seek` или `reset`.
3. Зафиксировать возврат JSON, console errors и реальные screenshots выбранных состояний. Отдельно осмотреть модели/контактные кадры; зелёные state assertions не заменяют эту проверку.

CLI wrapper доступен: `[LOCAL_PATH]`; `npx` найден. Пример после открытия страницы в собственной сессии root:

```sh
[LOCAL_PATH] run-code "$(cat [LOCAL_PATH])"
```

Стабильные selectors: `#scenario-tabs [data-scenario]`, `#choice-buttons [data-action]`, `#event-time`, `#run-play`, `#run-step`, `#run-reset`, `#event-humans`, `#calc-wave`. Slider меняется через его DOM value/input event. Read-only наблюдения: `window.fortressV2Lab.state`, `.mode`, `window.fortressV2Native.state`, `.ports`, `.ready`.

Восемь событий: ранний counter / игнорирование, поздние irreversibles, before/on/after дедлайны, scrub0→end, reset, pause и N1/N4. Структурные repro: поздние gate/battery/tower/stores; one-group canopy; настоящая остановка/освобождение spread trap; оплаченная и расходуемая forge партия; отличающаяся высадка hull/anchor.

Native controls после принятой сборки: `[data-native-model]`, `#model-model`, `#model-clip`, `#model-variant`, `#model-cycle`, `#model-hold-walk`, `#model-ports`, `[data-model-phase]`. Все шесть: idle/walk/windup/attack/recover/hit/death и реально существующие специальные клипы; scrub первой/средней/последней фазы death, смена модели после death, повтор clip/reset, A/B Старшины. Проверить читаемость лица/силуэта, опоры ног, соединения клешни/шланга/нагрузки, отдельные смерти, рендер на desktop/mobile, отсутствие horizontal overflow и external requests. Режим walk на месте явно скрывает только displacement; для контактов выключить его и смотреть исходный root motion.

`source/build.mjs --require-models` выполняет один bounded report bundle после root принятия точных файлов. Все шесть `acceptedByRoot:true`, matching GLB SHA и реальные inputStart/inputEnd обязательны; непринятые кандидаты не читаются/не встраиваются. V1/main index заморожены до root visual QA.
