Что не стали менять

  • Запекание всего света/теней: соответствие дождевой палитре, blackout и движущимся деталям не доказано.
  • Общий batch всех кварталов: он ухудшил бы отсечение за кадром.
  • Объединение матовых и глянцевых материалов: оно потеряло бы различие штукатурки, эмали и лака.
  • Урезание моделей, густоты растений, текстур, дальности, fade, теней и воды: риск ухудшения принятого изображения.
  • Глобальная заморозка матриц: риск для attach, anchors, лодок, дверей и скелетов.

Проверка и откат

Проверка типов, 20 узких тестов, сборка и diff check прошли; runtime errors 0. Полный общий gate и независимое ревью делает ведущий. Тест имени сначала воспроизвёл проблему: 30 неподвижных обновлений давали 30 повторных requests обновления каждого буфера. После изменения проверяются неизменный кадр, движение, плавная прозрачность и скрытие. Отдельная регрессия сохраняет синхронизацию живых shader uniforms и исключение inherited свойств.

Файлы игры: client/lobby/plaza3/perf.ts, client/lobby/plaza3/npc.ts и узкие регрессионные тесты. Ни source Blender, ни GLB, ни профили не менялись. Ведущий создаёт отдельный коммит после независимого review/full gate; откат — git revert <optimization-commit>.
