Аркада у автоматов

Рядом со слотами — ряд обычных игровых автоматов: без ставок, только ловкость и рекорды. Три мини-игры на 1–3 минуты. Выбери автомат мышью или клавишей 1–3.

Страница открыта как файл — браузер не грузит модули с диска. Открой её через сервер: в папке игры npm run dev → /lab/plaza3/arcade/, или любой статический сервер в папке lab/plaza3/arcade.

На экранах — демо, как у настоящих автоматов. «Играет Саня» — так соседи видят автомат, за которым кто-то играет: имя и живой счёт. Три пустых места — под будущие игры.

Награды предложение

Платим за медаль партии: новичку бронза — со второй-третьей попытки, золото — повод вернуться. Длинные игры платят больше: хорошая игра — 8–13 🪙 в минуту.

очки → 🪙ПаровозикТирЗамок
  • Свой рекорд в игре — ещё +10 🪙 (раз в день на игру).
  • Первое место недели или всех времён — +25 🪙 и строка в общий чат.
  • Потолок — 150 🪙 в день на всю аркаду. Дальше играешь за рекорды.

Рекорды

Над каждым автоматом — табло «Неделя» и «Всё время», по пять строк; твоя строка — золотом. Неделя начинается в понедельник в 00:00 по Москве.

Новый рекорд — баннер на экране, фанфары и строка в общий чат: «Роман набрал 1240 в «Паровозике» — рекорд недели!»

Честно

Сервер выдаёт партии зерно, игра записывает нажатия. В конце сервер сам переигрывает партию по журналу и сам считает очки — подделать счёт нельзя.

Здесь это видно: после каждой партии справа строка «Сервер переиграл бы…» с его счётом.
