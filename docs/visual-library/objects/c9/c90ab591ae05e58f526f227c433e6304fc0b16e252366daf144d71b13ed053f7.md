# TIREDWOOD: пять направлений HUD

Открыть `./index.html` напрямую: это автономная офлайн-страница. Нужен браузер с CSS `conic-gradient` и `:has` (актуальный Chrome/Safari).

Пять направлений: Воздух / Эмаль / Кованый фонарь / Курортная лента / Полевой блокнот.
Сценарии: спокойная набережная, бой в крепости, забег Подземелья, набережная с чатом и тремя уведомлениями.
Есть контрольная схема main, A/B без уменьшения текста, два чистых игровых кадра, светлая/тёмная сцена, HUD 90/100 %, нагрузка тостов.

Все пять предложений используют один набор данных `./source/data.js`. Внутренний уровень Подземелья (11) не смешан с уровнем профиля (12); жетоны — в одном бейдже. HP / патроны / оружия появляются там, где они есть в соответствующем режиме. Центральных окон, меню, журнала, продажи и окна рыбалки на стенде нет.

Новый портрет взят из текущего локального farm-pack1; контрольный бейдж сохранён по main с ником. Контроль — схема основных HUD-элементов по коду, не запись запуска. Радар и состояние боевого мира здесь постановочные. Фон по умолчанию снят ведущим с локального farm-pack1 12.10.2026 при временно скрытом DOM HUD. Это не заявление о выпуске пакета.

`./source/app.js` — отображение и локальный отклик. `./source/styles.css` — пять компоновок. `./source/page.html` — оболочка. `source/{tokens,kit,combat,dungeon}.css` — сохранённая база существующей игры для контрольного вида. `assets/` — родные иконки, шрифты, два кадра и SVG-портрет.

Пересобрать автономный HTML:

```sh
/opt/homebrew/opt/node@24/bin/node source/build.mjs
/opt/homebrew/opt/node@24/bin/node source/check.mjs
```

`prepare-assets.mjs` предназначен для первоначального снятия ресурсов с исходников. Для обычного редактирования и пересборки он не нужен. Следующие снимки не должны заменять контрольный main или смысл исходного набора данных без обновления подписей.

Браузерные селекторы:

- `[data-direction=clean|enamel|lantern|ribbon|ledger|current]`
- `#scenario`: `plaza`, `fort`, `dungeon`, `busy`
- `#lighting`: `day`, `dusk`; `#background`: `background`, `background-lab`
- `#ui-scale`: `90`, `100`; `#load`: `auto`, `0`, `1`, `3`
- `#compare`, `#ab`, `#focus`, `#exit-focus`
- `[data-action=hit|heal|toast|hero|reset|chat|voice]`
- `#chat-message` + Enter. Сохранение выбора в игре и сервер отсутствуют.

Структурная проверка 72 сочетаний renderer/scenario/load прошла. Она не заменяет визуальную проверку браузером. Ведущий проводит её на одном общем runner; см. его финальный отчёт.
