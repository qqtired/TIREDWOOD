# Fortress R2 — просмотрщик подготовлен к финальному пакету

Это source-only подготовка. Текущий `v2/index.html` остаётся ранее проверенным event lab; новые кандидаты в него ещё не встроены. V1 и основной index сохранены. Файлы `v2/models` принадлежат model-refinement worker и этим worker не менялись.

Согласованный manifest: `./models/manifest.json`, IDs `ropecrab/jampump/canopy/foreman/crabcrane/miller`. Формы приняты для animation review, `acceptedByRoot=false` до полного принятия. Один финальный `source/build.mjs --require-models` после root GO требует все шесть `acceptedByRoot:true`, точные GLB SHA, реальные клипы/inputStart/inputEnd, exported ports, material/primitive counts и matching contact proof. Непринятый пакет не читается и не встраивается.

Подготовлены:

- Общий существующий canvas и renderer для event labs, старых source-анимаций и новых GLB; новый WebGL context не создаётся.
- Lazy GLTFLoader для принятого GLB; реальные idle/walk/windup/attack/recover/hit/death и специальные клипы. Цикл собирается только из существующих клипов. Native `AnimationClip.duration` сверяется с manifest; offset 1/24 с сохраняется.
- Play/pause/step/reset/scrub и фазовые кнопки death. Контактные кадры читаются из exported-checks: это near-floor proxy ≤1,5 см на 24 fps, не игровая физика столкновения.
- Ходьба на месте скрывает только root displacement и явно подписана; исходный root motion доступен. Остальные клипы не нейтрализуются. Смена clip после death восстанавливает отдельные части через настоящий Three AnimationMixer.
- Канат и струя следуют `object.getWorldPosition()` экспортированных портов, а не rest-координатам. Диагностические маркеры отключены по умолчанию.
- Реальные PNG/attack/death contact sheets и экспортные метрики; отдельные ссылки GLB/BLEND/MCP receipt. Optional atlas B только после своего принятия и PASS parity; A по умолчанию, та же модель/клипы.
- Сохранённые ImageGen originals v1 с provenance помечены как ранние эскизы направления, не Blender renders R2.
- `./QA-RUN-CODE.md` и `./source/qa-events.run-code.js`: реальные controls восьми событий, late failures, scrub/reset/pause/N1/N4; API используется только для наблюдения. Браузерный сценарий не выполнен.

Свежая узкая проверка: 42 тестов PASS, включая 7 проверок настоящего Three mixer на явных тестовых fixtures. Это проверка компонента, а не визуальное принятие шести моделей. JS syntax, DOM selectors и run-code syntax проверены. Кандидатный реальный manifest остаётся закрытым для embedding. Chrome, Blender, сервер, report bundle и полный game build/gate не запускались в этой фазе.

Основные новые файлы: `./source/native-model-viewer.js`, `native-model-timeline.mjs`, `collect-model-assets.mjs`, их tests и QA run-code. Изменены только source hooks/HTML/build/check, не сценарная причинность и не арифметика 98-й волны. Контакты/разные смерти требуют настоящего visual review; карта и арифметические времена не превращаются в winrate.
