# Локальный стенд WebGL / WebGPU

Исследовательский прототип для сравнения рендереров на одной детерминированной процедурной набережной. Не входит в сборку игры и не подключается к игровому серверу. Это не измерение полной TIREDWOOD и не проверка вместимости боевого сервера.

## Запуск

Использовать Node 24+ (на текущем Mac: `/opt/homebrew/opt/node@24/bin/node`). Из корня `game-opus`:

```sh
npm run bench:check
npm run bench:build
npm run bench:preview
```

Адрес: `http://127.0.0.1:5199/`. Для разработки — `npm run bench:dev`. Артефакты сборки находятся только в `tools/render-bench/dist/`, игровая `dist/` не меняется. Зависимостей сверх уже установленных Three.js и Vite нет. Spector загружается отдельно с CDN лишь по кнопке захвата.

## Сравнение

- A — `WebGLRenderer`, классические материалы и GLSL-доработки.
- B — `WebGPURenderer` с `forceWebGL: true`, node-материалы.
- C — `WebGPURenderer` с проверенным WebGPU backend; откат на WebGL не принимается.

Переключатель «Нагрузка» выбирает исходный режим **1×** (16 / 64 персонажа) или **10×** (160 / 640 персонажей, 100 зданий, 240 деревьев, 18 000 дождевых полос, 960×80 сегментов воды). По умолчанию выбран 10×. Кнопка общего теста запускает только две сцены выбранной нагрузки. Исходная геометрия, движение и сигнатуры режима 1× сохранены.

Множитель относится к компонентам сцены, а не к обещанию ровно десятикратного времени кадра. Статические расходы и число инстансированных отрисовок не растут линейно. Реальный submitted workload следует брать из samples JSON; в исследовании 10× получены около 9,4–9,8× draw calls и около 10× треугольников.

B/C используют один граф материалов. Геометрия, расстановка, анимация, камера и параметры качества одинаковы; сигнатура сцены и исходные данные входят в JSON. Различия встроенного освещения, теней и цветопреобразования следует оценивать по кадру t=2 с. Сцена намеренно упрощена: нет полного набора игровых материалов, одежды, отражений, UI и сети. Их отсутствие не позволяет переносить процент ускорения на всю игру.

По умолчанию: буфер 1280×720, DPR 1, прогрев 3 с, измерение 10 с, 3 повтора. Для каждой из двух сцен порядок вращается A/B/C → B/C/A → C/A/B. После чистых измерений идут отдельные GPU-профили. Вкладка должна оставаться видимой, размер — постоянным. Инициализация/компиляция сцены измеряются отдельно; это не холодный запуск браузера или очищенного кеша драйвера.

В JSON сохраняются исходные интервалы кадров, CPU submission time, необязательные GPU timestamps, процентили, backend, сведения о среде, настройки и причины недействительности. Отсутствующее GPU-время — `null`, не 0. GPU-профиль не смешивать с чистыми измерениями: запросы сами создают дополнительную работу. CPU submission не означает время выполнения на видеокарте. FPS может упираться в частоту экрана.

Большие серии могут превышать лимит `localStorage`; браузерную таблицу не используйте как архив. Сохраняйте полный JSON. В первом исследовании большой экспорт встроенного браузера был записан без потерь через одноразовый локальный приёмник; этот обход описан в артефактах отчёта и не относится к игровому серверу.

«Кадр на 2-й секунде» готовит PNG. Захват Spector поддерживается только у A/B; после подключения инспектора перед новым измерением требуется перезагрузка. Данные таблицы сохраняются локально в браузере; экспортируйте JSON для воспроизводимого отчёта.

Если CDN недоступен, официальный `dist/spector.bundle.js` из тега `v0.9.33` репозитория `BabylonJS/Spector.js` можно положить в отдельную папку сборки как `spector-0.9.33.js`, загрузить его на странице через DevTools, затем нажать ту же кнопку захвата. Это делается только после чистых измерений. Браузер после диагностического подключения перезагрузить.

## Проверки

```sh
node --test test/render-bench-*.test.ts
npm run bench:check
npm run bench:build
npm run check && npm test && npm run build
```

Браузерная проверка обязательна: настоящие A/B/C, отсутствие ошибок компиляции, фиксированные кадры и выгрузка результатов. Эмуляция телефона проверяет только интерфейс стенда; десктопные измерения не доказывают производительность телефона.
