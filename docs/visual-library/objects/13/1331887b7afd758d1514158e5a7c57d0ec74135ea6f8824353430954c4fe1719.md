# Подземелье R2 — план реализации

> Исполнитель: `dungeon_expansion_concept`, native execution через executing-plans. Коммиты, общий прогон и браузерная приёмка — root. Новых агентов не запускать.

**Цель:** новые враги после15-й, новый фазовый босс20-й и эволюции всех8нынешних оружий работают в настоящем бесконечном забеге; обновлённый прежний HTML объясняет реализованный результат.

**Архитектура:** расширяем нынешнюю детерминированную shared/dungeon симуляцию. Рецепты остаются в данных и общем механизме сундуков. Модели передают полный цикл атаки с `animAt`, события impact/death приходят из manifest; клиент рисует фактическое состояние, не proximity-атаку. Новые виды используют нынешнюю запечённую инстансную анимацию, босс — отдельный skinned renderer.

**Стек:** Node24, TypeScript, three.js, Vite/Rolldown. Без новых зависимостей и постоянных player fields.

**Бриф:** `/tmp/tiredwood-farm-pack1.NNujvo/dungeon-evolutions-v2-brief.md`, принят root12.10.2026. Рецепты: Фонарь+Фитиль;Угольки+Масло;Кирка+Сапоги;Светляки+Фартук;Искра+Подкова;Сталактиты+Каска;Шашки+Кремень;Луч+Линза. Оружие7+катализатор≥1+сундук, одна первая готовая,5+5слотов.
