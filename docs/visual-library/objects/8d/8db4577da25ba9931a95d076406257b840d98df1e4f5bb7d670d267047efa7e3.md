## P2 — Space keep → следующий заброс подключён только к пруду

- `client/lobby/scene.ts:1964`: Space вызывает только `fishPress()`.
- `client/lobby/scene.ts:2212`: `fishPress()` возвращается при `fish2.choosing`, поэтому карточка улова не сохраняется по Space.
- `client/lobby/fish2hud.ts:89`: `onAutoCast` по умолчанию пустой; в текущем LobbyScene callback не подключён.
- Рабочие подключения есть только в `client/farm/pond.ts:50` и `client/farm/pond.ts:163`.

Воспроизведение: включить FISH2, сесть на любое место набережной, лодки или острова; выловить обычную рыбу с выбором «В рюкзак / Отпустить», дождаться конца CHOICE_LOCK_MS, нажать новый Space. Source path не отправляет `keep` и следующий `cast`. Та же последовательность на пруду использует новый helper. Требование F1 предусматривает одинаковое действие для всех этих мест.

Ведущий подтвердил, что exact patch Lobby hooks ожидает общей интеграции из waterfront-ветки. После его подключения нужен свежий final-state просмотр и runtime сценарий. Finding не является неожиданным новым blocker, но на момент этого среза контракт отсутствует.
