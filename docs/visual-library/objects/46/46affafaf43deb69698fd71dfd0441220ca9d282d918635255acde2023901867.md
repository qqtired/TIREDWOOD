# Лёгкая текстура — один A/B на Старшине

Разрешение Романа: попробовать лёгкие ImageGen текстуры шерсти/доспехов на Blender-моделях. Это эксперимент, не способ скрыть простую геометрию или одинаковые анимации.

Цель: Старшина v2, вариант A без текстуры / вариант B с одним цветовым atlas. Один исходный1024×1024 PNG, runtime512 или1024. Не делать4K, комплект PBR, normal/roughness/metalness картинки. Материалы, геометрия, triangles, анимации и UV развёртка обоих вариантов одинаковы; растёт только один texture bitmap.

Четыре зоны atlas: каштановая матовая шерсть, кремовая грубая ткань, тёплые цельные деревянные доски со слабой патиной, тёмный потёртый металл. Дистанция камеры требует крупных мягких вариаций, не волосков, гравировки и шума. Глянец варенья и сиреневые глаза остаются своими смысловыми материалами/цветами; фиолетовые пятна не запекать хаотично в шерсть.

Генерировать только через Codex CLI built-in image_gen, текущий repo pipeline; сохранить original без изменений, prompt, receipt, source SHA256. Затем уменьшить отдельную веб/runtime копию sips, original не менять. Никаких API keys/PythonAPI.

Промпт:

```text
Use your built-in image_gen tool to generate one square 1024x1024 colour atlas for a warm stylised seaside fortress game. Image-only job, no API keys, Python, SVG or drawing scripts. Return the exact generated PNG path.

Four equal square material swatches fill the canvas, without gaps, labels or borders. Top left: matte warm chestnut-brown beaver fur, broad softly painted irregular clumps, very low contrast, no individual photoreal strands. Top right: warm cream coarse woven work-apron fabric, subtle wide weave and restrained wear, flat albedo lighting. Bottom left: warm walnut wooden boards with broad readable grain and mild edge patina, no deep grooves or painted lights. Bottom right: matte dark warm iron, soft broad scuffs and wear, no shiny reflections or dramatic highlights. Each swatch should tile in its own region. Match a mature yet charming painted cartoon game, natural warm colours, no toy-plastic sheen, no neon, no sci-fi, no blood, skulls or horror. This is a flat diffuse/albedo sheet: no shadows, scene lighting, perspective, objects, UV wireframe, text, letters, numbers, logo, watermark or border. Use large gentle variation, not noisy miniature detail.
```

Проверка: один ряд A/B с одинаковыми светом, ракурсом, позой, расстоянием. Вблизи убедиться, что материал помогает форме; с25м пятно не мерцает и не выглядит грязью, лицо/слабый штифт читаются. В отчёт — image bytes/resolution, GLB texture count, triangles/materials/drawcalls обоих и наблюдение критика. Если B выглядит грязнее или пластичнее — оставить A.
