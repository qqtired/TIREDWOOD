Пять новых вариантов — предложения, которые ещё не внедрены. «Текущий · main» — контрольная схема основных элементов из исходников main 62f814f: Светлый HUD, текущий бейдж с ником, общий чат и боевая панель. В Подземелье сохраняется его отдельная тема. Это схема на общих постановочных данных; она не является снимком запуска игры.

Новые бейджи используют портрет из локального пакета farm-pack1. Размер 90 % — отдельное условие сравнения. Эти изменения не выданы за выпущенные. Числа — одинаковый набор для каждого варианта; клавиши, валюта, оружие и типы событий взяты из существующей игры.

Фон — чистый кадр лаборатории UI 2.0; тёмная сцена моделируется затемнением этого же кадра. Игровая сцена статична, клики проигрывают только локальные примеры.
