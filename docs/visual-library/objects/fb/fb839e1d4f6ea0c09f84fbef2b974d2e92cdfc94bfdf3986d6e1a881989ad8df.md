# Передача модельеру Fortress v2

Полные сюжеты формы, attack/hit/weakness/death — `./BRIEF-REV2.md` §6. Бриф принят root для ревизии. Старые картинки/GLB сохранены в `../v1/`; не перезаписывать их и не объявлять v1 новым результатом.

Модельные IDs: `ropecrab`, `jampump`, `canopy`, `foreman`, `crabcrane`, `miller`. Мобы/элита поддерживают замковые сценарии, не являются просто новым цветом старой роли:

|Модель|Сцена/задача|Основной предмет|Пример позиции на стенде|
|---|---|---|---|
|Канатник|Осадная башня / якорь|Натянутая катушка, крюк, стопор|(-23,0,-7)|
|Смоливщик|Насос / склад|Клапан, рычаг, настоящий шланг|(-5,0,-22)|
|Зонтиковик|Рассыпной строй / мостик|Рёбра навеса и замок|(-5,0,-25)/(5,0,-25)|
|Старшина|Батарея / заклинившая тяга|А-распорка, рабочая рука, штифт|(13,0,-28)|
|Краб-Кран|Большая осада / груз и сектор|Асимметричная стрела, опоры, лебёдка|Отдельная boss-сцена, не масштабированный Канатник|
|Мельничиха|Ветер / работа с муфтой|Толстое колесо/рама/копыта/ткань|Отдельная boss-сцена и модельный обзор|

Формы должны держать среднюю детализацию из `docs/models.md` и глубину эталонов currentFort. Сравнение из текущего source уже есть в `v2/index.html`: Подрывник, фуга, Барон, Валун, Таран, Ткачиха. Переключи их death/attack перед проектированием новой части. Это настоящие procedural pose, а не произвольные рекламные картинки.

Главный запрет: общий `root` по диагонали у всех шести, даже с разными amplitudes, не считается уникальной гибелью. У каждого работает своя конструкция/тело/предмет в несколько стадий из брифа. Обязательно отдельно смотреть начало, середину и конец death, чтобы ведущий не угадывал по одному ключевому кадру.

Сдача: `v2/models/manifest.json`, пути от корня `v2/`; отдельные GLB/BLEND/воспроизводимый script snapshot/PNG. Manifest `{models:[{id,name,glb,blend,render,triangles,materials,clips,mcpEvidence,mcpReceipt,version,deathStoryboard,textureVariant}]}`. Имена клипов `<id>_idle/walk/windup/attack/hit/death`; роль/boss клипы дополнительно. Время указать по настоящему GLB, включая квантование24fps и экспортный offset, не только желаемое число.

Сохранить реальный MCP transport receipt, Blender version/background=true, channel variation и длительности; метод создания без окна. Не выдавать static PNG за анимационную приёмку. `.blend` и GLB до ревью отдельными версиями.

Для Старшины один A/B из `./TEXTURE-AB.md`: одинаковые geometry/UV/clips/materials, один лёгкий512/1024coloratlas через CodexCLI image_gen; original/prompts/receipt/SHA отдельно. Материалы/triangle count обоих показывать честно. Без4K/PBRпакетов. Если atlas делает грязнее/пластичнее — вариант A сохраняется как предпочтительный.

Root выполняет строгую визуальную критику перед вставкой/обновлением основного index. Gameimplementation Fortress этим контрактом не разрешается.
