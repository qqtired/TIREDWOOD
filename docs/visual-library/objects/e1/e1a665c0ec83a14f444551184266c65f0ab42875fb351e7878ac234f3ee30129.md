# Optional atlas — граница production CSP

Plain остаётся default. Текстурный atlas A/B не принят: в настоящем renderer текстура не загрузилась под production CSP. Изменение loader или CSP для текущей поставки не требуется.

Root наблюдал запрет fetch(blob:) и сообщение GLTFLoader Couldn't load texture. Свежий result.json даёт automated FAIL / visual NOT_ACCEPTED, softMapBound=false при softShaderLinked=true и serverParity=true. В soft-same-pose.json у живого инстанса map=false; failedPrograms=[] означает успешный шейдер без карты и не доказывает atlas поддержку.

## Проверенный локальный путь

- client/dungeon/assets.ts:61: обычный GLTFLoader без специального image handler.
- Установленный three.js0.186.1, GLTFLoader.js:2653–2661: в Chrome выбирается ImageBitmapLoader.
- GLTFLoader.js:3359–3369: embedded image.bufferView превращается в Blob и object URL.
- ImageBitmapLoader.js:173: fetch(url), затем createImageBitmap(blob). Root наблюдал блокировку blob fetch.
- GLTFLoader.js:3331: ошибка картинки превращается в null texture, сам GLB может успешно загрузиться.
- tools/release/csp-proxy.mjs:8: connect-src self + wss://game.tired.solutions, img-src self + data:. CSP не изменена.
- Soft GLB:1PNG1024×1024,919127bytes,1texture,UV0. Native структура, компенсация яркости и exact motion сохраняют свои доказательства; это не live texture acceptance.

## Минимальный будущий вариант — только если atlas понадобится

Локальный plugin для Dungeon GLTFLoader: для embedded PNG/JPEG взять уже загруженный bufferView через parser.getDependency, декодировать createImageBitmap(new Blob([bytes],{type:mimeType})) напрямую и вернуть Texture через стандартный GLTF texture path. Он сохраняет sampler, flipY=false, colorSpace/baseColorFactor и нынешний merge/VAT. Нет fetch(blob:) и нового сетевого ресурса; CSP менять не требуется. Это предложение, код не внедрён и runtime не проверен.

TextureLoader — допустимая простая альтернатива с data URI, созданным из embedded bytes: img-src data: уже разрешён. Это добавляет временную base64 копию (~1.23MB для этой PNG). Простая замена ImageBitmapLoader на TextureLoader при том же blob URL не объявляется гарантией CSP совместимости без проверки.

До принятия: тот же production CSP; отсутствие CSP/image-load ошибок; настоящая map с положительными размерами и UV0 в live merged renderer; shader link; совпадающая поза A/B; отдельный performance замер. Сейчас optional atlas остаётся отдельным артефактом, plain game asset не меняется.
