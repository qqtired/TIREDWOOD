# Крепость — Осада Варенья

Открой `./index.html` двойным кликом. Интернет и локальный сервер для просмотра не нужны. Это концепт новых врагов и баланса, не изменение режима игры.

- `./index.html` — автономная русская страница: референсы, описание контригры, 3D-стенд, макет выбора волн и калькулятор текущих формул.
- `./BRIEF.md` — полное предложение, художественное направление, ограничения и критерии будущей проверки.
- `art/originals/` — четыре исходных imagegen PNG без изменений; `./art/PROVENANCE.md` — промпты, SHA256 и реальные receipts.
- `models/` — Blender MCP исходники, GLB, рендеры и каталог. Состав/готовность сверять с `./models/manifest.json`; промежуточный HTML явно показывает отсутствие ещё не добавленных моделей.
- `analysis/` — исходный аудит текущего баланса: 256 фиксированных составов на случай, траектории старой модели, таблицы и предложенные правила.
- `source/` — воспроизводимая сборка страницы и узкая проверка данных/переключателей. `./data/check-receipt.json` не заменяет браузерную проверку.

Пересборка с Node 24:

```sh
/opt/homebrew/opt/node@24/bin/node source/build.mjs
/opt/homebrew/opt/node@24/bin/node source/check-report.mjs
```

Референс — образ от imagegen. Blender-рендер — снимок настоящей 3D-модели. Прототип GLB с клипами — ассет. Игровые предупреждения, урон, серверная логика и новые реальные бои пока не реализованы и не проверены.
