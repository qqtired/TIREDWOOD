# Смоливщик — один frozen контракт сцены

Root выбрал настоящий aimed pose: форма, placement, цель и стоимость сценария сохранены. Модельер владеет Blender/GLB; concept worker — адаптером сцены.

| Поле | Контракт |
|---|---|
| Placement | `[-5,0,-22]`, yaw Y=0, scale1, GLB forward +Z |
| Film target | `[-4.9,4.95,-18.8]`, плоскость z−18.8, ширина1.9м/высота1.25м |
| Pivot | nozzle pivot world≈`[-4.55,.88,-21.56]`, source local Blender `[.45,-.44,.88]` |
| Aim | От pivot, pitch≈55.65° вверх/yaw≈−7.23°. Source Z-up Euler X≈−.971/Z≈−.126. Сопло поднимается, gripTargetR/рука/гибкий шланг следуют. |
| Forward stream | Только actual nozzlePort. Направление — normalized(actual tip−actual pivot). Прямой луч до target-plane, без подмены origin/невидимой дуги и без притягивания попадания к центру. |
| Firing phase | Один настоящий attack burst с event t4, длительность по key-span GLB. Windup начинается `4−windupSpan`; реальные samples сохраняют inputStart offset. Плёнка остаётся до t17 после прекращения струи. |
| Counter | decision t5; smash .5с, redirect3с, wash4с. Фильм/slow/работа/расчётные costs не изменены ради кадра. |
| Reverse | После redirect3с — настоящий nozzle/hand/hose pose к полу `[-4.55,.05,-25.1]` внутри прежней лужи; 6с потока из actual port, затем recover. Предпочтительна наружная дуга +180° вокруг сопла, не через корпус. |

Forward burst заканчивается раньше первого counter. Поэтому wash очищает уже нанесённый слой, не сталкивается с бесконечно продолжающимся повторным окрашиванием. Residual tank pressure используется reverse counter. Это уточнение визуального цикла, не изменение mechanical deadlines или экономики.

Нативные имена и emission metadata поступают через `entry.sceneClips.pump`/`entry.sceneAim.pump`. Адаптер не рисует поток при отсутствии pose/порта. Если actual ray не попадает в film rectangle — показывает измеренное отклонение/NO-GO, а не корректирует траекторию. Статическая prototype-трубка и прежние условные origins из сцены убираются.
