# Blender model provenance

All five model construction calls were sent through `mcp__blender__execute_blender_code` in a real background Blender 5.2.2 LTS process. They were not constructed via direct Blender CLI model scripts. The process was created using `Blender -b --factory-startup` only to host the MCP transport. `./session-proof.json` was written by an MCP call before construction and records `bpy.app.background = true` and the session PID.

The installed mcp-for-blender 2.1.9 addon rejects GUI-free startup because its normal queue uses application timers. A temporary process-local bootstrap (`scripts/headless_mcp_bootstrap.py`) imports the installed addon unchanged, starts its socket listener and client handling, and drains its unchanged command queue on Blender's main thread. No installed addon, persistent preferences, connector configuration, secret or existing GUI scene was changed. The root coordinator explicitly authorised this local adapter before launch.

References were created separately via Codex CLI ImageGen; see `../art/PROVENANCE.md` and the per-character receipts. Each reference was visually inspected before its corresponding model script was executed. Character roles, palette and motion came from `../brief.md`.

`mobkit.py` is a standalone local adaptation of the game's existing `game-opus/tools/survivors/blender/mobkit.py`. It retains the established rigid-part modelling, named NLA animation and GLB export structure, while output paths and preview camera were changed for this design artifact. Existing game models and their sources were read only. The boss uses the same geometry helpers and a new real 13-bone weighted skin with 16 animation clips.

The first outputs and their original generators are retained in `v1/<id>/`. Subsequent review fixes use the current files, preserving v1. Source `.blend`, GLB, generator scripts, reference path, triangle count, animation names and background attestation are recorded in `./manifest.json`.

This is a local design artifact. Nothing was copied into game runtime files, committed, pushed or deployed. Server-side attack timing, collider size, pose baking for large crowds, gameplay balance and manual visual acceptance remain outside the Blender export proof.
