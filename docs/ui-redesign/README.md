## Что решено (сводка ответов владельца)

- Стиль: окна, меню, затемнение — «Ретро-парк 2.0» (`data-skin="retro2"`): бирюзовая эмаль, крем, коралл, заголовки Rubik Mono One.
- HUD поверх игры — вариант «Светлый» (`<html data-hud="light">`): тёплые белые плашки с тёмным текстом, без `backdrop-filter`,
  «вывесочные» надписи в HUD — Rubik 800. Единственное исключение с размытием — подложка шкалы вываживания (рыбалка, не бой).
- HUD компактный: если не окно и занимает больше 1/8 экрана — уменьшать. Панель бойца — отдельные блоки на своих подложках.
- Меню Esc и Tab — раскладку не трогать. Любимые экраны (Подземелье, блэкджек, дурак, бильярд) — только общий верх.
- Иконки — картинки imagegen без текста; эмодзи как иконки UI убираются. Сине-жёлтое вместе на флагах/лодках — нельзя.
- Звуки UI — тихие, с выключателем «Звуки интерфейса».
- Вход в игру — раскладка «карточка слева». Загрузки — чёткие на 2560×1440 (HD-картины).
- Lobster и рукописные шрифты — нет.

## Как устроено (коротко)

- Токены: у каждой шкурки пары `--w-*` (окно) и `--h-*` (HUD), `--hd-*` — шапка окна; раздаются по месту (`.k-window` — окно,
  `.k-hud` и плашки — HUD). Вариант HUD — один блок `[data-hud='light'][data-skin='retro2']` в `tokens.css`, только `--h-*`.
- Слоты HUD (`HudSlots`): `tl tr bl bc br c tcUnder`, верх-центр `tc` — в своём слое над меню. Всё в слотах масштабируется
  `zoom: var(--hud-k)` (1440×900 = 1; на 2K = 1,6). Окна — `.k-scrim` (не внутри `.k-hud`).
- Верх-центр — один менеджер `TopCenter`: плашка события по приоритету `PRIO`, до 3 тостов, крупный баннер. Уровень и жетоны —
  только в бейдже (`Badge`). Подсказок только в `title` нет — мышь в игре захвачена.
- Справочник кита для игры — [docs/ui.md](../ui.md) (образцы, токены, размеры, поведение окна, чек-лист); полная разметка — `lab/ui/kit/KIT.md`.

## Как продолжить улучшать

1. Менять вид — сначала на странице `lab/ui/` (запуск: `node docs/ui-redesign/tools/serve.mjs "$PWD/lab/ui" 9500`, открыть
   `http://localhost:9500/`), показать владельцу (выкладка через `/tech`, имя `tiredwood-ui-v2` или новое для новой версии;
   старые версии не удалять), после «да» — перенести в `client/ui/kit/` и экраны.
2. Новый вариант стиля — блок токенов в `lab/ui/kit/tokens.css` (+ карточка на странице), компоненты не трогать.
3. Новые иконки — только Codex imagegen без текста на картинке (см. icons-pipeline), затем `PROVENANCE.md`.
4. Перед правкой экрана — его сцена в `lab/ui/screens/` и опись в `inventory/`.
