- **Примерочная** (`p08-wardrobe.png`, `p09-wardrobe-hats.png`): у киоска касание «E» открывает окно снизу, 26 ячеек с картинками (37 картинок, битых 0, эмодзи нет), вкладки, «Подарочный код», «Готово». Закрывается и ✕, и «Готово» (`p10-after-wardrobe.png`).
