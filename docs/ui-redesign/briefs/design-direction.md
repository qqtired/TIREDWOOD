# Единый интерфейс TIREDWOOD — направление (черновик ведущего)

Основано на инвентаризации: inventory/A-shell.md, B-fishing.md, C-farm-fort.md, D-modes-refs.md.
Корень бед: нет общей сетки экрана (каждый режим кладёт свои плашки в одни и те же углы), нет общего набора
компонентов (17 кнопок, 10+ клавиш, 7 палитр окон), нет шкалы шрифтов (40 размеров, десятки <13px), одна и та же
информация в 3–6 местах, подсказки в title при захваченной мыши.

## 1. Принципы
1. **Сетка из 7 слотов.** Любой элемент HUD живёт в одном из слотов; углы не делят несколько систем.
2. **Один набор компонентов** (кнопка, клавиша, панель, окно, вкладки, тост, плашка события, подсказка E,
   полоса, карточка-счётчик, таблица итогов, баннер). Режимы меняют только акцент/шкурку, не устройство.
3. **Шкала шрифтов**: 14 · 16 · 18 · 22 · 28 · 36 · 48 · 72 (+ числа-герои). 13 — только третичные подписи,
   меньше 13 нет. Rubik 400/500/700/900; режимные заголовочные шрифты допускаются (Подземелье — Alegreya SC).
4. **Одна информация — в одном месте.** Уровень и жетоны — только в бейдже игрока; рюкзак — в одном счётчике;
   подсказка управления — один раз (на кнопке-клавише или в нижней подсказке, не в трёх местах).
5. **Ничего только в title.** Пояснения видны сразу или по Alt («Alt — подробнее», как пассивки Подземелья).
6. **Клавиши — колпачком на самой кнопке** (рецепт блэкджека), мышь — значком мыши.
7. **Картинки, а не эмодзи** в HUD и окнах: общий набор imagegen-иконок «нарисованный предмет без рамки»
   (как иконки фермы и лавки рыбака), медальоны — только у Подземелья.
8. **Свои — золотом** (ход, строка, ставка, рекорд). Красный — только опасность/ошибка.
9. **Важный момент — праздник**: баннер-герой со ступенчатой тенью (рецепт блэкджека), звук, вспышка.

## 2. Слоты экрана (десктоп 1280–1600, поля 16–20px)
| Слот | Что живёт | Сейчас там бардак |
|---|---|---|
| ВЛ «Режим» | статус режима: уровень фермы, мини-карта+волна крепости, место в гонке, рыбалка: сезон/событие | regatta/race stand, fort map, farm 430px стена |
| ВЦ «Событие» | ОДНА плашка события с очередью (волна/босс, шторм, пираты, таймер аквапарка, голосование кика, рулетка) + под ней тосты | 8 систем на y 14–150 |
| ВП «Игрок» | бейдж игрока: кольцо уровня с XP + жетоны (+N); под ним колонка контекста ≤3 карточек (напиток, рюкзак/лайвел, лодка, ставка крыс) | жетоны + 4 системы на y 62–76 |
| НЛ «Связь» | чат + голос одним доком (кнопка голоса прилеплена к чату) | чат и голос касаются |
| НЦ «Действие» | подсказка E (одна) / панель действий режима (здоровье+патроны, кнопки стола) | hint/ask/chip/storm button стопкой |
| НП «Улов/Инструмент» | карточка улова, патроны, оружие, эмоции | catch card vs boat buttons vs radio |
| Центр | баннер-герой (30–34% высоты), прицел, шкала вываживания (справа от центра) | ok |

## 3. Компоненты (общий CSS client/ui/kit/*.css, классы `.k-*`)
panel, window (шапка: портрет-иконка, eyebrow, заголовок, баланс, закрыть [Esc]), tabs, button (gold primary,
green go, red stop, periwinkle special, ghost), keycap, chip/pill, meter (с «следом»), stat-card (иконка+число+полоса),
toast (info/reward/warn с иконкой), event-plate, prompt, hero-banner, results (таблица, своя строка золотом,
кнопки «Ещё раз»/«На набережную»), countdown, switch/seg/slider.

## 4. Три шкурки для выбора на странице
- **A «Вечерняя веранда»**: тёплое тёмное стекло rgba(34,24,29,.9), кремовый текст, одно золото, кнопки-«конфеты».
  Продолжение блэкджека/дурака — самое читаемое поверх яркой сцены.
- **B «Курортная открытка»**: кремовая бумага #fff6e6, чернильный текст, терракота и морская бирюза, мягкие тени,
  тонкая рамка-«зубчик». Под солнечный городок; проверить читаемость поверх неба.
- **C «Ретро-парк»**: эмалевые вывески (вишня/бирюза/сливки), полосатая маркиза в шапке окон, рамка из точек-лампочек
  у важных плашек, крупные «вывесочные» заголовки. Под набережную 3а+в (южный городок + ретро-парк аттракционов).
Набережная выбрана 3а+в: южный курортный городок (светлая штукатурка, терракота, зелёные ставни, полосатые маркизы,
кипарисы) + ретро-парк (павильоны с лампочками). Таблички набережной (5а) берут шрифт и рамки нового UI.
Fight Club удаляется из игры (тред набережной) — не редизайним.
Режимные надстройки поверх любой: Подземелье (свой фонарь), крепость (дерево ворот), рыбалка (морская карта),
ферма (зелень грядки) — только акцентный цвет и рамка.

## 5. Страница-обзор lab/ui/index.html
Переключатель шкурок A/B/C (без липкого меню и прыжков), «было/стало» на каждом экране (as-is снимки),
мокапы на чистых фонах игры (bg-*.png): площадь (HUD, чат, Tab), меню Esc, рыбалка (подход, ожидание,
вываживание, улов), журнал, Семён, ферма (HUD + посадка без модалки), крепость (бой, прилавок, итоги),
общий экран итогов, загрузка; витрина компонентов; иконки; тихие звуки с выключателем.
