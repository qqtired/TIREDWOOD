## Твои файлы
Только `lab/ui/screens/<группа>.js`, `lab/ui/screens/<группа>.css` и картинки в `lab/ui/img/<группа>/`.
Чужие файлы, kit/*, page/*, index.html — не трогай. Нужен новый общий компонент или правка кита — напиши ведущему
(SendMessage to "main") одной строкой, что и зачем; до ответа сделай локально в своём css с префиксом группы.

## Как рисовать
- Каждый экран — сцена 1440×900 через stage-хелпер из page.js, фон — чистый кадр игры без интерфейса
  (`asis/bg-*.png`, см. `asis/INDEX.md`; копируй сжатым в `lab/ui/img/<группа>/`), «Было» — снимок как сейчас (`asis/NN-*.png`).
- Над сценой: заголовок экрана и 1–2 строки «что поменялось» человеческим языком (для владельца, не для программиста).
- Только компоненты кита и токены — так все три шкурки работают сами. Проверь каждый экран во всех трёх шкурках.
- Слоты из KIT.md соблюдай точно. В одном углу — одна система.
- Тексты, числа, названия — настоящие из игры (ищи в client/ и shared/). Механик не выдумывай; если редизайн требует
  новой мелочи интерфейса (например, видимой легенды врагов вместо всплывающей подсказки) — можно, и отметь в
  подписи «новое».
- Иконки — `client/assets/ui/icons/*.webp` (рисуются сейчас; что уже есть — смотри папку), плюс существующие
  `client/assets/{farm/icons,fishshop,fort,rods,fish,ownboats,dungeon/icons}`. Копируй нужные в `lab/ui/img/icons/`
  (если файла там ещё нет). Эмодзи — только временная заглушка.
- Интерактив, где это помогает понять: кнопки состояний сцены («ждёшь поклёвку / вываживание / улов»), вкладки окон
  переключаются, кнопки дают тихий звук через kit/sfx.js. Без анимаций каждый кадр, без прыжков страницы.

## Проверка и нагрузка Mac
- Headless Chrome — только по очереди со всеми: перед запуском захвати замок `mkdir <scratchpad>/ui/chrome.lock`
  (не вышло — подожди 30 с и повтори), после закрытия своего Chrome — `rmdir` замка. Свой профиль, свой порт отладки
  (дан в задании), закрывать только свой PID, Chrome по имени не убивать. Страницу открывай через свой статический
  сервер на своём порту (дан в задании) или file://.
- Снимки каждой своей сцены в трёх шкурках — в `<scratchpad>/ui/shots/<группа>/`, посмотри их сам и поправь
  наложения, мелкий текст, слабый контраст.
- Не коммить, npm не ставь, python3 не запускай, mcp__hearthbot__ не вызывай.
