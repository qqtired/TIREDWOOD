# Бриф: страница-обзор нового интерфейса TIREDWOOD (lab/ui/)

Общий для всех помощников, которые строят страницу. Читать целиком.

## Что это и для кого
TIREDWOOD — браузерная 3D-игра для компании друзей владельца (Роман, CarGuru): приморский курортный городок,
желейки, набережная, рыбалка, ферма, крепость (оборона от зомби), картинг, пейнтбол, прятки, регата, пираты,
«Выше облаков», карточные столы, бильярд, «Подземелье». Владелец попросил переделать ВЕСЬ экранный интерфейс
(HUD, панели, окна, чаты) в единый красивый, продуктово-игровой вид: «понятный, красивый, чёткий, логичный и интересный».
Сейчас: 7 разных палитр окон, ~17 видов кнопок, 10+ видов клавиш, ~40 размеров шрифта (много 10–12px), одна
информация в 3–6 местах, в углах экрана налезают плашки разных систем.

Перед внедрением в игру владелец смотрит интерактивную красивую страницу и выбирает стиль. Эту страницу мы и строим:
`/Users/tired/Desktop/game-opus-ui/lab/ui/` (git worktree, ветка mode/ui). Потом её выложат на tired.solutions/tech.

Ответы владельца: один большой патч на всё; показать РАЗНЫЕ варианты стиля (три); крепость переделать целиком;
все остальные режимы тоже в этом заходе; блэкджек, дурак, бильярд и «Подземелье» по виду не трогаем (только общее —
шрифт, кнопки, верхняя панель); тихие звуки интерфейса с выключателем. Fight Club удаляется из игры — его не рисуем.

## Что владелец любит (эталон качества)
- Интерфейс блэкджека/дурака/бильярда: одна тёплая тёмная панель + одно золото (= «твой ход/твоё»), кнопки-«конфеты»
  (градиент + сплошная тень снизу `0 5px 0 <тёмный>` + внутренний блик сверху, нажатие = сдвиг вниз), цвет кнопки =
  смысл (зелёная — да/вперёд, красная — стоп, золотая — подтвердить, барвинковая — особое), клавиша колпачком прямо
  на углу кнопки, крупный герой-текст со ступенчатой тенью, центр экрана свободен.
- «Подземелье» «Кованый фонарь»: железо+латунь, заклёпки, медальоны-иконки, Alegreya SC в заголовках.
- Иконки, нарисованные imagegen (предмет в 3/4, тонкий тёмно-коричневый контур, тёплый свет слева сверху,
  прозрачный фон): `client/assets/farm/icons/*.png`, `client/assets/fishshop/*.webp`, `client/assets/fort/*.webp`,
  `client/assets/rods/*`, `client/assets/fish/*.webp`, `client/assets/dungeon/icons/*.webp` (медальоны).
- Владелец НЕ любит: мелкие перегруженные HUD, наложение текста, мелкие подписи. Хочет большие читаемые карточки
  с картинками-иконками и минимум подписей.

Набережная параллельно переделывается в стиле «южный курортный городок (светлая штукатурка, терракотовая черепица,
зелёные ставни, полосатые маркизы, кипарисы) + ретро-парк аттракционов (павильоны с лампочками)». Вывески набережной
возьмут шрифт и рамки нового UI.

## Правила интерфейса (обязательны для каждого мокапа)
1. **Сетка из 7 слотов** (десктоп 1440×900, поля 18–20px):
   - ВЛ «Режим» — статус режима (уровень фермы; мини-карта крепости; место в гонке; сезон/событие рыбалки);
   - ВЦ «Событие» — ОДНА плашка события за раз (волна/босс, шторм, пираты, таймер аквапарка, голосование, рулетка),
     под ней тосты (максимум 3);
   - ВП «Игрок» — бейдж игрока: кольцо уровня с прогрессом опыта + жетоны (+N всплывает); под бейджем колонка
     контекста ≤3 карточек (напиток, рюкзак, лодка, ставка);
   - НЛ «Связь» — чат и голос одним доком (кнопка голоса прилеплена к чату);
   - НЦ «Действие» — подсказка «E — …» (одна) или панель действий режима;
   - НП «Улов/Инструмент» — карточка улова, патроны/оружие, эмоции;
   - Центр — баннер-герой на 30–34% высоты, прицел, шкала вываживания.
2. **Шрифты**: Rubik (400/500/700/900) для всего текста. Шкала: 14 · 16 · 18 · 22 · 28 · 36 · 48 · 72. 13px — только
   третичные подписи. Меньше 13px — нельзя. Цифры — tabular-nums. Шкурке можно дать свой заголовочный шрифт с кириллицей.
3. **Одна информация — в одном месте.** Уровень и жетоны — только в бейдже игрока.
4. **Ничего только во всплывающей подсказке (title)** — мышь в игре захвачена. Пояснения видны сразу или по «Alt — подробнее».
5. **Клавиши** — один компонент-колпачок, прикреплённый к углу кнопки/карточки; мышь — значок мыши.
6. **Иконки-картинки, не эмодзи.** Новые иконки рисуются сейчас в `client/assets/ui/icons/` (см. ниже);
   пока их нет — бери существующие из папок выше; эмодзи — только как временная заглушка с пометкой в коде.
7. **Своё — золотом**, опасность — красным, награда — золото/мята, инфо — нейтральный.
8. **Тексты** — по-русски, на «ты», коротко, тепло, от лица игрока («Ты поймал…», «Твой рекорд»). Без программистских
   слов. Числа и названия бери из игры (файлы клиента/shared), не выдумывай механик.
9. Цвета категорий рыбы — СОХРАНИТЬ как есть: `shared/fishrules.ts:104-110` (`TIER_CSS`). Шкала вываживания
   и её темы (`client/ui/fishstyle.css`) — игровое поле, их вид не меняем, только окружение.
10. Без сине-жёлтых сочетаний на флагах/вымпелах/лодках.

## Три шкурки (переключаются атрибутом `data-skin` на <html>)
Все экраны строятся ТОЛЬКО из компонентов кита и токенов, поэтому шкурка меняет вид всего сразу.
- `veranda` — **«Вечерняя веранда»**: тёплое тёмное стекло rgba(34,24,29,.9), кремовый текст #fff3de, одно золото #ffd35a,
  кнопки-«конфеты». Продолжение блэкджека/дурака, самое читаемое поверх яркой сцены.
- `postcard` — **«Курортная открытка»**: светлые карточки цвета штукатурки/сливок, чернильный текст #2a1f24, акценты
  терракота и зелень ставен, морская бирюза для инфо; мягкая тень и чёткая тёмная кромка, чтобы читалось поверх неба.
- `retro` — **«Ретро-парк»**: эмалевые вывески (вишня/бирюза/сливки), полосатая маркиза в шапке окон, рамка из
  точек-лампочек у важных плашек (событие, баннер, рекорд), крупные «вывесочные» заголовки.
Шкурки должны быть РАЗНЫМИ на вид, а не перекраской. Режимные акценты поверх любой шкурки допустимы через
`data-mode` (рыбалка — морская бирюза, ферма — зелень, крепость — дерево/кирпич, гонки — шашечки).

## Устройство страницы (файлы)
- `lab/ui/index.html` — страница: шапка, выбор шкурки (3 большие карточки), разделы.
- `lab/ui/kit/tokens.css` — токены трёх шкурок (`:root[data-skin=...]`).
- `lab/ui/kit/kit.css` — компоненты, классы `.k-*`, только через токены. Этот CSS потом переносится в игру — пиши
  его чисто, без зависимостей от страницы.
- `lab/ui/kit/sfx.js` — тихие звуки интерфейса на WebAudio (клик, открыть, закрыть, награда, ошибка, тост), громкость
  низкая, выключатель на странице (по умолчанию включено, но звук только после первого клика пользователя).
- `lab/ui/page/page.css`, `lab/ui/page/page.js` — оформление самой страницы, масштаб «сцен», переключатели.
- `lab/ui/screens/<группа>.js` + `.css` — мокапы экранов группы (каждая группа — свой файл, чужие не трогать).
- `lab/ui/img/` — фоны, снимки «было», иконки для страницы (копии, сжатые в webp/jpg).

## Правила страницы
- Красиво и интерактивно, но спокойно: никакого липкого меню, которое прыгает; никаких изменений раскладки каждый кадр.
- Работает с телефона (не ломается), основная проверка — десктоп 1440.
- Внешние скрипты нельзя; шрифты — локальные копии woff2 в `lab/ui/fonts/` (Rubik из
  `node_modules/@fontsource/rubik/files/`, Alegreya из `@fontsource/alegreya-sc`/`alegreya-sans`), либо Google Fonts
  ссылкой для шрифта, которого нет в node_modules (тогда отметь в отчёте, что для игры его надо будет поставить).
- Размер всей страницы — разумный (картинки webp/jpg, фоны ≤250 КБ каждый).
- Проверка: один headless Chrome (свой профиль и свой порт отладки, закрыть по своему PID, никогда не убивать Chrome по
  имени), снимки 1440×900 каждой шкурки. Страницу открывать через `file://` или свой маленький статический сервер
  на порту 3116 (только свой порт). Игровой сервер 3106 не трогать.
- python3 на этой машине сломан — только node. Новые npm-пакеты не ставить. Удалять — только в ~/.Trash.
- Не коммитить: ведущий сам коммитит. Не вызывать инструменты mcp__hearthbot__.
