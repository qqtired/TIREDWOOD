# 2. КРЕПОСТЬ (client/fort)
---------------------------------------------------------------------------------------------------

3. Шесть каналов сообщений (баннер, тост, тревога, подсказка у стойки, коуч, «новый враг»/карточка) с разными местами и стилями; тревоги-предложения на 90 символов в nowrap-пилюле.
4. Много мелкого текста <13px: 9–12.5 (ступени, футер прилавка, справка управления, карточка волны, подписи стрелок/частей босса/таблицы итогов, «РЕКОРД» 10.5).
5. Подсказки/легенда (фишки врагов, ступени укрепления, «Орда на N») лежат в `title` → при захвате мыши недоступны.
6. Дубли: золото (полоса, прилавок, состав, Tab, итоги), HP ворот/кристалла (полоса, подсказка, 3D-метка, подзаголовок прилавка, карта), волна (полоса, карточка, баннер), команда (состав + Tab).
7. Две валюты рядом (золото матча vs жетоны) с похожими монетами.
8. Левая колонка перегружена (карта, состав, «новый враг», коуч, чат, здоровье, голос); низ-право — стволы, патроны и прилавок конфликтуют.
9. Итоги без кнопок и без явного «что дальше»; `Tab`-таблица заменяет общий «кто где».
10. Эмодзи как иконки в тревогах/баннерах вперемешку с 15 webp.
