## 1.5 What the owner likes — distilled (target quality bar)
1. **One surface language per mode**: dark warm plate (panel-strong .88 / iron), thin warm hairline, generous radius (18-24, dungeon 8 + rivets), soft long shadow; text cream, never pure white.
2. **One accent = state**: gold border + glow (+ pulse) means "your turn / act now" everywhere; secondary status via a single coloured element (ring, strip, bar) never 3 indicators at once.
3. **Tactile buttons**: gradient + solid under-shadow (`0 5px 0`) + inset highlight, press = translateY; colour = meaning (green go, red stop, gold commit, periwinkle special). Dungeon's iron/brass variant is the same idea in metal.
4. **Key caps attached to the control** (corner badge), small dark capsule, never a separate legend only (bl adds a legend row too).
5. **Real art over emoji** where it matters: card atlas, ball WebP, CSS chips, medallion icons; emoji only as secondary glyphs.
6. **Hierarchy by size/weight**: hero 36-96/900 with stepped hard shadow (or brass clip-text), status 16-24/800, meta 12-14 only for secondary facts; tabular numerals.
7. **Layout discipline**: top strip (who/what) + one bottom bar (me | what to do | balance & leave) + hero text at ~34% height; the middle of the screen stays free for 3D.
8. **Short springy motion** (`cubic-bezier(.2,.9,.3,1.15/1.6)`), reduced-motion honoured, explicit `max-height:700/480` + `max-width:780` tiers.
