## 9. Главные проблемы для редизайна
1. **Семь «семей» окон и кнопок**: кофе-панель `--panel-strong` (журнал, карточка, плашки, чипы), зелёная #25302a (рюкзак, рулетка), кофе-диалог #2b1f26 (Семён/лодки), зелёная #2b3129 (крысы), rgba-зелёные (плашка крыс, плашка рулетки), «золотая» #c9a36a с градиентом (радио), хардкод rgba(30,22,26)/rgba(20,26,22) (`fh-chip`, `fe-reelbonus`). Кнопок 4 языка (кремовая «клавиша», зелёная #45604d, оранжевый градиент, мята/голубая), вкладок 3 стиля (золотые пилюли, зелёные `fe-booktab`, `fe-tab`), клавиш kbd 3 версии (`kbd`, `.br-key`, `.rr-pKeys kbd`), крестиков 4 (`fb-x` круг, `fn-close`/`rr-close` квадрат, `br-x`).
2. **Углы переполнены**: верх-право (жетоны + напиток + 7-плашечная колонка + в тех же координатах 62–76px `ob-nav`/`rr-panel`/`rg-list`); низ-право (карточка улова vs `ob-side` vs радио); шкала и колонка почти касаются.
3. **Дубли информации**: подсказка шкалы (низ + `fr-hint` + «Прекратить [X]»), оценка (шкала + карточка), уровень (колонка, журнал ×2, Семён, профиль, тост), сезон/дождь (тост, плашка, 3D-вывески, Семён, заголовок «Шансов», журнал), рюкзак (чип, окно, «Продать», карточка, подсказка), коллекция «N из 52» (кнопка, карточка, журнал, профиль, доска), бонусы снасти/баркаса (`fe-gear`, `reelbonus`, `odds-why`, `fe-why`).
4. **Мелкие шрифты (<13px)** почти везде: `fe-reelbonus` 11, `fe-odds-why` 10.5, легенда шансов 11, плашка-подпись 11.5, перк уровня 11.5, чипы/снасть 12, `fr-quit` 12 (kbd 10), `fb-*` 11–12.5, `frw-*` 11–12, eyebrow/подвал диалога 10–12, `ob-*` 11.5–12.5, `rr-*` 11–12.5, `br-*` 11–12; на таче 10–12.
5. **Остров выпадает из системы**: нет плашки тумана/сезона в HUD; «Шансы сейчас» на острове называются «🌧 дождь» / «🎣 сезон рыбалки»; `fr-rain` привязан к дождю, не туману; журнал называется «Журнал рыбака» и при счёте «Остров: N из 20».
6. **Что нельзя «унифицировать»**: шкала, её темы и оверлеи способностей — игровое поле/контент; категории и оценки (§7) — смысловые токены.
7. **Неэкранное**: доски/подиум/вывески/табло — canvas, шрифты 13–72px в текстуре, цвета зашиты (#1f4a5e, #30473f, #192f27); `boatbanner.ts` сине-жёлтый.
8. **Мёртвый код под удаление после снятия старой рыбалки**: `.fs-card/.fs-btn/.fs-bar/.fs-auto`, `alb-*`, `RARITY_CSS`, `FishHud` (кроме пилюли «Подсекай!»), `fishart.ts` canvas-иконки.
