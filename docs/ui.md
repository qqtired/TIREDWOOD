# Интерфейс TIREDWOOD — как делать окна, HUD и тексты

Для всех помощников, особенно для Codex. Читай перед любой работой с интерфейсом. Общий стиль и тексты —
в [product.md](product.md) §6, правила — в [AGENTS.md](../AGENTS.md). Если расходится, прав `AGENTS.md`.

Главное правило: **своё оформление с нуля не придумывай.** Общего компонента «окно» в игре нет — есть общие
переменные стиля, общие мелкие детали и удачные окна-образцы. Новое окно — копия ближайшего образца
с его классами, размерами и поведением, но со своим префиксом CSS.

## 1. Найди образец — до кода

| Что делаешь | Образец | Что взять |
|---|---|---|
| HUD игрового стола или режима поверх 3D | блэкджек: `client/lobby/blackjackhud.ts`, `blackjack.css`, ставки — `bjbet.ts` | полоса снизу `.bj-bar`, плашки сверху `.bj-strip`, баннер итога `.bj-banner`, кнопки действий с клавишей, фишки ставок |
| Окно у предмета в мире (подошёл — открыл) | музыкальный автомат: `client/ui/jukebox.ts`, `jukebox.css` | карточка по центру, заголовок + ✕, список, подсказки клавиш внизу, закрытие при уходе |
| Большое окно с вкладками: NPC, магазин, коллекция | `client/lobby/fishnpcdialog.ts` (стили `.fe-npc` в `fisheco.css`); помощники `el`, `btn`, `icon` — `client/farm/ui/common.ts` | нативный `<dialog>`, ✕ + кнопка «Закрыть», Esc, клик мимо, вкладки-«таблетки» |
| Настройки, ползунки, переключатели | меню Esc: `client/ui/menu/settings-panel.ts`, голос — `client/ui/voicepanel.ts` | строки `.set-item`, ползунок, `.sw`, выбор `.seg` |
| Подтверждение «Точно?» | `.bj-dialog` в блэкджеке | нативный `<dialog>`, «Остаться» зелёная, опасное действие красное |
| Короткое сообщение | `Toasts.show(text, ms, key, sub, big)` — `client/ui/toasts.ts` | не больше 4, `key` заменяет старый тост того же вида |
| Жетоны 🪙 в тексте | `client/ui/coin.ts`: `COIN_HTML`, `setCoinText`, `appendCoinText` | эмодзи 🪙 нет на старой Windows — только эти функции |
| Баланс, +N / −N | `TokensHud` — `client/ui/tokens.ts` | |
| Обычные кнопки | `.btn`, `.btn.primary`, `.btn.ghost` — `client/styles.css` | |
| Цвета редкости и уровней | `client/ui/fishstyle.css`, `shared/fishstyle.ts` | новые цвета редкости не придумывай |
| Кнопки на телефоне | `client/touch.ts` (`PADS`, `TouchMode`) | |

Открой образец в игре, сделай снимок и держи его рядом: новое окно должно выглядеть как его родственник.

## 2. Стиль — только общие переменные

Переменные — в `:root` файла `client/styles.css`. Новые цвета в коде не пиши, бери эти:

- фон панелей — `--panel`, плотнее — `--panel-strong`; рамка — `--line`; тень — `--shadow`; скругление — `--radius`;
- текст — `--cream`, `--cream-2`, `--cream-dim`; тёмный — `--ink`;
- акценты — `--orange` (главная кнопка), `--gold` (своё и награды), `--mint` (хорошо), `--jam` (плохо, опасно),
  `--blue`, `--sea`, `--steel`.

Шрифт — **Rubik**, другой не подключай. Заголовки и числа — жирные (700–900), у чисел
`font-variant-numeric: tabular-nums`. Без `backdrop-filter` (дорого для кадра), без неона и стекла.

## 3. Размеры — крупно

- Ориентир — экран 1280×800: всё читается без наклона к монитору.
- Основной текст — от 15 px, подписи — не меньше 13 px, заголовки окна — от 22 px, итог — крупный баннер,
  как `.bj-banner`.
- Кнопка действия — от 44 px в высоту, лучше как в блэкджеке: 112×58. ✕ — 38×38.
- Ширина окна — `min(<ширина>, 100vw - 24px)`, высота — не больше `100vh - 24px`, внутри прокрутка.
- Ничего не налезает на другие панели: проверь вместе с чатом, балансом, тостами и голосом.

## 4. Поведение окна — обязательно

- **Закрытие тремя способами:** Esc, ✕ (`title="Закрыть (Esc)"`, `aria-label="Закрыть"`) и, для окон по центру,
  клик мимо карточки. Окно у предмета закрывается, когда игрок отошёл. Внутри идёт раунд — Esc сначала спрашивает
  «Встать из-за стола?», как блэкджек.
- **Подключи окно к сцене** (`client/lobby/scene.ts`): добавь его в `wantsPointer` (иначе мышь не освободится),
  в `touchMode` — `'none'`, модальное — в `syncMenu` и `voiceBlocked`. Клавиши — через `onKey`, который
  возвращает `true`, если клавиша обработана.
- **Окно не пропускает ввод в игру:** глушит WASD и E, останавливает `mousedown`, `pointerdown`, `wheel`.
  На кнопках `mousedown` → `preventDefault`, чтобы клик не забирал фокус клавиатуры.
- **Слои:** HUD стола — 32, окно по центру — 33–34, подтверждения — 60–70. Проще — нативный `<dialog>`.
- **Ждём сервер:** кнопки заблокированы до ответа; через 5 с — «Ждём подтверждение сервера…»; ошибка — красной
  строкой, сама исчезает.
- **Текст — только через `textContent`.** Чужой текст (ники, чат) в `innerHTML` не вставляй.
- Окно обновляется не чаще нескольких раз в секунду и меняет только изменившийся текст.

## 5. Тексты и подача

- По-русски, на «ты», от лица игрока: «Ты выиграл 180 🪙!», «Твой рекорд!». Без английских и программистских слов:
  не «Production», «P1», «TTL», «Snapshot», «Submit», «Error».
- Кнопка говорит, что произойдёт: «Поставить», «Забросить», «Встать». Не «Проверить», «ОК», «Действие».
- **Одна информация — в одном месте.** Счёт, таймер или ставка показаны один раз.
- **Своё — золотом:** своя ставка, своя строка в таблице, свой рекорд.
- Клавиши — значком `kbd` на углу кнопки (`E`, `Esc`, `1–4`), не текстом в скобках.
- Правила режима — три строки с картинками за круглой кнопкой «?», как в блэкджеке. Причина запрета — прямо
  на кнопке: «Нужен 3-й уровень».
- Без надписей, вводящих в заблуждение: «Победа» — только когда игрок правда победил.

## 6. Режим: что игрок видит всегда

- **Цель** — одной строкой сверху: «Продержись 5 волн», «Найди 3 прячущихся».
- **Прогресс** — счёт, время, волна.
- **Отклик на каждое действие** — звук, вспышка, цифра, строка. Действие без отклика игрок считает багом.
- **Итог** — карточка результата с местами, наградой в 🪙 и кнопкой «Ещё раз».
- **Нет заглушек.** Коробка вместо корабля, ящики вместо лодок, чёрный экран ожидания — в игру не идут.

## 7. Чему научили прошлые ошибки

- **Пираты, первая версия** (переделана 04.10): корабль — коробка, ползущая по прямой; лодки — ящики на берегу;
  одна кнопка без отклика; ядро улетало в никуда; цели и прогресса не видно. Плашки налезали друг на друга,
  слово «Жетоны» было сокращено.
- **Прятки, первая версия** (переделана полностью): негде прятаться, перебор всех предметов выгоднее игры,
  20 с чёрного экрана, кнопка «Проверить», нет счёта и итогов, предмет просто исчезал без отклика.
- **Катера, полоса препятствий, животные** — отклонены владельцем по качеству картинки и переделаны.

Вывод: сначала сделай, чтобы было **понятно и приятно**, и только потом добавляй функции.

## 8. Чек-лист перед сдачей интерфейса

Сделай снимок в headless Chrome на 1280×800 и сам посмотри на него. Отметь каждый пункт:

1. Рядом со снимком образца окно выглядит как родственник: те же цвета, шрифт, скругления, кнопки.
2. Ничего не налезает и не обрезано, в том числе с чатом, балансом и тостами.
3. Текст читается без увеличения, нет английских и технических слов.
4. Каждая информация показана один раз; своё выделено золотом.
5. Окно открывается и закрывается мышью: ✕, клик мимо; и клавишами: Esc.
6. Пока окно открыто, игрок не ходит и не стреляет; после закрытия управление сразу возвращается.
7. У каждого действия есть отклик; ожидание сервера видно.
8. На телефоне окно хотя бы открывается и закрывается.
