# Новая набережная (plaza3) — вход для следующего агента

Полный редизайн площади TIREDWOOD: суша ×2, центральная площадь «Роза ветров» и кварталы, у каждого режима своё
здание-павильон, вывески «Ретро-парк 2.0» с живым статусом, 17 жителей у входов, аркада из трёх мини-игр, порт B
«Маячный мол». Всё — за флагом сервера `PLAZA3` (только явная `1`, даже в `npm run dev`); без флага площадь та же,
что раньше (`test/plaza-legacy.test.ts` — отпечаток старой площади).

## История
- 10.10.2026 — вопросы владельцу и его ответы 1а…9а: ×2,5 площади, площадь + кварталы, южный курорт + ретро-парк,
  павильон у каждого режима, вывеска «иконка + название + живой статус», ~15 жителей заново в Blender, аркада,
  дорога на ферму под аркой «Огороды», всё за флагом и выпуск целиком. Fight Club удалён из игры совсем.
- 10–11.10 — концепты и страница-обзор https://tired.solutions/tech/tiredwood-plaza/ (`lab/plaza3/`); владелец выбрал
  порт B «Маячный мол», шрифт вывесок Rubik Mono One, аркада 1а/2а/3а (медали + рекорд, до 150 🪙 в день; по 2 автомата
  каждой игры).
- 11.10 — код пакетами WP0–WP14 (`tech-foundation.md` §6), бюджет WP13, правки после прогулки владельца по 3105:
  полы без мерцания, текстуры земли из imagegen, дальность прорисовки, Лавка Семёна на помосте у сходней мола,
  ножки и стулья карточной веранды. 11.10 по «вливай в main» — слито в `main`, протокол 17. На сайте пока нет.

## Решения владельца — не менять без спроса
- Нравится и сохранено: автоматы, бильярд, аквапарк, «Рекорды рыбаков», «Крупнейшие рыбы сегодня» (витриной на виду),
  маяк с помостом и местами ловли, вход в Подземелье, музыкальный автомат, карточные столы, батуты, надпись TIREDWOOD
  видна со спавна, Бочка и Капитан.
- Памятника на площади больше нет; его файлы и счёт не удалять (`AGENTS.md` §11).
- Модели v1 не перезаписывать: снимок `../concepts_blender/plaza3/v1-2026-10-11/` (только чтение), правки — v2,
  список v2 — `client/assets/plaza3/SOURCE.md`.

## Где что лежит
- Данные: `docs/plaza3/level/layout.json` → `node docs/plaza3/level/check.mjs && node tools/plaza3/layout.mjs` →
  `shared/plaza3/layout.ts`. Твёрдое моделей — `node tools/plaza3/cols.mjs [--write]`, места вывесок —
  `node tools/plaza3/signs.mjs [--write]`.
- Клиент: `client/lobby/plaza3/` — `world.ts` (блокаут), `floor.ts` (высоты слоёв земли и наклеек), `ground.ts`
  (текстуры земли), `pavilions.ts`/`pavdata.ts` (модели), `signs.ts`, `npc.ts`/`npcdata.ts`, `arcade/`, `perf.ts`
  (бюджет), `lights.ts`. Карта всех систем — строки «Новая набережная…» в `docs/README.md`.
- Исходники моделей, бриф и заметки ведущего — `../concepts_blender/plaza3/` (`BRIEF.md`, `BRIEF-CODE.md`,
  `LEAD-NOTES.md`).

## Бюджет
79 программ из 80 и до ~282 отрисовок из 300 с высоты глаз (самый тяжёлый вид — порт с юга). Любой новый модуль
на площади мерить (`?debug` → `__opus.info()`), игровое помечать `userData.p3keep`, наклейки поднимать `DECAL_LIFT`.

## Что улучшить дальше
- Доска сезона у Лавки Семёна торчит над коньком крыши — нужна v2 `pav_semyon` с полем ниже.
- Вывески сезона (`seasonsign.ts`) собирают 2 программы при первом показе — прогреть или дать общий шейдер.
- Контактные тени зверей (`city-critters`) лежат под землёй plaza3.
- Выкладка с `PLAZA3=1` — только по «да» владельца, вместе с CSP-проверкой боевой сборки.
