# Набережная: правки по прогулке владельца 11.10.2026

Рабочий бриф пакета. Основание — пять замечаний и снимков владельца, затем уточнение о старой звезде и плитке. Позже владелец прямо поручил влить UI 2.0 из `mode/ui`, коммит `ebc1edb`; итоговая проверка проводится совместно с ним. Выкладка в этот запрос не входит.

## Результат для игрока

1. Между аркой «Огороды» и мельницей — простые грядки и повторно используемые подсолнухи. Гора за TIREDWOOD имеет цельный силуэт, надпись сдвинута левее; дома не врезаются в склон.
2. Публичные покрытия согласованы по рисунку и масштабу, без случайных резких наложений. Уточнение владельца по снимку старой площади: **«нужно перенести эту звезду обязательно и плитку»** — переиспользовать прежнюю мозаичную розу ветров и мелкую прямоугольную плитку, не заменять их новым рисунком. **Сохранить понравившуюся дорогу по мосту до маяка.** Участок после маяка до Лавки Семёна получает спокойное каменное покрытие.
3. Все отдельные столбы со стрелками удалены. Вывески зданий и функциональные доски остаются.
4. Доска рекордов Подземелья ближе к скалам и левее зева. Внутри входа нет светлых/прозрачных прорех, вход в режим работает.
5. Крепость: изначально закрытые ворота плавно открываются, когда игрок встаёт на увеличенный круг; эталон — картинг. Мерцание входа устранено. Нижние таблички-инструкции у крепости и пейнтбола удалены; вход пейнтбола расширен.

## Разделение работы

- Ландшафт: `client/lobby/world.ts`, отдельный модуль огородного декора.
- Покрытия: `client/lobby/plaza3/ground.ts`, `world.ts`, модуль покрытия мола и текстура с происхождением.
- Входы: `client/lobby/plaza3/pavilions.ts`, стартовые зоны, v2 моделей крепости/пейнтбола.
- Подземелье: модуль входа, v2 геометрии/якорей.
- Ведущий: `docs/plaza3/level/layout.json`, генерация `shared/plaza3/layout.ts`, подключения в общие файлы, приёмка общего результата.

## Проверка и границы

- Правки площади не меняют прежнюю раскладку, прогресс игроков и игровые правила; UI 2.0 включён отдельной принятой веткой. Исходники v1 не перезаписывать.
- Новая логика — узкие тесты; перед сдачей один общий `npm run check && npm test && npm run build`.
- Собранная игра, headless Chrome 1440×900: маршрут по всем изменённым местам, входы мышью/клавишами, открытие крепости своим и другим игроком, нагрузка в тех же точках до/после. Короткая проверка запуска телефона; CSP по релизному сценарию.
- Ориентиры: ≤300 отрисовок, ≤80 программ; однотипный декор общими геометриями/инстансами. Любые превышения или непроверенные границы перечислить при сдаче.
- Откат: вернуть только этот пакет локальных изменений; серверные данные и боевые флаги не затрагиваются.

Статус: в работе. Свежие результаты проверок добавляются после интеграции, без переноса старых цифр как новых.

Для команд в Codex worktree явно использовать Node 24: `PATH=/opt/homebrew/opt/node@24/bin:$PATH`. В этой сессии обычный `node` в worktree выбирал Node 22, из-за чего четыре теста сохранения отменялись; в основной папке Node 24 проходит те же тесты без изменения кода.
