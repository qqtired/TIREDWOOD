# Крепость: новые башни на стенах — план агента `fort-turrets`

**Статус:** готово. Ветка `rework/fort-turrets` (от `rework/arsenal` на `a9a91eb`), копия `game-opus-wt/fort-turrets`.
Проверки: `npm run check`, `npm test`, `npm run build` — зелёные. Снимки — `game-opus-wt/shots/fort-turrets/`.

## Зачем
Владелец: «Пушечки как-то херово выглядят». Башни арсенала (баллиста, пушка, смоляной котёл, жаровня) были
палочками на табуретках: одна модель на все уровни, поворот рывком. Нужны узнаваемые игрушечные модели, рост
по уровням и сочные анимации без потери кадра.

## Решение
Отдельный модуль `client/fort/turrets/`:
- `kit.ts` — палитра игрушечного замка, один материал на все детали (цвет — в вершинах, «металл/свечение» —
  в атрибуте `aMat`, отражения латуни и меди — от своего светлого неба), помощники геометрии,
  `BatchPool` (все твёрдые детали всех башен — один `BatchedMesh`) и `PartPool` (ткань вымпелов — инстансы);
- `models.ts` — геометрия четырёх типов по четырём ступеням облика, всё кодом;
- `fx.ts` — свои частицы: дым и пыль, вспышки/огонь/искры (атлас), щепки, угольки, конфетти, капли смолы —
  три вызова отрисовки на все башни;
- `turrets3d.ts` — `Turrets3D`: места, состояние, пружины прицела, анимации, матрицы деталей.

Кадр без `new`. Башни вне кадра камеры не пишутся в пачку. Тени: башни поворачиваются, а карта теней статична —
поэтому своё мягкое пятно-тень под каждой.

### Роли и силуэты
| Тип | Роль (сервер) | Силуэт |
|---|---|---|
| Баллиста | одна цель, сначала крылатые | лук-крестовина на стойке-веретене, ворот, щит-мишень (со II), на III–IV — двойной лук и магазин болтов |
| Пушка | ядро по дуге, взрыв | пузатый бронзовый ствол на лафете с колёсами, ящик ядер на хоботе; I — на бочке из клёпок с мешками; III–IV — два ствола |
| Смоляной котёл | лужа смолы у подножия | котёл на козлах над костром с воротом наклона; III–IV — чайник смолы с крышкой (на IV — корона) |
| Жаровня | угли вблизи, поджог | чаша-корзина на гнутых ногах и меха; II — медный кубок; III–IV — дракончик на шее из колец, плюётся углями |

### Ступени облика (уровни 1–10)
- I (1–3) — дерево и железо, своя простая основа;
- II (4–6) — белая каменная площадка, латунь, крашеное дерево, синий щиток;
- III (7–9) — круглая башенка с зубцами и бойницами, медь и золото, двойной лук / два ствола / чайник / дракон;
- IV (10) — королевская: золото, пурпур, корона на флагштоке.

Внутри ступени — звёзды на щитке флагштока (1–3): бронза (I), серебро (II), золото (III–IV). Щиток смотрит во двор —
его видят защитники. Вымпел — цвет уровня (I — треугольный, II–IV — «ласточкин хвост», больше со ступенью).

### Анимации
- поворот к цели — пружина с инерцией (лёгкий перелёт); баллиста ведёт зомби по номеру из события `bolt`, жаровня —
  последнего подожжённого (`burn` перед `coals`), пушка и котёл — точку выстрела; без цели — спокойный осмотр;
- выстрел — баллиста: хлопок тетивы, плечи вздрагивают, отдача; пушка: вспышка, огненный шар, клубы дыма вдоль ствола,
  искры, пыж, откат лафета с колёсами, отдача ствола и подброс дула; котёл: наклон, струя смолы параболой через
  бруствер к цели, капли и брызги; жаровня: меха сжимаются, огонь полыхает, угли и искры веером, у дракона — пасть;
- перезарядка — баллиста: ворот крутится, тетива взводится, новый болт въезжает сзади; пушка: верхнее ядро с ящика
  прыгает в дуло, на ящике «вырастает» новое, фитиль тлеет перед выстрелом; котёл: смолу подливают, булькает;
  жаровня: меха набирают воздух;
- простой — вымпел на ветру (волна в вершинном шейдере), огонь пляшет, смола булькает и парит, осмотр;
- постройка — вырастает из стены с пылью и каменной крошкой, приседает, разворачивает вымпел, звёзды выскакивают;
- улучшение — приседание, подскок со вспышкой, облик меняется в верхней точке (если сменилась ступень — белая вспышка),
  конфетти, новая звезда выскакивает; снос — уходит в стену.

## API
Сверено со снимком: в хвосте только тип и уровень на 8 местах; остальное — события `tower`, `bolt`, `cball`, `tar`,
`coals`, `burn`. Поворот и «стреляет» в снимок не идут — их выводит клиент.
```ts
const t = new Turrets3D(scene, quality = 'high', spots = TOWER_SPOTS, camera = null);
t.setAll(types, levels);               // хвост снимка; первое после reset — без анимаций (вход посреди игры)
t.set(spot, type, level);              // одно место: сам видит постройку / улучшение / снос
t.fire(spot, x, y, z, out, zid = -1);  // выстрел в точку (NaN — без точки, цель — зомби zid); out = дуло
t.aim(spot, x, y, z); t.track(spot, zid); t.muzzle(spot, out);
t.build(spot); t.upgrade(spot);        // явный запуск анимаций (set/setAll делают это сами)
t.update(dt, camPos, where);           // where(zid, out) — где зомби на экране
t.setQuality(q, slow); t.reset(); t.dispose(); t.info;  // info — вызовы, детали, частицы (для стенда и тестов)
```

## Кадр: было → стало (стенд, бой, 8 башен, высокое качество)
| вид | вызовов | треугольников | обновление + отрисовка, мс |
|---|---|---|---|
| со стены (wall) | 50 → 45 | 307k → 314k | 1,11 → 0,64 |
| ворота (gate) | 51 → 46 | 294k → 289k | 1,19 → 1,23 |
| двор (yard) | 56 → 51 | 322k → 342k | 1,63 → 0,99 |
| терраса | 91 → 59 | 291k → 321k | 1,69 → 1,03 |
| места 0–3 вблизи | 47/45/38/41 → 42/43/35/40 | +3…+17k | 1,6/1,6/1,4/1,4 → 1,2/1,1/0,9/1,0 |
| снаружи (front0, front2) | 124/140 → 103/106 | +26…+31k | 1,57/2,00 → 0,82/0,85 |

Башни целиком — 1 вызов (пачка) + 1–2 (вымпелы) + 1 (пятна) + до 3 (частицы). Одна башня — 3,5–10 тыс.
треугольников (тест держит ≤ 10,5 тыс.).

## Вставка для агента arsenal
Проще всего — `git cherry-pick` коммитов `rework/fort-turrets` (после `a9a91eb`): общие файлы с тех пор в
`rework/arsenal` не пересекаются с моими строками (в `arsenalc.ts` правки интерфейса — в других местах).
Если руками:

1. **Новые файлы** — скопировать как есть: `client/fort/turrets/{kit,models,fx,turrets3d}.ts`,
   `test/fort-turrets.test.ts`, `tools/fort-turrets/{index.html,lab.ts}`.
2. **`client/fort/arsenal3d.ts`**
   - импорты: из `shared/fortarsenal.ts` убрать `TW_TAR`, из `shared/fortmap.ts` — `TOWER_MUZZLE`; добавить
     `import type { Quality } from '../settings.ts';` и `import { Turrets3D } from './turrets/turrets3d.ts';`;
   - удалить старые башни целиком: `interface TowerModel`, `interface TowerVis`, `buildBallista`, `buildCannon`,
     `buildTar`, `buildBrazier`, `BUILDERS`, `TOWER_SCALE`, `LEVEL_COLORS`, метод `buildSpots()` (круги мест теперь
     рисует `Turrets3D`), приватные `aim()` и `muzzle()`, функцию `dampAngle()` в конце файла;
   - поле `towers: TowerVis[]` → `readonly turrets: Turrets3D;` и `private lastBurn = -1;`;
   - конструктор: `constructor(scene: THREE.Scene, camera: THREE.Camera | null = null)`, вместо `this.buildSpots();` —
     `this.turrets = new Turrets3D(scene, 'high', TOWER_SPOTS, camera);`;
   - методы башен — короткие вызовы:
     ```ts
     setTowers(types, levels) { this.turrets.setAll(types, levels); }
     bolt(i, x, y, z, out, zid = -1) { this.turrets.fire(i, x, y, z, out, zid); this.launch(this.bolts, …как было…); return out; }
     cannon(i, x, y, z, ticks, out) { this.turrets.fire(i, x, y, z, out); const d = …; this.launch(this.balls, …как было…); return out; }
     pour(i, x, z, out) { this.turrets.fire(i, x, 0, z, out); …лужа смолы как было…; return out; }
     coals(i, out) { this.turrets.fire(i, NaN, NaN, NaN, out, this.lastBurn); this.lastBurn = -1; return out; }
     setQuality(q: Quality, slow = false) { this.turrets.setQuality(q, slow); }
     ```
   - `burn()`: в конце `this.lastBurn = zid;`;
   - `reset()`: вместо `this.setTowers(-1…)` — `this.turrets.reset(); this.lastBurn = -1;`;
   - `update()`: весь цикл `for (… this.towers …)` заменить на `this.turrets.update(dt, camPos, where);`.
3. **`client/fort/world.ts`** — две строки: `this.arsenal = new Arsenal3D(scene, this.camera);` и в `setQuality()`
   перед `refreshShadows()` — `this.arsenal.setQuality(q, slow);`.
4. **`client/fort/arsenalc.ts`** — событие `bolt` передаёт номер зомби (баллиста ведёт цель между выстрелами):
   `const [, spot, zid, x, y, z] = e; const m = a3.bolt(spot, x, y, z, _v, zid);`.
5. **`client/fort/props.ts`** — табличка над местом башни выше: `st.kind === 'tower' ? 3.2` (было 2.3; новые башни
   с вымпелом — до 2,9 м, табличка «⚔ ур. N» пряталась за навершием).
