# План: режим «Крепость» (выпуск 6, задача 4)

Дизайн — `docs/superpowers/specs/2026-10-02-fortress-design.md`. Помощник «fort», общие правила — в плане выпуска 6.
Свой код — в новых файлах `shared/fort*.ts`, `server/fort/*`, `client/fort/*`, `test/fort*.test.ts`; общие файлы —
точечными заменами, перед правкой перечитать. Основная папка всегда зелёная; режим скрыт флагом.

### Шаг 1. Общее: числа, карта, снимок
- [x] `shared/fort.ts`: типы зомби (HP, скорость, урон, очки, размеры хитбокса), волны и множители на игроков,
      цены лавки, сроки фаз, `fortReward`, типы сообщений (`FortStatus`, `FortEvent`, строки состава и итогов).
- [x] `shared/fortmap.ts`: `buildFort()` — стены, бруствер, ворота (номер бокса), башни, бастионы, лестницы, двор,
      терраса, постамент, стойки, точки появления, дороги и концы дорог, точки липучек, границы.
- [x] `shared/fortnet.ts`: хвост снимка — ворота, кристалл, лужи, зомби по 12 байт; `fortShotDir` / хиты по зомби.
- [x] Тесты `test/fortmap.test.ts`: точки появления и стойки на опоре и не в стене, с террасы по лестницам — на стену,
      хвост снимка туда-обратно, волны растут, награда.

### Шаг 2. Сервер: зомби и бой
- [x] `server/fort/nav.ts`: сетка 0,5 м, поле расстояний до кристалла и до точек липучек (Дейкстра по клеткам).
- [x] `server/fort/horde.ts`: зомби — появление, шаг по полю, расталкивание, ворота (стоп и удары), кристалл, игроки
      на земле, липучки (подъём, ход стены, прыжок во двор), пузыри (взрыв цепочкой), застрявшие, история для отката.
- [x] `server/fort/game.ts`: люди (`stepPlayer`), выстрел от третьего лица с откатом зомби, урон и отхил, смерть
      и появление, фазы (сбор → волна → передышка → … → итоги → сбор), колокол, лавка, краскомёты, лужи, очки,
      жетоны через хук, AFK, снимки 30 Гц, состав, события.
- [x] `server/fort/room.ts`: комната для хаба.
- [x] Тесты `test/fort.test.ts`: волна стартует и кончается, зомби доходят до ворот и ломают их, проходят к кристаллу,
      выстрел сбивает (с откатом), липучка на стене, пузырь лопается, кристалл разбит — поражение, 8 волн — победа,
      жетоны.

### Шаг 3. Хаб, набережная, флаг
- [x] `PROTOCOL_VERSION` = 7 (если ещё 6), `RoomKind` + `'fort'`, сообщения крепости в `shared/messages.ts`.
- [x] `server/hub.ts`: комната только с флагом (`fort` в `HubOptions`), выход, чат, наряд, жетоны и статистика,
      `/health` (`fort`, `busy`), статус для набережной раз в секунду. `server/main.ts`: `FORTRESS`.
- [x] `shared/maps/lobby.ts`: точка `fort` в конец, где появляется вернувшийся; `server/lobby/room.ts`: вход,
      поле `fort` в `lobby` только с флагом. Статистика `ft*` в профиле.
- [x] Тесты `test/fortflag.test.ts`: флаг выключен — режима нет нигде; включён — вход, выход, жетоны в профиль;
      `test/maps.test.ts` — новая точка в конце.
