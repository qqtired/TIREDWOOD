# План: режим «Подземелье» (10.10.2026)

Дизайн одобрен владельцем 10.10.2026 («НАЧИНАЙ РАБОТУ МНЕ НРАВИТСЯ»), страница:
https://claude.ai/artifact/7urdMxbig82AgaA6hyYhPb. Источник правды по числам — `docs/survivors/design-data.json`,
по карте — `docs/survivors/level-data.json`, мир и правила — `docs/survivors/brief.md`, как подключаются режимы —
`docs/survivors/tech-wiring.md`. Ведущий — тред «Режим в духе Vampire Survivors». Ветка `mode/survivors`,
worktree `~/Desktop/game-opus-survivors`.

## Решения владельца по странице (10.10.2026, «1б 2б 3б 5а 6а 7а»)

1. **Карточки сразу при новом уровне**, мир на паузе, как в Vampire Survivors (1б). Передышка между волнами остаётся
   (5 с, Enter — раньше), но без карточек.
2. **Эволюция — через сундук** (2б): оружие на макс. уровне + нужная пассивка → сундук элиты/босса/проклятый даёт эволюцию.
3. **Обрыв связи — забег на паузе 60 с** для переподключения (3б); не вернулся — засчитать отбитые волны.
4. Доп. постройки: **фонари-маяки, вагонетка, пороховые бочки, гриб-батут, забытая кузня**.
5. Варенье на полу замедляет **только героя** (5а).
6. Рывок перелетает провалы до 5 м (6а).
7. Вход — западная лужайка набережной (7а), координаты в `level-data.json`.
Решения ведущего: камера по левел-дизайну, 5 мест под алтари (активны 4), 40 % врагов рождаются по ходу движения,
«Щитожук».

## Архитектура

- **Флаг `DUNGEON`** (как FIGHT/HIDE: '1' вкл, '0' выкл, без переменной — только `npm run dev`). Вид комнаты `'dungeon'`.
- **Одна симуляция на 30 Гц** в `shared/dungeon/` — детерминированная (без Math.random/sin/cos/hypot/atan2, Date; только
  `makeRng`, `sinCos`, sqrt). Клиент играет её у себя, пауза — просто не шагаем.
- **Сервер повторяет её по журналу ввода** (`DgEvent`, куски ≤ 20 событий, JSON ≤ 2000 символов) в своём экземпляре на
  игрока и сам решает волны, жетоны, рекорды. `upto` не может обгонять настенные часы (шаги ≤ прошедшее время × 30 + запас).
  Расхождение по `h` — только в журнал сервера (у друзей не ловим читеров, но и не платим за невозможное).
- **Инстанс на игрока**: `DungeonRoom` создаётся при входе, шагается из `Hub.step`, удаляется при выходе/конце.
  Обрыв — пауза до 60 с, потом итог. Пауза дольше 10 минут — итог (`timeout`). Пауза не считается занятостью сервера.
- **Договор** — `shared/dungeon/api.ts` (типы событий, сообщений, итога, рекордов). Симуляция экспортирует из
  `shared/dungeon/sim.ts`: `createRun(seed)`, `applyEvent(sim, ev)`, `step(sim)`, `dgResult(sim)`, `dgHash(sim)` и тип
  `DgSim` с полями для отрисовки (герой, враги, снаряды, метки-телеграфы, лужи, подборы, постройки, босс, карточки,
  сундук, `fx` — события шага для эффектов, очищаются каждый шаг).
- **Клиент** `client/dungeon/`: сцена, куски карты по модулю 240 у камеры, GLB из `client/assets/dungeon/`, враги
  инстансами по частям с анимацией узлов, герой и босс со скелетом, HUD, карточки, пауза, итоги, звук.
- **Площадь**: вход-пещера и табличка рекордов (всё время / неделя) на западной лужайке, E — войти.
- **Награды/рекорды**: формула жетонов из design-data, потолок 600; `Stats` + `dgRuns, dgBest, dgBestMs, dgKills, dgBosses`;
  топы `dgTop` (за всё время) и `dgWeek` (с понедельника 00:00 МСК) в `State`; профиль → Рекорды.

## Проверка (минимум, только headless Chrome)

`npm run check && npm test && npm run build`; тесты: симуляция (детерминизм: один журнал → один итог; 10 волн ботом
проходятся/не проходятся в разумных пределах), флаг (выкл — нет входа; вкл — вход, итог, жетоны), рекорды. Браузер:
один заход в режим в headless Chrome на десктопе, снимки главных состояний, замер `__opus.info()` до/после на
набережной, CSP-проверка сборки, короткая проверка телефона «запускается». Сервер для проверки — порт 3102,
`DATA_DIR=$(mktemp -d)`.
