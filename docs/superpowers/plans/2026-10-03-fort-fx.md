# Крепость: эффекты событий и берег — план (`rework/fort-fx`)

**Статус / что осталось:** готово 03.10 вечером, ждёт слияния в `rework/fort`. Помощник агента `fort`: механика
событий, метки атак, маяк ящика, звук и тряска — у него, здесь только вид. Два новых файла по договору:
`client/fort/eventfx.ts` (метеор, ящик припасов, морской туман, золотая лихорадка) и `client/fort/shore.ts` (статика
юга: песок, причал, места высадки). В `world.ts` — одна строка вместо старого скалистого берега. Проверочная страница
`tools/fort-fx/` (только `npm run dev`, в сборку не входит). Тест `test/fort-fx.test.ts`. Ниже «Как подключить» —
для `fort` при слиянии. Открыто: звук (у `fort`), проверка на телефоне в настоящей игре.

## Как подключить

Сверено с `rework/fort` @ `ec4301f` («события волны»): `FortMatch` уже зовёт всё через `EventFxApi` из `marks.ts`,
сигнатуры совпадают с `EventFx` один в один. Осталось три правки при слиянии.

### 1. Берег — `client/fort/world.ts` (уже в этой ветке)
- `import { buildShore } from './shore.ts';`, в конструкторе `buildShore(this.scene);` на месте `this.buildShore();`,
  старый приватный `buildShore()` (скала и камни) удалён, импорт `WATER_Y` больше не нужен. Всё: 2 строки + удаление.
- Столкновений берег не добавляет (только вид). Свободные коридоры высадки: `SHORE_LANDINGS = [-12.5, 12.5]`,
  `SHORE_LANE_FREE = 3.2` м в каждую сторону, `SHORE_LANE_Z = [14, 31]`; при желании заменить на импорт ваших
  `BOAT_LANE_X`/чисел лодок — в `shore.ts` они только в этих константах. Причал — `SHORE_PIER`: x = 27 (снаружи стены
  x = 18, в стороне от середины бухты, где Кракен), z 22,6…40,6, ширина 2,4 м, голова 6,6 м.
- Песок у кромки: `waterline(x) ≈ 26,5 ± 0,7`, сухой песок с z ≈ 20; лодка `fort` встаёт к берегу у z ≈ 27,5 —
  на снимке `02-landing.jpg` стоит копия корпуса.

### 2. Создать эффекты — `client/fort/scene.ts`
```ts
import { EventFx } from './eventfx.ts';
// поле
private readonly eventFx: EventFx;
// в конструкторе, рядом с projectiles/marks
this.eventFx = new EventFx(this.world.scene, this.world.camera, this.collision);
this.marks.placeholder = false; // простой ящик marks.ts больше не нужен, маяк и круги остаются
// в enter(): new FortMatch({ ..., marks: this.marks, eventFx: this.eventFx, ... })
// в setQuality(q, slow):
this.eventFx.setQuality(q, slow);
```
`dispose()` у `EventFx` есть (уберёт всё из сцены и освободит память), но `FortScene` живёт между заходами — звать
не нужно; `clear()` match.ts уже зовёт при старте и в `dispose()`.

### 3. События → эффекты (как уже сделано в `match.ts` @ `ec4301f`, для сверки)
| Сервер | Вызов | Числа |
|---|---|---|
| `throw` c `what = ZS_METEOR` | `meteor(fx, fy, fz, tx, ty, tz, ticks / TICK_RATE)` | старт: цель + (±15, 46 м, −34), 84 тика = 1,4 с |
| `blast` c `ZS_METEOR` | `meteorHit(x, y, z, r)` | r = `METEOR_R` = 3; звук и тряска — ваши |
| `supply` what 0 (начал падать) | `crate(1, x, z, y)` | сядет через 7 с (`CRATE_FALL_S` = `SUPPLY_FALL_TICKS`/`TICK_RATE`) |
| `supply` what 1 (сел) | `crate(2, x, z, y)` | |
| `supply` what 2 (подобран) | `crate(0, x, z, y)`, затем `cratePicked(x, y, z)` | порядок любой |
| `supply` what 3 (конец волны) | `crate(0, x, z, y)` | ящик тает облачком |
| хвост снимка `crate`/`crateX`/`crateZ` | `crate(1 / 2 / 0, x, z, crateSurface(x, z))` | вошедшим посреди волны: сразу 2 — сразу лежит |
| хвост `event = EV_FOG` | `fog(on)` | слои 3 с вкл / 3,5 с выкл |
| хвост `event = EV_GOLD` | `goldRush(on)` | 1,6 с вкл / 2,2 с выкл |
| `zdie` в лихорадку (не лодка) | `coins(x, y + 1, z, boss \|\| tier > 0)` | 7 монет, у босса/элиты 18; падают на опору под точкой |
| кадр, после `updateCamera` | `update(dt)` | |

Что `EventFx` трогает в сцене и чего не трогает:
- `scene.fog` только читает: цвет — для купола и слоёв (в sRGB, как three.js подмешивает туман), `far` — радиус купола
  (`far × 1,25`, не больше 460 м: холмы без тумана не торчат из дымки) и где гаснут слои (0,7…1,15 `far`). Дальность
  (`FOG_NEAR` 6 / `FOG_FAR` 50 в `applyFog`) и глаза зомби — ваши.
- Солнце (первый `DirectionalLight` сцены) и небесный свет (первый `HemisphereLight`): запоминает при включении
  тумана или золота, в тумане солнце ×0,8 (`FOG_SUN`), в лихорадку теплее; когда оба выключены или `clear()` —
  возвращает ровно как было и дальше не трогает. Если `FortWorld` начнёт сам менять свет посреди события — сказать.
- Метки не рисует: красный круг метеора и маяк ящика — `marks.ts`. Под метеором в последние ~0,6 с только тёплый
  отсвет огня на земле (внутри круга).

Цена: 7 пулов спрайтов (по одному вызову отрисовки, без события не рисуются), ком метеоров и монеты — по инстансу,
ящик — 6 мешей, купол и слои — по вызову только при тумане/золоте. Дождь из 15 метеоров: до ~400 частиц, +5 вызовов,
GPU ~1–3 мс в безголовом Chrome. Качество: `low` — половина частиц и один слой тумана, `medium` — ¾.

Звук (если захочется): свист на `meteor`, удар на `meteorHit` (уже `sound.boom`), глухой стук на «сел», монеты на
`cratePicked` (уже `sound.coin`), фанфара на начало лихорадки, рог-ревун на туман.

### Проверочная страница
`npm run dev` → `/tools/fort-fx/` (кнопки), для снимков — параметры: `cam` (north, sky, wall, sea, landing, pier,
yard, crate, cratenear, top), `fx` (meteor, wallmeteor, rain, crate, wallcrate, land, take, fog, gold, kill, clear —
через запятую), `t` (шагнуть секунд ровными кадрами), `pause`, `q` (low/medium/high), `nopanel`. Заглушки чужого:
копия лодки у места высадки, красный круг вместо `marks.ts`, дальность тумана сцены 6…50 м за 3 с, как в `applyFog`.
Можно не брать при слиянии — в сборку не входит.
