## Риски и границы

Стандартный старый install.sh делает откат только кода и удаляет старые релизы, поэтому его прямой запуск здесь не подходит. Использовать отдельный сохранённый operator script для согласованной миграции и совместимого отката. Production данные остаются на сервере; наружу выводить только aggregate checks и безопасные результаты. Токены не печатать и не передавать в командной строке.

Голос: локальный реальный Opus проверен через контролируемый loopback; физический mic/WAN/TURN пока не приняты. В production включается как добровольная экспериментальная функция, отключаемая VOICE=0. Остальные улучшения FPS из O1–O11 остаются передачей Opus и не расширяют релиз.

Готово, когда новый согласованный release реально active, post-start проверки данных и HTTP/WS проходят, доступен совместимый rollback и отчёт не скрывает оставшиеся ограничения.
