# Выпуск 4: управление карта, связь, набережная, графика, телефоны

**Цель:** всё, что владелец одобрил («сделай») после вечерней игры 01.10.2026: управление карта и камера,
связь и ошибки игроков, набережная для общения, графика, телефоны.

**Как работаем:** код живёт в той же папке, из которой идёт выкладка (`deploy.sh` берёт всё). Поэтому каждую задачу
доводим до конца (проверки, тесты, сборка, проверка в браузере) и только потом берём следующую: папку можно выложить
в любой зелёной точке. Выкладка — только после «да» владельца.

**Порядок:** 1 → 2 → 3 → 4 → 5 → … — от того, о чём просили первым, и от быстрого к долгому.

## Общие правила

- Физика карта общая для сервера и браузера: только `+ − × ÷`, `Math.sqrt/abs/min/max` и `sinCos` (тест следит).
- Поменялась физика или формат снимков — `PROTOCOL_VERSION` +1 (старые вкладки перезагрузятся).
- Всё, что даёт жетоны, решает сервер; клиенту не верим.
- Секреты в код и журнал не пишем; в журнал ошибок игроков — только текст ошибки, файл и строку.
- Файлы статуи не трогаем (`statue*.ts`, `client/assets/statue`, `tools/statue`, `test/statue.test.ts`, `STATUE`).
- Проверки после каждой задачи: `npm run check && npm test && npm run build` и браузер (headless Chrome).

### Задача 1: Управление картом и камера гонки

Просьба: «Руль острее (радиус на полной ~15 м, поворот даже на месте); после удара карт разворачивается вдоль стены и
едет дальше, застрять нельзя; занос начинается подскоком на пробел, полоска заряда ускорения; камеру пофиксить — слишком
выравнивается».

- [x] Руль: `TURN_FALL` 0,6 → ~0,36 (радиус ~15 м на 22 м/с); на месте руль поворачивает на ~половину
      (`TURN_MIN`), полная сила — с ~5 м/с. Тест: радиус 13–17 м на полной; на месте за 1 с поворот > 40°.
- [x] Стены: носом в стену — курс за несколько тиков доворачивает вдоль стены (в сторону, куда карт смотрел вдоль неё;
      лоб в лоб — по ходу трассы), касательная скорость остаётся, нормальная гасится; лоб в лоб — отскок назад.
      Тест: удар под 30/50/75/90° с газом без руля — через ≤ 1,5 с едет вдоль трассы > 5 м/с; ни разу не стоит дольше 1 с.
- [x] Подскок: нажал пробел на земле — подскок (~0,25 с). Приземлился с зажатым пробелом и рулём — занос в сторону руля.
      Без руля — просто подскок. Окно: руль можно нажать до 0,5 с после нажатия пробела. Тест.
- [x] Полоска заряда на экране: появляется в заносе, наполняется до синего (мини-турбо), потом до оранжевого.
- [x] Камера: смотрит туда, куда карт едет (в заносе — по скорости), догоняет мягко (пружина ~0,45 с), не болтается
      сильнее ~35° от курса; мышью оглянулся — держит взгляд, возвращается плавно только через секунду без мыши.
- [x] Боты: пересчитать скорости в поворотах под новый руль; тесты гонки (3 круга за 4 мин, порядок сложности).
- [x] `PROTOCOL_VERSION` 5; README (управление, занос), design.md (физика).

### Задача 3: Ошибки из браузеров игроков — в журнал сервера

### Задача 6: Действия вдвоём — «дай пять», обнимашки, фото у маяка

- [x] 5 — «дай пять», 6 — обняться: игрок рядом (≤ 2 м, перед тобой) получает приглашение «нажми 5»; согласился — оба
      встают лицом друг к другу и играют жест; звук, звёздочки. Приглашение живёт 5 с.
- [x] Фото у маяка: штатив с фотоаппаратом на площадке маяка, E — отсчёт «3, 2, 1» всем рядом, вспышка; у каждого,
      кто был рядом, — снимок с площадки (рендер с фиксированной камеры) и кнопка «Сохранить».
- [x] Тесты: приглашение, согласие, дальность, отмена шагом.

### Задача 7: Мяч на площади

- [x] Сервер: мяч (физика в `shared/ball.ts`: тяжесть, отскок от настила и стен, трение, упал в воду — вернулся в центр).
- [x] Пинок: желейка вбегает в мяч — пинок по направлению бега, рывком — сильнее, прыжком — выше.
- [x] Клиент: мяч по снимкам, звук удара, тень. Тесты физики. Вместо интерполяции «как чужие» — мяч считается

### Задача 8: Рыбалка с причала

- [x] Места рыбалки на мостках к маяку; E — встал с удочкой; пробел/ЛКМ — заброс.
- [x] Сервер решает поклёвку: сначала «пробы» (поплавок дёргается), потом настоящая поклёвка — успей подсечь
      (окно с учётом пинга). Рано подсёк — сорвалась.
- [x] Улов: вид и вес случайные по редкости; «В коллекцию» или «Продать за N 🪙». Коллекция — альбом видов с

- [x] Клиент: удочка, леска, поплавок, рыба в руках, панель альбома. Тесты сервера.

### Задача 9: Дождь

- [x] Сервер решает погоду для всех: иногда дождь (на несколько минут), сообщает при входе и при смене.
- [x] Клиент: капли вокруг камеры, небо и туман серее, настил мокрый (меньше шероховатость, темнее), лужи с отражением
