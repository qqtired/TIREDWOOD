> **Для исполнителя:** план выполняется в этой же сессии, по порядку, без субагентов (так договорились с владельцем). Шаги отмечаются `- [x]`.
>

>
> Проекта нет в git: вместо коммитов — контрольные точки `npm run check && npm test`. Перед началом — архив-копия.
>
> **Картинг не подключается к игре до задачи 8.** Выпуск 2 могут выложить из этой же папки в любой зелёной точке (`deploy.sh` везёт папку целиком), поэтому до задачи 8 гараж на набережной по-прежнему «скоро», а новые файлы никто не импортирует (кроме тестов и страницы предпросмотра, которой нет в сборке).

**Цель:** раздел 17 спецификации `docs/superpowers/specs/2026-10-01-lobby-platform-design.md`:
- трасса «Портовое кольцо» ~580 м: контейнеры, краны, трамплин через канал, открытые причалы;
- 3 круга, до 6 картов, боты, если людей меньше 4;
- сбор в круге «Старт» у гаража: 15 с отсчёта;
- бонусы из ящиков: турбо, банка варенья-ловушка, краска;
- таблица результатов и жетоны по разделу 6.

**Подход:**
- **Трасса — осевая линия, а не боксы.** Дорога задаётся замкнутым многоугольником со скруглёнными углами, разбитым на отрезки ~2 м. Стены — края коридора, в котором держится карт; где края нет (причал, канал) — карт падает в воду. Высота дороги — по осевой (трамплин). Контрольные точки, места в гонке и боты считаются по номеру отрезка.
- **Физика карта** (`shared/kart.ts`) — детерминированная, как у желеек: сервер считает, клиент предсказывает тем же кодом. Курс карта хранится вектором `(hx, hz)`: поворот — через `sinCos`, никаких `atan2`.
- **Сервер:** комната `race` (как пейнтбол: одна на процесс). Внутри `Race` — карты, фазы, ящики, ловушки, столкновения, боты, итоги.
- **Клиент:** сцена `race`, третья рядом с набережной и пейнтболом. Мир трассы строится при первом заезде и остаётся в памяти; заезд (предсказание, чужие карты, камера погони, интерфейс) — заново на каждый.
- **Набережная:** круг «Старт» у гаража считает сервер набережной. Хаб переводит людей из круга в гонку и после итогов — обратно к гаражу.

**Стек:** как в выпусках 1–2. Node 24 (TypeScript без сборки), three.js 0.186, ws 8, Vite 8, `node --test`.

## Общие ограничения

- Общение, тексты интерфейса, комментарии — на русском. Имена в коде — английские.
- `PROTOCOL_VERSION = 4` — только в задаче 8 (новая комната и сообщения). Старые вкладки перезагрузятся сами.
- **Детерминизм:** в `shared/track.ts` и `shared/kart.ts` — только `+ − × ÷`, `Math.sqrt`, `Math.abs/min/max/floor/round/sign/trunc` и `sinCos` из `shared/math.ts`. Запрещены `Math.sin/cos/tan/atan/atan2/hypot/exp/pow/log`. Это проверяет тест (ищет их в исходнике).
- **Сеть гонки:** снимок раз в 2 тика (30 в секунду), позиции — int16 с шагом 1/128 м (трасса целиком в ±256 м), своё состояние — точно (float64).
- **Карты:** до 6; людей меньше 4 — боты добивают до 4. Бонусы и столкновения считает только сервер.
- **Жетоны (раздел 6):** финишировал +10, 1-е место +25, 2-е +15, 3-е +10. Место — среди всех картов, включая ботов. Не доехал — ничего.
- **Таймеры:**

  | стартовая решётка (3-2-1) | 5 с |

  | гонка целиком, не больше | 5 мин |

// shared/track.ts
export interface TrackNode { x: number; z: number; r: number }      // угол многоугольника и радиус скругления
/** Участок «ноги» — прямой между скруглениями узлов i и i+1; at, from, to — метры от её начала */
export interface TrackDef {
  name: string;
  nodes: TrackNode[];          // обход по ходу гонки, путь замкнут
  width: number;               // ширина дороги, м
  step: number;                // длина отрезка не больше, м (2)
  start: { leg: number; at: number };                                // линия старта/финиша = точка 0
  checkpoints: Array<{ leg: number; at: number }>;                   // КТ 1…; КТ 0 — линия старта
  ramps: Array<{ leg: number; at: number; up: number; height: number; gap: number }>;
  open: Array<{ leg: number; side: 'left' | 'right'; from: number; to: number }>;
  crates: Array<{ leg: number; at: number; count: number }>;         // ряд ящиков поперёк дороги
}
export interface Track {
  readonly name: string;
  readonly n: number;                    // точек осевой (= отрезков, путь замкнут)
  readonly length: number;
  readonly half: number;                 // половина ширины
  readonly px: Float64Array; readonly pz: Float64Array;   // точки
  readonly h: Float64Array;              // высота дороги в точке
  readonly s: Float64Array;              // дистанция от линии старта до точки
  readonly len: Float64Array;            // длина отрезка i → i+1
  readonly tx: Float64Array; readonly tz: Float64Array;   // единичное направление отрезка
  readonly gap: Uint8Array;              // 1 — у отрезка нет дороги (канал)
  readonly openL: Uint8Array; readonly openR: Uint8Array; // 1 — край без стены
  readonly curv: Float64Array;           // кривизна в точке со знаком (+ — влево), для ботов и бордюров
  readonly cpSeg: Int32Array;            // точка каждой КТ; cpSeg[0] = 0
  readonly crates: Array<{ x: number; y: number; z: number; seg: number }>;
  readonly grid: Array<{ x: number; z: number; hx: number; hz: number; seg: number }>;   // 6 мест за линией
}
export function buildTrack(def: TrackDef): Track;
/** Найти отрезок у точки: поиск в окне seg−4…seg+8 (по кругу). Пишет в out. */
export interface TrackLoc { seg: number; t: number; lat: number; ground: number /* NaN — нет дороги */ }
export function locate(tr: Track, x: number, z: number, seg: number, out: TrackLoc): TrackLoc;
/** Отрезок у точки поиском по всей трассе (сборка, решётка, ловушки на сервере) */
export function locateAny(tr: Track, x: number, z: number, out: TrackLoc): TrackLoc;
export function wrapSeg(tr: Track, i: number): number;
/** Прогресс по гонке (м): круг × длина + путь от КТ cp, со знаком — для мест */
export function progress(tr: Track, lap: number, cp: number, seg: number, t: number): number;

export const RING: TrackDef;
export interface Land { x0: number; z0: number; x1: number; z1: number }    // плиты суши, верх на y = 0

**Правила построения:**
- Скругление угла с направлениями `d1 → d2` и радиусом r: отступ `r · tan(θ/2)` = `r · |d1×d2| / (1 + d1·d2)`. Дуга — поворотом начального радиус-вектора на `k·δ` через `sinCos`; число отрезков дуги — `ceil(длина / step)`.
- Прямые разбиваются так, чтобы границы трамплина, провала, открытых краёв, ящиков и КТ попадали точно в точки.
- После сборки точки переставляются по кругу так, что точка 0 — на линии старта. `s[0] = 0`.
- Трамплин: высота растёт линейно `0 → height` на длине `up`, следующие `gap` метров — провал (`gap = 1`), дальше высота 0.
- Решётка: 6 мест, ряды через 4 м, первый — в 6 м за линией, через одно влево/вправо на 2,4 м.
- `curv[i]` = поворот направления между соседними отрезками / средняя длина (со знаком).

**«Портовое кольцо» (узлы, м; X — восток, Z — юг):**

| узел | x | z | r | поворот |
|---|---|---|---|---|
| N0 | −90 | 54 | 24 | юг → восток |
| N1 | 72 | 54 | 26 | восток → север |
| N2 | 72 | −54 | 14 | север → запад (шпилька, половина 1) |
| N3 | 44 | −54 | 14 | запад → юг (шпилька, половина 2) |
| N4 | 44 | 6 | 16 | юг → запад |
| N5 | −12 | 6 | 16 | запад → север |
| N6 | −12 | −48 | 18 | север → запад |
| N7 | −90 | −48 | 22 | запад → юг |

- Ширина 11 м. Длина ≈ 584 м.
- Старт: нога 0 (N0→N1, на восток), линия при x = −20.
- КТ: начало ног 1, 3, 4, 5, 6, 7 и начало ноги 0 (x = −66).
- Открытые края:
  - нога 6 (причал, на запад) — справа, по всей прямой;
  - нога 1 (восточный причал, на север) — справа, по всей прямой.
- Трамплин: нога 7 (на юг): от z = −12, `up` 8 м, `height` 1,5 м, `gap` 9 м (канал z −4…5).
- Ящики (по 4 в ряд, через 2,4 м): нога 1 при z = 0, нога 4 при x = 16, нога 7 при z = 18.
- Суша: плиты верхом на y = 0. Канал x −100…−60, z −4…5 — вода. Север ноги 6 — вода с z < −54, восток ноги 1 — с x > 78.

**Управление:** W/↑ — газ, S/↓ — тормоз и задний ход, A/D — руль, Space (`BTN_JUMP`) — занос, E или ЛКМ (`BTN_USE`/`BTN_FIRE`) — бонус, R (`BTN_RELOAD`) — вернуться на последнюю КТ. Мышь не нужна.

**Шаг (по порядку):**
1. События — в ноль. `pressed = buttons & ~prevButtons`, `prevButtons = buttons`. Таймеры `boostT, slowT, spinT, ghostT, itemT` уменьшаются.
2. `done`: кнопки не действуют, мягкое торможение (`COAST × 2`).
3. R при `canDrive` и `ghostT = 0` → `respawn`, событие, конец шага.
4. Стоит, если `!canDrive` или первые 0,5 с призрака: скорость 0, руль сглаживается, конец шага.
5. Руль к цели (−1/0/1) со скоростью `STEER_RATE = 8`/с.
6. Бонус по `pressed` (E или ЛКМ), если `item ≠ 0` и `itemT = 0`: турбо → `boostT = TURBO_TICKS`, `boostLvl = 3`. `ev.used = item`, `item = 0`.
7. Занос: Space зажат, `|steer| > 0,5`, скорость вперёд > 9 м/с, на земле → `drift = знак руля`. Space отпущен или скорость < 7 → конец. `driftT` ≥ 50 → мини-турбо `boostT` 28, `boostLvl` 1; ≥ 110 → 55 и 2.
8. Поворот курса:
   - `w = руль × TURN_RATE(2,3) × sf(v) × знак(v)`, где `sf = min(1, |v|/7) × (1 − 0,45 × min(1, |v|/22))`;
   - в заносе руль заменяется на `drift × (0,75 + 0,4 × steer × drift)`, `w × 1,15`;
   - в воздухе `w × 0,25`;
   - курс поворачивается на `w·DT` через `sinCos`, затем нормируется.
9. Скорость раскладывается на «вперёд» и «вбок» по новому курсу. На земле:
   - потолок: 22 м/с; турбо 30, мини-турбо 26/28; в варенье 11; `done` — 0; задний ход до 6;
   - газ: `+14·(1 − 0,55·v/потолок)` м/с², выше потолка — сброс 12 м/с²;
   - тормоз 30 м/с², накат 4 м/с²;
   - боковая скорость гасится на 25 % за тик, в заносе — на 6 %.
10. Сдвиг `x += vx·DT`, `z += vz·DT`; `locate` от `seg`.
11. Стены (край не открыт): `|lat| ≤ half − KART_R`. Позиция — на край, нормальная скорость `−0,3 × v_n`, касательная `× (1 − 0,15·min(1, v_n/10))`; `ev.wall = v_n`.
12. Дорога под колёсами есть, если отрезок не провал и `|lat| ≤ half + 0,5`.
    - На земле: есть дорога → `y` = её высота, `vy` = подъём за тик × 60 (так трамплин подбрасывает). Нет → взлёт с этим `vy`.
    - В воздухе: `vy −= 22·DT`, `y += vy·DT`. Если `y` ≤ высоты дороги: приземление при `y ≥ высота − 0,45` (`ev.land`), иначе удар в стенку причала — назад на прошлую точку, горизонтальная скорость 0 (падает в воду).
13. Вода: `y < WATER_Y − 0,4` → `ev.splash`, `respawn`.
14. КТ: следующая `c = (cp+1) mod 8`; если `(seg − cpSeg[c]) mod n < 20` → `cp = c`. Если c = 0 → `lap++`; при `lap > RC_LAPS` → `done = 1`, `ev.finish`.

**Тесты `test/kart.test.ts`:**
