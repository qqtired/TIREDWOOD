# Крепость: вид замка и ворота — план и отчёт агента `fort-castle`

**Статус:** готово. Ветка `rework/fort-castle` (от `rework/fort` 32370b6) + слито `rework/arsenal` (386bbe8, по
разрешению оркестратора). Модуль `client/fort/castle.ts` + `client/fort/castle/*`, стенд `/tools/fort-castle/`,
тест `test/fort-castle.test.ts`. Снимки — `game-opus-wt/shots/fort-castle/` (`before-*` — было, `after-*` — стало,
`t3-boss-*`, `t3-breach-*` — прорыв, `after-crystal-*` — кольца).

## Задача (слова владельца)
«Сам визуал крепости продумать, поинтереснее. Там сейчас всё куцо, не продумано. Анимации стоит добавить, какие-то
открытия ворот сделать». Коллизии не меняются (`shared/fortmap.ts`): визуал ложится точно на коробки карты.

## Что сделано
- [x] Стены (`castle/masonry.ts`): тёплый песчаник крупной кладкой, светлый тёсаный камень бруствера и зубцов
      с шапками, цоколь, карниз на двухступенчатых кронштейнах, угловые камни, бойницы, плющ, клинчатая перемычка
      с замковым камнем над воротами, ниши в стенах проезда под открытые створки. Видимые грани считаются вычитанием
      соседних коробок — внутри стен ничего не рисуется.
- [x] Надвратная башня (`castle/towers.ts`), только вид: этаж на консолях выше хода по стене (низ балок 6,15 м — под
      ним 2,75 м над ходом), арки спереди и сзади, окна со ставнями и цветами, герб, поднятая решётка, шатровая
      черепичная крыша с большим флагом. Проём (5 × 3 м) и «горло» не тронуты, консоли — вне хода и выше головы.
- [x] Эркеры с коническими крышами и вымпелами на северных бастионах — НЕ на диагональных углах (там бойницы башен
      арсенала). Шатры на весь бастион не ставил: под ними стоят игроки, башня-турель и летают крылатки.
- [x] Флаги, знамёна (10 шт.), вымпелы и гирлянды флажков — один меш, ветер в вершинном шейдере (`castle/flags.ts`).
- [x] Ворота (`castle/gate.ts` + чистая логика `castle/gatestate.ts`): две створки из досок (6 инстанс-мешей),
      открыты/закрыты — пружина на петлях в ниши (проём не сужается), мягкий удар о стену с пылью; прочность — трещины,
      пробитые и выбитые доски (лежат на земле), створки подаются внутрь и провисают; удар — дрожь, пыль, щепки, при
      сильном — дрожит перемычка; пали — левая падает наружу плашмя, правая висит на одной петле; прорыв босса —
      правую швыряет во двор, левую отпихивает, арка трясётся, сыплются пыль и камешки; ремонт и новые ворота — всё
      «отматывается» назад, доски летят на места; укрепление 0–8 — петли, полосы, заклёпки, средняя полоса, уголки,
      продольные полосы, оковка, шипы, на 8-й — золото и умбон. Вид по прочности и ступени детерминирован — у всех
      игроков одинаковый.
- [x] Кристалл: золотые кольца с бусинами над постаментом по ступени 0–5, вырастают с искрами, кружат вразнобой.
- [x] Двор (`castle/yard.ts`): кузня в СВ углу (горн с углями, колпак и труба с дымком, искры, наковальня, бочка),
      склад в СЗ углу (бочки, ящики, мешки), стойка с копьями и щитами, поленница, ящики с цветами на террасе,
      фонари у «горла», факелы во дворе, фонари на столбах террасы.
- [x] Частицы (`castle/fx.ts`): огонь и ореолы — billboards с шейдером мерцания; пыль/дым — альфа-billboards;
      камешки и щепки — инстансы. Количество режет `setQuality` (low 45 %, medium 70 %).
- [x] Стенд `/tools/fort-castle/` и тест `test/fort-castle.test.ts`.

## Интерфейс (`client/fort/castle.ts`)
```ts
export class CastleDecor {
  readonly gate: CastleGate; readonly fx: CastleFx; readonly root: THREE.Group; readonly triangles: number;
  constructor(scene: THREE.Scene, map: FortMap);
  setTiers(gate: number /*0–8*/, crystal: number /*0–5*/): void;
  setQuality(tier: 'low' | 'medium' | 'high'): void;
  update(dt: number, t: number): void;   // каждый кадр
  dispose(): void;
}
export { gatePress } from './castle/layout.ts';   // = gateSqueeze у fort (та же формула)
// CastleGate:
set(open01: number, hp01: number, broken: boolean, instant = false): void; // каждый снимок; меняется только новое
setTier(tier: number, instant = false): void;
hit(power = 1): void;      // удар по воротам
rumble(power = 1): void;   // гул: событие прорыва — арка вздрагивает, сыплется пыль (створки не трогает)
breach(): void;            // остатки створок отрывает (сам вызывается из squeeze, когда босс в проёме)
squeeze(k: number): void;  // каждый кадр: max gatePress по живым боссам
repair(): void;            // событие ремонта: стук, пыль у досок
```

## Инструкция вставки (сделана в этой ветке — при слиянии перенести так же)
1. `client/fort/world.ts`:
   - `import { CastleDecor } from './castle.ts';`, поле `readonly castle: CastleDecor;`;
   - в конструкторе `this.buildWalls(map);` → `this.castle = new CastleDecor(scene, map);` (методы `buildWalls`,
     `buildBanners` и поле `flags` удалить — стены, флаги и знамёна теперь в замке);
   - коробка теней `fitShadow(... new THREE.Vector3(26, 9, 20))` → верх `14.5` (конёк надвратной башни);
   - `setQuality`: `this.castle.setQuality(tier);` перед `refreshShadows()`;
   - `update`: строку с `f.rotation.y` для флагов удалить, перед `this.props.update(...)` — `this.castle.update(dt, t);`
     (каждый кадр, не под `decorEvery`).
   `buildYardProps`, `buildShore` и остальное не трогаются: при конфликте с `fort-fx` (берег) берите обе стороны.
2. `client/fort/props.ts`: ворота (группа, текстуры, обломки, дрожь, «вырастание») удалены; `setGate(hp)` теперь
   только запоминает «стоят/пали» для щита сбора; `shakeGate` удалён.
3. `client/fort/arsenalc.ts`: геттеры `gateTier`, `crystalTier` (из хвоста арсенала).
4. `client/fort/match.ts`:
   - `import { gatePress } from './castle.ts';` (после слияния с fort можно звать их `gateSqueeze` — формула та же);
   - удар: `props.shakeGate(...)` → `world.castle.gate.hit(Math.min(1.5, (this.gate - t.gate) / 25));`;
   - после `props.setGate(t.gate);`:
     `world.castle.setTiers(this.ars.gateTier, this.ars.crystalTier);`
     `world.castle.gate.set(0, t.gate / this.ars.gateMax, t.gate <= 0, first);`
   - событие `['gate', 1, …]` (подлатали): `world.castle.gate.repair();`;
   - после `d.zombies.update(...)`: `press = max(gatePress(x, z))` по живым боссам (`isBossKind`) через
     `d.zombies.where(id, _v)` → `d.world.castle.gate.squeeze(press);`;
   - событие `['breach', id]` (есть у fort): добавить `world.castle.gate.rumble();` — арка вздрогнет, когда Барон
     ревёт; остатки створок оторвёт сам Барон, когда войдёт в «горло» (`squeeze` > 0,55 → `breach`).
5. `client/fort/textures.ts`: `gateTexture`, `stoneTexture`, `cutStoneTexture` больше не используются — можно
   удалить при слиянии, если никто другой их не зовёт.

## Открытые ворота — что нужно от сервера (сейчас всегда закрыты: `set(0, …)`)
Вид готов (`set(open01, …)` плавно открывает и закрывает). Чтобы ворота открывались в игре:
- бит «открыты» в хвосте снимка ворот (например `FM_OPEN` в флагах крепости) или число 0…1 при медленном открытии;
- пока открыты — выключать коллизию ворот (`map.gateBox`) на сервере и в предсказании (`shared/`);
- команда открыть/закрыть в перерыве между волнами (кнопка у стойки ворот или колокол), авто-закрытие перед волной
  и выталкивание игроков из проезда, если створка закрывается на них.

## Боссы и проём (5,0 × 3,0 м)
| Босс | r | hrx | рост | нужно по ширине (2·hrx + 0,2) |
|---|---|---|---|---|
| Барон (Z_BOSS) | 2,1 | 2,3 | ≈5,5 м | 4,8 — проходит |
| Таран (Z_RAM) | 2,0 | 2,4 | ≈4,3 м | 5,0 — впритык |
| Валун (Z_GOLEM) | 2,3 | 2,5 | ≈6,1 м | 5,2 — шире проёма на 0,2 |
- Ширина: Барон проходит, Таран — впритык, Валун задевает стены. Проём по договору не меняю; Валуну хватит сжатия
  по ширине на ~4 % в проезде (или hrx 2,4).
- Высота: все выше 3 м — в проезде (z −16…−13) нужно сжатие по высоте (у fort есть `gateSqueeze`). В «горле» под
  надвратной башней сжимать не надо: низ балок 6,15 м, арки 4,95–5,8 м по краям/в замке — Барон и Таран проходят
  целиком, Валун — почти.
- Красота прохода: пока босс в «горле» и проезде, арка дрожит и сыплет пылью и камешками; если ворота пали — остатки
  створок отрывает (правую швыряет во двор, левую отпихивает), пыль занавесом и клубы во двор.

## Не сделано / риски
- Открытие ворот в игре — нужен сервер (см. выше).
- Сжатие боссов в проезде делает fort (`gateSqueeze`); на моём стенде босс без сжатия, поэтому снят у входа в «горло».
- Брошенная во двор створка лежит без коллизии (ноги игроков на 0,2 м «тонут» в ней) — до новых ворот.
- Вечернего режима нет — фонари и факелы горят и днём (мягко, без вспышек).
