## План

### A. Микшер — Меню → Настройки → Звук
1. `client/audio.ts` (точечно, дождь и гром не трогаю): шина `music` (вход для чужой музыки, баян баркаса) с
   приглушением `duckMusic(k)`, вход автомата мимо приглушения, общая громкость музыки `musicMix`; шина `ui`
   отдельно от эффектов (`uiMix`); `setMix(эффекты, окружение, интерфейс, музыка)`; `preview(kind)` — короткий
   пример звука каждой шины.
2. `client/settings.ts`: `musicVolume`, `uiVolume` (старые сохранения: интерфейс = прежние «Эффекты», музыка 0,8),
   ключ прежний.
3. `client/voice-prefs.ts`: маленький экспорт `voiceVolume()` / `setVoiceVolume()` — живой контроллер голоса или
   сохранение; `voicepanel.setVoiceSource` регистрирует контроллер. Один источник правды с вкладкой «Голос».
4. `client/ui/menu/settings-panel.ts`: ползунки Общая / Без звука / Музыка / Окружение / Эффекты / Интерфейс /
   Голоса игроков; отпустил ползунок — пример его звука.
5. Аудит шин: что куда идёт (интерфейс — кнопки, уведомления, монетки; окружение — море, чайки, ветер).

### B. Музыкальный автомат
1. `shared/jukebox.ts`: каталог 8 песен (название, настроение, темп, такты → длина), цена 10, очередь 5, место,
   кривая громкости по расстоянию, флаг `JUKEBOX` (в dev включён), сообщения.
2. `server/lobby/jukebox.ts`: очередь, текущая песня {song, кто, start}, продвижение по времени (ленивое — и после
   сна цикла), отказы без списания. `room.ts`: точечно — сообщение `juke`, рассылка, состояние входящему.
3. `shared/maps/lobby.ts`: коллайдер и точка «E — музыкальный автомат» в конец списка (без флага коллайдер выключен).
4. `client/music/*`: синтезатор (электропиано FM, бас, щипковые Карплус-Стронг, пэды, аккордеон, свист, чиптюн,
   колокольчики, ударные из буферов), реверберация из сгенерированного импульса, свинг; секвенсор с упреждением
   ~100 мс без выделений на кадр; 8 оригинальных песен в маленьком нотном формате; офлайн-рендер для проверки
   уровней (пик, RMS) и «теория по нотам» (такты сходятся, ноты в ладу).
5. `client/lobby/jukebox*.ts`: модель кодом (арка, светящиеся трубки, хром, огоньки, эквалайзер, ноты), окно
   (список, «Поставить · 10 🪙», что играет, очередь), подсказка E, клик/тап, закрытие Esc/шагом/отошёл;
   звук по миру: полная громкость до ~12 м, дальше до ~40 %, синхронно по времени сервера, в инстансах тишина,
   в скрытой вкладке не синтезируем.
