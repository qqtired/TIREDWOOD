Ветка `feat/fishC`. Части A (данные, сервер, сезон) и B (кальмар, прыжки рыб) — в своих ветках, их файлы не трогаем.

- [x] Пирс длиннее в море, дом рыбака на конце, места рыбалки по длине, коллизии, лодка «Удалая» в обход
- [x] Семён: новая модель (борода, шапка, жилет, трубка), анимации (стоит, чинит сеть, курит, машет, оборачивается)
- [x] Окно Семёна в стиле журнала рыбака и меню Esc, таймер сезона (заглушка до сервера A: `client/lobby/fishseason.ts`)
- [x] Плашки событий: дождь, рыболовное событие, сезон, бонусы — меньше текста, иконки, понятная иерархия
- [x] Баркас: музыкальный автомат на баке (общая очередь с площадью), матрос вместо баяниста, вывеска «Бизнесмен»
- [x] Проверки: `npm run check`, тесты, `npm run build`, снимки «до/после» в `shots/fishC/`

## Что не сделано / на потом
- Сезон рыбалки: часы сезона ждут письма сервера части A (`fishSeason`); до него — заглушка, только в разработке и с `?debug`.
- `SEASON_PERKS` («эпик и выше ×3») записан вручную по `SEASON_MUL` части A — сверить при слиянии.
- Окна рюкзака и рулетки — в прежнем зелёном стиле (в задаче их не было).

## Решения
- Автомат на баркасе — та же очередь, что на площади: автомат на площади слышен на всей набережной (не тише 40 %),
  две разные песни одновременно звучали бы кашей; громкость — по ближнему автомату.
- Для проверок — `/go tp x z [y]` в чате (только `--dev` / `DEV_GO=1`): встать в точку набережной.
