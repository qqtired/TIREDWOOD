# Лаборатория TIREDWOOD (`/lab`)

Страница, где лежат новые идеи для игры и живые прототипы. Идею можно посмотреть, покрутить и попробовать. Владелец ставит
статус (берём / не берём / доработать), сервер хранит решения в `DATA_DIR/lab.json`, и по нему планируются релизы.

`game-opus-wt/tmp/lab/`. Протокол игры не меняется: лаборатория не использует WebSocket.

## 1. Идеи (30)

Правила отбора: смешно и весело для компании друзей, без sci-fi, в духе сказочной набережной при ясной погоде. Ничего из
уже сделанного (набережная, карты, рыбалка, аквапарк, колесо, пейнтбол, картинг, катера, «Выше облаков», прятки, крепость,
Fight Club, шторм, пираты, кракен, животные, одежда, уровни, подарки, голос) и ничего из зоны работающих веток: крепость
и Fight Club закрыты; голос, меню, загрузка, бонусы картинга, прятки, гонка катеров, баркас и новая рыбалка не трогаются.

Размер: **S** — до пары дней, клиент и одно-два сообщения; **M** — несколько дней, новое состояние на сервере, правила, тесты;
**L** — неделя и больше или нужен новый мир. Оценка грубая, пересмотрим после выбора.
«Живое» — получится ли показать маленькой 3D-сценой на странице (иначе — иллюстрация, нарисованная кодом).

### Что задевают чужие ветки (учесть при выборе)

- `pet-buddy`, `gull-thief` — животные: пересекаются с `critters`. Делать после слияния. `gull-thief` намеренно ничего не отбирает
  у игрока насовсем: улов, рюкзаки и продажа — зона `fisheco`.
- `fishing-derby` — доска, подиум и награды рыбалки: `fisheco` (опыт, рюкзаки, шансы), `fishstyle` (сеты, скины удочек),
  `barkas` (рейсы в море). Награду придумать вместе с ними, здесь — только значок дня.
- `food-costumes`, `trails`, `umbrella-glider` — гардероб. Аудит просил не плодить дорогие вещи, пока не проверены сочетания
  с катером и сиденьем. Зонтик меняет общую физику (`shared/sim.ts`) — осторожно с «Выше облаков».
- `cafe-rush` — кафе «Чайка», где работает `cards`. Это отдельная комната, но решение за вами.
- `call-to-play` — сбор в круге и ожидание: пересекается с `loading`, переиспользовать `ModeQueue`.
- `titles`, `weekly-cup` — показываются в профиле, которым занимается `menu`.
- `merchant-boat`, `ferry-*` — море и причал у `boats` и `barkas`; только картинка и расписание.

### Что потребует протокола или профиля

Видны другим игрокам, значит нужно поднимать `PROTOCOL_VERSION` до 13 (сведёт главная сессия): `pet-buddy`, `trails`,
`food-costumes`, `umbrella-glider`, `conga-train`, `pyramid`, `twirl-throw`, `prank-shop`, `banner-plane`, `party-for-friend`,
`ping-beacon`, `emote-wheel`, `weekly-cup`, `titles`. Новые поля профиля (питомец, звания, счётчики недели) — только с
нормализацией старых сохранений; `weekly-cup` и `titles` лучше хранить отдельным файлом в `DATA_DIR`, не трогая профили.
Сама лаборатория (этап 2) протокол и профили не трогает.

## 3. Устройство страницы

### Разделы

1. **Шапка** — название, строка «что это», счётчики по статусам (клик = фильтр), значок «режим владельца» с кнопкой «выйти».
2. **Панель фильтров** (прилипает при прокрутке) — статус, категория, «остров и паром», «есть живое превью», поиск по названию
   и тексту, сортировка («ждут решения» — по умолчанию, «дешёвые сначала», «по категориям»), «скрыть решённые».
3. **Сетка карточек** — основная часть; одна колонка на телефоне, 2–4 на компьютере. Пустой результат — «Ничего не нашлось».
4. **Что берём** — свёрнутая сводка внизу: списки «Берём», «Доработать», «На тесте»; кнопка «Скопировать текстом» для чата.
5. **Подвал** — «Как добавить своё» (4 строки), ссылка на доску идей игроков `/ideas/`, ссылка на сырые данные `/lab/api/state`.

Ссылка на отдельную карточку: `/lab/#hot-melon` — страница прокручивается к ней и подсвечивает.

- Для остальных вместо управления — чип статуса и цитата заметки владельца.
- «Не берём» приглушает карточку, «Берём» красит рамку в зелёный.
- Палитра тёплая и дневная, как на концепте `docs/art/plaza-2026-10-02/2-painted.jpg`: сливочный фон, небесный, мандариновый,
  бирюзовый, ягодный акценты; шрифт Rubik; скругления 20 px; никакой тёмной темы и неона.
- Всё доступно с клавиатуры, у кнопок видимый фокус, `prefers-reduced-motion` выключает самозапускающиеся анимации.

### Статусы и решение

Шесть статусов: **идея → прототип → на тесте → берём / доработать / не берём**.

- Без записи на сервере статус задаёт код: есть живая сцена — «прототип», иначе — «идея».
- Владелец нажимает на статус в карточке — запись уходит на сервер сразу, чип меняется без перезагрузки; при ошибке
  возвращается прежний с красной подсказкой. Заметка сохраняется по кнопке «Сохранить» и при уходе из поля.
- «Сбросить» убирает запись, карточка возвращается к статусу по умолчанию.
- Остальные посетители видят изменения сами: страница раз в 20 секунд обновляет решения, пока вкладка открыта.

### Превью

- **Иллюстрация** есть у каждой из 30 идей: набор функций в `client/lab/art.ts` (небо, море, пирс, желейка с шапкой и
  настроением, реквизит). Одна иллюстрация — 10–25 строк. SVG строится только с атрибутами оформления (`fill`, `stroke`,
  `transform`), без `style=` и скриптов, чтобы страница работала под CSP сайта.
- **Живое 3D** — по кнопке. До нажатия three.js не загружается (страница лёгкая и открывается с телефона). Нажатие грузит
  сцену, в карточке на месте картинки появляется холст; мышью (на телефоне — пальцем влево-вправо) сцену можно покрутить.
  Колесо мыши страницу не перехватывает, вертикальный свайп на телефоне листает страницу.
- **Один WebGL на страницу.** Внутри — один `Renderer` игры на невидимом холсте; кадр каждой живой карточки копируется в её
  холст. Одновременно оживают не больше двух карточек (запуск третьей останавливает самую старую), всё замирает, когда вкладка
  скрыта или карточка ушла с экрана. Потеря контекста или отсутствие WebGL — остаётся иллюстрация и подпись «превью не запустилось».
- Каждая сцена — диорама: деревянная площадка посреди моря на небе игры (`makeSky`, `makeSea`) в ясный день. Все прототипы
  выглядят одной семьёй. Желейки — настоящий `Avatar` с настоящими нарядами.

### Как добавить новый эксперимент (для следующих агентов)

1. Создать файл `client/lab/proto/<id>.ts`:
   ```ts
   import type { Experiment } from '../types.ts';
   import { scene, jelly } from '../art.ts';
   export default {
     id: 'my-thing', title: 'Название', category: 'social', size: 'M',
     pitch: 'Что это одной строкой', fun: 'Почему это весело',
     art: () => scene('day', [jelly({ x: 120, y: 120, color: 'berry' })]),
     live: { create(ctx) { /* ctx.THREE, ctx.kit.avatar(), ctx.kit.diorama() … вернуть {scene, camera, update} */ } },
   } satisfies Experiment;
   ```
2. Добавить в `client/lab/experiments.ts` одну строку `import` и одно имя в массив.
3. Идея без прототипа — просто запись в `client/lab/ideas/<категория>.ts` (без `live`).
4. `npm test` проверит реестр: уникальный `id`, все поля, безопасная иллюстрация, а файлы прототипов не тянут `three` и
   `client/render` при загрузке (только `import type`; рабочее берут из `ctx`, так страница остаётся лёгкой).

## 4. Сервер

### Флаг

`LAB` — как `HIDE` и `VOICE`: `1` включает, `0` выключает, без переменной включён только в `npm run dev` (в собранной игре
`npm run play` нужен `LAB=1`). Выключен — `/lab/api/*` и страница из сервера отвечают 404, игра ведёт себя как раньше.
На сайте флаг не включается без «да» владельца.

### Ключ владельца и ссылка

- Ключ — 32 случайных байта (64 hex-знака). Сервер сам создаёт файл `DATA_DIR/lab-key` (права 0600) при первом обращении и
  перечитывает его по времени изменения: удалил файл — завтра будет новый ключ, перезапуск не нужен.
- Ссылку печатает отдельный скрипт, никогда не сервер и не страница: `deploy/lab-link.sh` (по ssh читает ключ на сайте,
  как `../ideas/admin-link.sh`) и `tools/lab/link.mjs` (локально). Формат: `https://game.tired.solutions/lab/#key=<ключ>`.
  Ключ стоит во фрагменте адреса: он не уходит на сервер, в журналы nginx и в Referer. Страница забирает его в
  `localStorage` и тут же убирает из адресной строки.
- Ключ едет только заголовком `x-lab-key`: на изменяющих запросах и на первом чтении состояния (чтобы страница узнала, владелец ли
  ты). Сравнение — по хешам, за постоянное время.
- Ключ не пишется в журнал, в ответы API, в репозиторий и в чат. На неверный ключ — 401 и счётчик: больше 10 за 10 минут
  с одного адреса — 429.

### API (всё под `/lab/api/`, JSON, `Cache-Control: no-store`)

| Метод и путь | Кто | Что делает |
|---|---|---|
| `GET /lab/api/state` | все | `{ ok, owner, updatedAt, decisions }`; `owner: true`, если пришёл верный ключ |
| `PUT /lab/api/decisions/<id>` | владелец | тело `{ status, note?, title? }`; ответ `{ ok, decision }` |
| `DELETE /lab/api/decisions/<id>` | владелец | сбросить решение к статусу по умолчанию |

Ограничения: `id` — `[a-z0-9-]{1,40}`; статус из шести; заметка до 600 знаков (очищается как чат, но без обрезки строк);
`title` до 80 знаков (чтобы по `lab.json` было видно, о чём речь); не больше 200 решений; тело до 2 КиБ; чтения 120 в минуту,
изменения 30 в минуту с адреса. Адрес берётся из `X-Real-IP`, только если запрос пришёл с этой же машины.

### `DATA_DIR/lab.json`

Отдельный файл, профили и миграции не затрагивает; откат кода его не теряет. Запись атомарная (временный файл → fsync →
переименование), перед заменой прежний лежит рядом как `lab.prev.json`. Повреждённый файл откладывается как
`lab.json.corrupt-<время>`, сервер берёт `lab.prev.json` или начинает с пустого.

```json
{
  "version": 1,
  "updatedAt": "2026-10-03T21:14:05.120Z",
  "decisions": {
    "hot-melon": { "title": "Горячий арбуз", "status": "take", "note": "Берём. Таймер 8–15 с.", "at": "2026-10-03T21:14:05.120Z" }
  },
  "log": [ { "id": "hot-melon", "from": null, "to": "take", "at": "2026-10-03T21:14:05.120Z" } ]
}
```

Статусы в файле: `idea`, `prototype`, `testing`, `take`, `rework`, `skip`. Журнал хранит последние 200 изменений.
Для планирования релизов — `node tools/lab/decisions.mjs [путь/к/lab.json]`: сводит реестр и решения в таблицу.

## 7. Риски и вопросы

- **Публичный репозиторий.** Каталог идей попадёт в открытый код. Секретов там нет; ключ и `lab.json` живут только в `DATA_DIR`.
- **Заметки видны всем, у кого есть ссылка.** Подсказка под полем заметки это говорит. Если нужны личные заметки — отдельное поле позже.
- **Страница в сборке.** Без блока nginx на сайте она откроется без решений (см. выше); ожидаемо, пока владелец не скажет «да».
- **Много агентов пишут в один реестр.** Явный список даёт одну-две строки в диффе; конфликты тривиальны.
- **Тяжёлые превью.** Ограничены двумя живыми карточками и запуском по кнопке; на телефоне проверю только «открывается».
- **Голосование друзей в первой версии нет.** Решает владелец; если нужно, добавить как на доске идей (один браузер — один голос).
- **Нужно решение:** ссылка на `/ideas/` в подвале — да или нет; оценки S/M/L принимаем как есть или пересмотрим.
