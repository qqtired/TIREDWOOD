# Статуя на набережной: план

> **Для исполнителя:** выполнять по задачам (superpowers:executing-plans), шаги отмечать `- [x]`.

**Цель:** статуя в полный рост по фото владельца у входа на мостки к маяку. Спецификация:
`docs/superpowers/specs/2026-10-01-statue-design.md`.

**Устройство:** модель собирается офлайн скриптами `tools/statue/` (Python) в `client/assets/statue/`:
геометрия в своём формате и две WebP-текстуры. В игре `client/lobby/statue.ts` грузит модель
и строит постамент, табличку, цветы и подсветку. Коллизия — бокс в `shared/maps/lobby.ts`.

**Технологии:** Python 3.11 (uv-venv): mediapipe 0.10.14, numpy, scipy, scikit-image, xatlas,
fast-simplification, pillow. Игра: TypeScript, three.js 0.186, тесты `node --test`.

## Общие ограничения

- Надпись: `ALWAYS IN OUR HEARTS` (у владельца было «ALWAY», исправлено).
- Нашивка с фамилией пустая.
- Без GLTFLoader и без `blob:`-картинок: CSP сайта `img-src 'self' data:`, `connect-src 'self'`.
- Ассеты импортируются через `?url`: Vite кладёт их в `dist/assets/` с хешем, nginx отдаёт их как immutable.
- В `game-opus/` параллельно идёт выпуск 2 (дурак), другая сессия правит `world.ts`, `lobby.ts`
  и тесты. Свои правки в чужих файлах — точечные (`Edit` по свежему чтению). Всё своё — в новых файлах.
- Выкладка только по «да» владельца.

## Формат `statue.bin` (little-endian)

```
0   char[4]  'STAT'
4   uint32   версия = 1
8   uint32   длина JSON в байтах (N)
12  JSON     { meshes: [{ name, vertices, indices, min:[x,y,z], max:[x,y,z], pos, nor, uv, idx, idx32 }] }
    нули до кратного 4
... данные: pos — int16×3 (−32767…32767 → min…max), nor — int8×4 (xyz, 4-й байт 0),
    uv — uint16×2 (0…65535 → 0…1, v снизу вверх, как в three.js при flipY), idx — uint16 или uint32.
    Смещения pos/nor/uv/idx — от начала блока данных, каждое кратно 4.
```

Модель в метрах, натуральная величина, подошвы на y = 0, лицом к +Z, центр между пятками в x = z = 0.
Сетки: `head` (текстура `head.webp`) и `body` (текстура `body.webp`).

### Задача 2: голова

**Файлы:** `tools/statue/head.py`

**Даёт:** `build_head() -> Mesh(pos, nor, uv, idx), texture: PIL.Image (2048×1024)`, плюс
`HEAD_ANCHOR` — точка шеи, к которой крепится голова в координатах тела.

- [x] Масштаб: межзрачковое расстояние = 0,063 м (центры радужек 468 и 473).
- [x] Силуэт головы на фото: голова (кожа + волосы) против белого фона, одежда ниже линии воротника отрезана.
- [x] r(φ, θ) на сетке 256 × 128: лицо — пересечение луча из центра с сеткой MediaPipe; череп и волосы —
  суперэллипсы по высоте с полушириной из силуэта; уши — выпуклости по силуэту ушей на фото; шея — цилиндр
  до воротника. Разница «лицо − череп» на краю лица гасится на полосе ~3 см.
- [x] Текстура (эквидистантная развёртка): проекция фото спереди с весом по нормали; фон фото заранее
  залит цветом соседних пикселей головы; сзади волосы (тёмно-каштановые с прядями) и кожа (цвет щёк с фото).
- [x] Проверка: рендер спереди совпадает с фото; рендеры в три четверти и в профиль без дыр и швов.

### Задача 3: тело

**Файлы:** `tools/statue/body.py`, `tools/statue/camo.py`

**Даёт:** `build_body() -> Mesh, texture: PIL.Image (2048×2048)`.

- [x] Скелет позы «отдаёт честь» (метры): пятки вместе, носки врозь на ±22°; левая рука по шву;
  правое плечо отведено почти горизонтально и чуть вперёд, предплечье и кисть по одной линии,
  кончики пальцев у правого виска над концом брови.
- [x] SDF: китель (грудь, живот, бёдра, плечевой пояс, подол на y ≈ 0,79), брюки, рукава с манжетами,
  кисти (ладонь с сомкнутыми пальцами и большой палец), берцы с подошвой, воротник-стойка с клапаном,
  погоны, планка, накладные карманы с клапанами, накладки-липучки.
- [x] marching cubes (шаг 4 мм) → упрощение до ~40 тыс. треугольников → xatlas → запекание:
  ММ-14 (4 цвета с фото, «пиксель» 5 мм), олива нашивок, флаг (две приглушённые полосы), шеврон,
  пуговицы, строчки, кожа кистей, кожа берцев, AO по SDF.
- [x] Проверка: рендеры спереди, сбоку, сзади; рука у виска не закрывает лицо.

## Как вышло (отличия от плана)

- Python-окружение — не `tools/statue/.venv`, а зависимости в заголовке скриптов (PEP 723): `uv run`
  ставит их сам. mediapipe — строго 0.10.14 (1.x на macOS падает на старте).
- Масштаб головы — межзрачковое 0,065 м, сетка головы 200 × 100; голова на 5 % крупнее натуры
  (масштаб вокруг шеи), как принято у памятников.
- Камуфляж и нашивки — в `paint.py` (не `camo.py`); пиксель 4,5 мм, доли цветов как на фото.
- Надпись — золотые буквы прямо по полированному граниту, без таблички.
- Найдено при проверке глазами и исправлено:
  - сетка тела была вывернута — three.js отсекал лицевую сторону, сквозь грудь была видна шея (тест на знак объёма);
  - свет сцены второй раз затемнял глазницы с фото — нормали головы размыты;
  - прожекторы снизу пересвечивали лицо — 24 → 16;
  - воротник-стойка был ниже, чем на фото, — поднят по бокам до 1,56 м.
- README (раздел «Набережная») правит сессия выпуска 2 — текст для неё передан.
