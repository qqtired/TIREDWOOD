# Меню игры: профиль отдельно, настройки по категориям

Ветка `rework/menu`. Задание владельца: «профиль отдельно, настройки отдельно, чётко по категориям, удобно, понятно;
в этом же меню проверка своего микрофона».

## Статус / что осталось

- [x] План (этот файл)
- [x] Код
- [x] Проверка в браузере, снимки каждой вкладки (`game-opus-wt/shots/menu/`): компьютер 1600×900 и 1366×768,
  размер 130 %, экран входа, телефон 390×844
- [x] `npm run check && npm test && npm run build`, коммиты

## Решение

Одно меню на Esc (☰ на телефоне): карточка по центру, слева — разделы, справа — содержимое. Игра за меню идёт
дальше (онлайн), фон без размытия, чтобы не есть кадр.

Слева сверху «Продолжить», ниже группы:

- **Профиль:** Обзор (ник с рамкой — как его видят другие, жетоны, уровень и рамки, смена ника) · Рекорды
  (статистика по режимам) · Коллекция (рыбы, альбом, навык рыбалки) · Подарки и коды (подарочный код, код для входа
  с другого устройства, где примерочная).
- **Настройки:** Графика (качество, угол обзора, FPS и пинг) · Звук (общая, эффекты, окружение, без звука) · Голос
  (`mountVoicePanel` из `client/ui/voicepanel.ts`) · Управление (мышь, в прицеле, инверсия, подсказки клавиш на
  экране) · Интерфейс (размер меню и чата, сообщения чата).
- **Справка:** Клавиши.

Внизу — «На набережную» (в режимах) и «Выйти из игры».

Esc в меню прячет меню сразу. Мышь браузер отдаёт только по клику (Esc — не жест), поэтому до клика поверх игры —
короткое «Кликни, чтобы играть»; Esc ещё раз — меню назад. Кнопки «Продолжить» и ✕ захватывают мышь сразу.

Голос: в ветке заглушка `mountVoicePanel(root): () => void` — переносит во вкладку нынешние настройки голоса
(`client/ui/voice.ts`). При слиянии оркестратор подставит настоящую панель агента `voice`.

## Файлы

- новые: `client/ui/menu/menu.ts` (каркас, разделы, Esc, вуаль), `client/ui/menu/settings-panel.ts` (настройки по
  категориям), `client/ui/menu/keys.ts` (справка), `client/ui/menu/gift.ts` (подарочный код в меню),
  `client/ui/menu/menu.css`, `client/ui/voicepanel.ts` (заглушка), `client/ui/records.ts` (рекорды и счёт по режимам —

- `client/settings.ts` — новые поля с нормализацией, старый ключ `opus.settings.v1` читается как был;
- точечно: `client/app.ts` (подключение меню), `client/audio.ts` (громкость эффектов и окружения),
  `client/input.ts` (инверсия), `client/ui/gift-code.ts` (тексты ответов наружу), `client/styles.css` (старые правила
  паузы).

## Чего нет и не выдумываю

- Музыки в игре нет — вместо «музыки» регулятор «Окружение: море, чайки, дождь».
- Отдельной дальности прорисовки нет — её задаёт качество.
- Ники над игроками не прячу: табличка ника несёт значок голоса и нужна в командных режимах.
- Размер всего HUD режимов не меняю: часть подписей стоит по 3D-координатам и съехала бы. Масштаб — для меню, чата,
  жетонов, «кто где» и уведомлений.

## Для слияния

- Новая трасса картинга, курс «Выше облаков» или регаты, новый режим — одна строка в `RECORDS` / `MODE_STATS`
  (`client/ui/records.ts`); поле рекорда — в `Stats` (`shared/economy.ts`), у нового курса — свой ID.
- Строка-шпаргалка клавиш в режиме прячется настройкой «Подсказки клавиш на экране», если у неё класс `key-hint`
  (нынешние `.rc-help`, `.br-help`, `.skill-help`, `.ft-help`, `.ammo-hint` уже в списке, `menu.css`).
- Голос: настоящая панель агента `voice` встаёт вместо `client/ui/voicepanel.ts` с той же подписью
  `mountVoicePanel(root): () => void`. Его кнопка «настройки голоса» открывает меню сразу на «Голосе»
  (`openSettings` в `ensureVoice`, `app.ts`).
- `app.ts`: меню создаётся вместо старой паузы; Esc в открытом меню — в `onKey` перед `active.onKey`; `redeemResult`
  идёт и в меню, и в сцену; `buildSettings` удалён (настройки — `settings-panel.ts`).
