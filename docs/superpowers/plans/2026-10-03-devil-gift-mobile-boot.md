Мобильная работа явно запрошена. Production сейчас не изменяется.

## Решение

Набор «Чертёнок» выдаёт две вещи вместе, носить можно отдельно: h:devil и a:deviltail. Изогнутые алые рога на аккуратном ободке, хвост с мягкой S-дугой и стреловидным концом. Натуральная 3D-геометрия в существующем стиле, без сторонних зависимостей/тяжёлых текстур. Красное на розовом теле — визуальный пример; получение не меняет выбранный цвет или экипировку автоматически.

Общий многократно используемый подарочный код, однократная выдача на профиль. Серверная проверка и ограничение попыток; в клиентском bundle кода нет. Оба предмета не продаются, не выдаются за жетоны, не появляются в карточках/примерке до владения. Повтор не даёт денег/дубликатов. Существующее owned хранит entitlement без новой миграции; при выключении выдачи уже полученные вещи остаются. Флаг GIFTS: DEV on, production по умолчанию off. Root выдаёт владельцу придуманный campaign-код; это не ключ входа/API.

Мобильная рыбалка: проверить конфликт реально показанных слоёв на портретном и горизонтальном телефоне, сократить второстепенные баннеры/подсказки во время вываживания, сохранить понятные touch-действия и доступ к выходу. Десктопный процесс сохранить.

Bootstrap: первый HTML содержит доступный загрузочный экран до большого JS/CSS. Лёгкая анимация и правдивые этапы загрузки, без нарисованного таймером процента. Динамический запуск тяжёлого приложения; убрать экран только после подготовки и первого кадра. Ошибка/медленная сеть оставляют понятный retry, не пустоту; CSP без unsafe-inline script и blob-обходов.

## Дополнение пользователя: голос и круги сбора

- Голос: одна кнопка с микрофоном. Первое включение запрашивает разрешение, дальнейшее удержание передаёт звук; отпускание, потеря фокуса/маршрута выключают передачу. V использует тот же механизм. Настройки доступны из паузы, нет отдельного большого текстового HUD. Ограниченное ожидание подключения и явный повтор после ошибки.
- Публичная индикация: микрофон над говорящим виден и участникам без Voice Mode. Сервер связывает голос с actor ID текущей комнаты; socket ID не используется как ID персонажа. NPC/прятки не раскрываются.
- Соединение: проверить настоящее WebRTC/Opus через локальный coturn с принудительным relay и синтетическим аудиосигналом вместо доступа к микрофону владельца. Зафиксировать выбранный relay-маршрут и декодированный звук. Подготовить отдельную production-конфигурацию; новый публичный сервис/порты требуют разрешения на этот конкретный этап.
