# Выпуск 5: отзывы друзей после первого вечера с выпуском 4

**Цель:** всё, что владелец переслал из чата друзей 02.10.2026 со словами «сделай» / «продумай классную систему»:
доска «Последние входы», честная награда в дураке, автоматы (АФК и «лесенка» шансов), «Press F to pay respects»
у статуи, красивый фон за набережной, катер, аквапарк-паркур, колесо обозрения.

**Как работаем:** код живёт в той же папке, из которой идёт выкладка (`deploy.sh` берёт всё). Каждую задачу доводим до
конца (проверки, тесты, сборка, браузер) и только потом берём следующую: папку можно выложить в любой зелёной точке.
Выкладка — только после нового «да» владельца.

**Порядок:** от быстрого к долгому: 1 → 2 → … → 10.

## Общие правила

- Поменялась физика или формат снимков — `PROTOCOL_VERSION` +1 (один раз на выпуск: 5 → 6).
- Всё, что даёт или берёт жетоны, решает сервер; клиенту не верим.
- Новые точки взаимодействия — только в конец списка (клиенты шлют их номера).
- Файлы статуи не трогаем (`statue*.ts`, `client/assets/statue`, `tools/statue`, `test/statue.test.ts`, `STATUE`):
  «Press F» — отдельным модулем, координаты статуи только читаем.
- Секреты в код и журнал не пишем.
- Проверки после каждой задачи: `npm run check && npm test && npm run build` и браузер (headless Chrome).

### Задача 4: Автоматы — «лесенка»: чем дороже, тем чаще выигрыш и джекпот, но казино в плюсе

Gar_Di_X: «на автоматах с большой стоимостью … комбинаций больше … чтоб хоть какие-то копейки могли ещё падать».
Артём: «шанс джекпота чуть больше на дорогих, и на дорогих больше всяких комбинаций, но без перебора. Чтобы в итоге
казино всегда в выигрыше». Roman: «призы надо везде поднять».

Решение: у каждого автомата свои ленты барабанов (64 положения) и своя таблица выплат в жетонах. Каждый следующий
автомат — на одну комбинацию больше. Плюс, как и раньше, 5 % каждой ставки — в банк джекпота.

| Автомат | Ставка | Новая комбинация | Выигрыш | Джекпот | Возврат | С банком |
|---|---|---|---|---|---|---|
| Копеечка | 1 | — | 20,5 % | 1 из 1214 | 89,5 % | 94,5 % |
| Пятак | 5 | 🍒 на первом барабане — 1 | 32,2 % | 1 из 1040 | 89,9 % | 94,9 % |
| Червонец | 10 | 7️⃣ на первом барабане — 4 | 35,9 % | 1 из 892 | 90,7 % | 95,7 % |
| Четвертак | 25 | ⚓⭐7️⃣ вперемешку — 30 | 40,3 % | 1 из 764 | 91,0 % | 96,2 % |
| Полтинник | 50 | 🍒🍋🔔 вперемешку — 20 | 53,1 % | 1 из 669 | 88,6 % | 96,6 % |

(«С банком» — если весь вечер играть только на этом автомате: 5 % в банк и затравка банка до 1000 после джекпота
на Полтиннике. Было: 87,4 % без банка на всех.)

- [x] `shared/slots.ts`: `REELS[m][барабан][символ]` (сумма 64), `PAYTABLES[m]` — список комбинаций с выплатой в
      жетонах; `evaluate(m, reels)` → `{win, line, jackpot}` (платит лучшая комбинация); `symbolFromRoll(m, reel, r)`.
- [x] Сервер: `roll()` 0..63, выплата `win` из таблицы; джекпот как был (ставка ×100 + доля банка).
- [x] Клиент: на каждом автомате своя табличка выплат (в жетонах); эффекты — по выигрышу в жетонах, мелкий
      выигрыш (меньше ставки) — короткий звон без фонтана.
- [x] Тест: полный перебор 64³ на каждом автомате — точные суммы выплат, частота выигрыша, джекпота; возврат с банком
      растёт от автомата к автомату и везде < 100 %; добавки — по одной на автомат.
- [x] README (таблица), design.md.
