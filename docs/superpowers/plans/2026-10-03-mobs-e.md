# Мобы «Крепости», набор E — морской десант и супер-босс (`rework/mobs-e`)

**Статус:** в работе.

## План
1. Общие заготовки `client/fort/mobs/sea-shapes.ts`: раскраска вершин по месту, трубки переменной толщины, треуголка.
2. `crew-crab.ts` — краб-абордажник (экипаж, ZF_CREW): ходьба, атака клешнями, прыжок из лодки (ZS_HOP), лазание по
   морской стене, гибель. Два варианта; в орду обычных шаркунов не попадает (weight 0), крепость берёт его по ZF_CREW.
3. `sea-boat.ts` — пиратская шлюпка: корпус, вёсла гребут, флажок с банкой варенья, фонарь-банка (glow), крабы в
   треуголках по скамьям — сколько их, столько показываем (stage; пока его нет в MobAnim — 3). Высадка, отплытие, тонет.
4. `kraken-tentacle.ts` — щупальце из пяти звеньев: покачивается, замах заранее и удар, лежит «открытым», рубят — уходит
   под воду. Присоски, капли варенья, светящийся кончик.
5. `kraken.ts` — Кракен в капитанской треуголке: всплыл (можно бить), нырок (шляпа остаётся плавать), плевок, «открыт»,
   ярость (крышка-шляпа подпрыгивает, веки злые), гибель.
6. `set-e.ts`, тест `test/mobs-e.test.ts`, снимки на стенде, отчёт.
