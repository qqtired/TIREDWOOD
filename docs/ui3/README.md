# UI 3.0 «Веранда v3» — вход для следующего агента

Редизайн HUD поверх игры; окна (`data-skin='retro2'`) не трогали. Решения владельца дословно и история — `brief.md`,
опись по коду — `inventory-code.md`, сверка упущенного HUD — `audit-2026-10-31.md`. Лаборатория — `lab/ui3/v3/`
(раздел «Режимы в деле»), вывески — `lab/ui3/signs/`.

## Как включается

- Флаг сервера `UI3` — только явная `1`, даже в `npm run dev` (`shared/ui3.ts`). Сервер отдаёт `ui: 3` в `/health`
  (`server/hub.ts`), браузер узнаёт его до загрузки игры (`client/layout-boot.ts`, как раскладку площади), а
  `client/startup-game.ts` ставит `data-hud='veranda3'` на `<html>` и подключает перестройки разметки.
- Без флага — HUD «Светлый» и прежние вывески, ровно как раньше. На сайте — строка `Environment=UI3=1` в
  `deploy/game-opus.service` после «да» владельца.
- Посмотреть: `PORT=<порт> DATA_DIR=$(mktemp -d) UI3=1 <флаги сайта из deploy/game-opus.service> npm run dev`.

## Где что лежит

- Стили HUD v3 — `client/ui/kit/hud3/veranda3*.css`, копии `lab/ui3/v/veranda3*.css`. Меняешь одно — поменяй второе:
  `cmp` по каждой паре должен молчать. Подключены последними, после стилей игры, как в лаборатории.
- Перестройки разметки, которых не сделать одним CSS (как `lab/ui3/v/veranda3-msg.js`), — `client/ui/hud3.ts`, разбор
  текста — `client/ui/hud3-text.ts`: личные награды — в «кошелёк» у жетонов, ник в новостях цветом, значок у системных
  строк чата и дока «Ракушки».
- Вывески и табло — `client/ui/signs3.ts` (`SIGNS3 = UI3`), рядом в каждом файле — прежний вид.
- Табло «Загадки» в виде «Панели» — по умолчанию, без флага: `client/lobby/quiz/ui/board-riddle2.ts`; откат —
  `RIDDLE2 = false` в `board-riddle.ts`. Стенд — `tools/quiz-board/`.
- Тесты — `test/ui3-flag.test.ts`, `test/quiz-board2.test.ts`.

## Тонкие места

- В лаборатории холсты сняты картинками (`<img>`), в игре это `<canvas>`: правила под картинки проверяй на холсте.
  Так было с мини-картой картинга; к тому же она рисует дорогу цветами плашки (`client/race/hud.ts`, `token()`), поэтому
  у `.rc-map` в v3 светлые значения.
- Экран входа, экраны загрузки между режимами и примерочная (`.k-hudctx`) в первый шаг не входят: в конце
  `veranda3.css` им возвращены значения «Светлого». Цвет режима (`--mode-h`) пересчитан по `html[data-room]`.
  Проверка — вычисленные стили всех элементов при `light` и `veranda3`: 0 отличий.
