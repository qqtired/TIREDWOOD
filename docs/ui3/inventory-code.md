# UI 3.0 — опись интерфейса по коду

Отчёт Codex (Astra 6 Max, только чтение) для брифа `docs/ui3/brief.md`, 30.10.2026, `main` 13913f8. Пути ссылок — от этой папки.

Опись по `main`, коммит **`13913f8`**. Файлы не менял. Проверены исходники, подключения интерфейса и координаты карты; сервер, браузер и проверки сборки не запускались. Флаги приняты из задания.

Важные границы:

- **Зелёные окна включают Esc, Tab, торговцев и большинство итогов режимов.** Нативный `dialog` используется не везде: встречается `div.k-scrim`.
- **Радио лодки — светлая панель HUD**, не зелёное окно.
- **Верх крепости, мини-карта и щит имеют собственную тему Dungeon**, хотя стоят в слотах кита.
- **Аркада, автомат разминки пейнтбола, мобильное управление и «Рыба в руках» остались вне общего оформления.**
- При `QUIZ=1` «Ракушка» заменяет прогулочный катер «Ласточка».

Пути в основных таблицах — относительно [client/](../../client). Сокращения CSS:

- **K** — [ui/kit/kit.css](../../client/ui/kit/kit.css)
- **C** — [ui/kit/combat.css](../../client/ui/kit/combat.css)
- **M** — [ui/kit/modes.css](../../client/ui/kit/modes.css)

`HUD-светлый` ниже обозначает размещение в общих HUD-слотах; собственное оформление внутри отмечено в колонке «На ките?». Canvas внутри экранной мини-карты остаётся HUD; текстуры на объектах сцены обозначены как `мир (3D/canvas)`.

```sh
FORTRESS=1 FISH2=1 SKILL=1 BOATRACE=1 HIDE=1 STORM=1 PIRATES=1 \
```

Открыть `http://localhost:5191/?debug`. В консоли:

