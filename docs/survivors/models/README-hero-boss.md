# «Подземелье»: герой и босс (Blender → GLB)

Две модели со скелетом и действиями для режима «Подземелье»: герой **Фонарщик** (`hero`) и босс **Старый Повидл** (`boss`).
Сделаны в Blender 5.2 скриптами через Blender MCP, пересобираются одной командой.

| | Фонарщик (`hero`) | Старый Повидл (`boss`) |
|---|---|---|
| GLB | `docs/survivors/models/hero.glb` | `docs/survivors/models/boss.glb` |
| Исходник | `docs/survivors/blender/hero.blend` | `docs/survivors/blender/boss.blend` |
| Скрипт сборки | `tools/survivors/blender/hero.py` | `tools/survivors/blender/boss.py` |
| Превью | `previews/hero-3q.png`, `hero-top.png`, `hero-poses.png` | `previews/boss-3q.png`, `boss-top.png`, `boss-poses.png` |

Пересобрать (в Blender с MCP, в пустом файле — скрипт чистит сцену):

```python
exec(open('/Users/tired/Desktop/game-opus-survivors/tools/survivors/blender/hero.py').read(), {'STAGE': 'all'})
```

`STAGE: 'build'` — только модель и анимации, `'all'` — ещё превью, `.blend` и GLB.

Или в фоновом Blender без общего lock (из корня репозитория; аргумент — STAGE, по умолчанию `all`):

```sh
tools/survivors/blender/bg.sh tools/survivors/blender/boss.py all
```

Босс после полировки (10.10, 19:20) собран именно так.

## Общее для обеих моделей

- Метры. Стоит на полу: y = 0 в three.js (z = 0 в Blender). Смотрит вперёд по **+Z three.js** (−Y Blender).
  Правая рука героя — сторона −X three.js.
- GLB самодостаточный: без внешних файлов, без текстур и UV, без камер и ламп. Один `SkinnedMesh` на модель,
  разбит на примитивы по материалам (1 материал = 1 draw call).
- Действия — отдельные клипы `gltf.animations` с именами `hero_*` / `boss_*`, 24 fps, сэмплированы покадрово.
  Ключи на каждом кадре, поэтому интерполяция three.js по умолчанию подходит.
- Цвета — Principled BSDF (`baseColorFactor`, `roughness`, `metalness`). Свечение — `emissive` +
  `KHR_materials_emissive_strength` (three.js читает его сам). Bloom не обязателен: эмиссия уже яркая.
- Двусторонний материал только там, где виден тонкий лист (`hero_apron`, `boss_throat`). Остальные — `side: FrontSide`.
- Кость `root` ни к чему не привязана и в обычных клипах стоит на месте: двигать персонажа нужно узлом-арматурой
  (`hero_rig` / `boss_rig`), а не костью. Анимации «на месте» (in place).

### Подключение в three.js

```ts
const gltf = await new GLTFLoader().loadAsync(new URL('./hero.glb', import.meta.url).href);
const root = gltf.scene;                       // узел hero_rig → кости + SkinnedMesh
const mixer = new THREE.AnimationMixer(root);
const clip = (n: string) => THREE.AnimationClip.findByName(gltf.animations, n);
const idle = mixer.clipAction(clip('hero_idle')).play();
// разовое действие поверх: play().setLoop(THREE.LoopOnce, 1); clampWhenFinished = true для смерти
// смена: next.reset().play(); prev.crossFadeTo(next, 0.15, false)
```

Проверено загрузкой в three.js 0.186 (node, `GLTFLoader.parse`): все клипы, кости, скиннинг, габариты по кадрам.

## Фонарщик — `hero`

Коренастый шахтёр 1,54 м: каска с лампой, борода и усы, кожаный фартук с лямками крест-накрест, ремень с
подсумками и гаечным ключом, большие перчатки, сапоги. В правой руке — латунный фонарь на цепи из 4 звеньев.
Сверху читаются каска с горящей лампой, белые плечи, фартук и фонарь сбоку.

- **Треугольники:** 7 998 (вершин 4 252).
- **Габариты:** высота 1,54 м; в покое ширина 0,93 м вместе с фонарём (без фонаря ~0,6), глубина 0,54 м.
- **Кости (22):** `root`, `hips`, `spine`, `chest`, `head`, `upper_arm_r/l`, `forearm_r/l`, `hand_r/l`,
  `thigh_r/l`, `shin_r/l`, `foot_r/l`, цепь `chain_0`…`chain_3` (от кулака вниз) и `lantern`.
  Начало кости `lantern` — верхнее кольцо фонаря, кость идёт вниз к шипу (длина 0,43 м). Центр стекла фонаря —
  локальная точка (0, 0.21, 0) кости `lantern`.
- **Материалы (10):** `hero_skin`, `hero_hair` (борода, брови, глаза), `hero_helmet`, `hero_brass` (фонарь, пряжки,
  обод каски), `hero_iron` (цепь, ключ), `hero_apron` (двусторонний), `hero_leather` (сапоги, перчатки, ремни),
  `hero_shirt`, `hero_pants` (штаны и шарф), `hero_glow` (стекло фонаря и лампа каски: тёплый янтарь, сила 6).

### Действия (24 fps)

| Клип | Кадров | Секунд | Цикл | Что происходит |
|---|---|---|---|---|
| `hero_idle` | 48 | 2,00 | да, бесшовно | Дыхание, покачивание головы, фонарь чуть раскачивается в руке |
| `hero_run` | 16 | 0,67 | да, бесшовно | Бег: 2 шага за цикл, наклон вперёд, фонарь болтается с запаздыванием |
| `hero_dash` | 12 | 0,50 | нет | Рывок: низкий выпад вперёд (кадры 2–8), фонарь отлетает назад |
| `hero_swing` | 20 | 0,83 | нет | Стартовая атака: рука вытянута вправо, корпус делает полный оборот против часовой (вид сверху), центр фонаря летит по кругу радиусом ~1,1 м на высоте ~0,93 м. Оборот — кадры 2–16 (спереди фонарь проходит около кадра 7) |
| `hero_strike` | 32 | 1,33 | нет | Заряжаемый удар Q: замах над головой (0–10), удержание (10–14, можно держать кадр 12 пока идёт заряд), удар фонарём в землю **на кадре 17 (0,71 с)**: низ фонаря в точке ~(−0,44; 0; 0,79) — 0,8 м перед героем, чуть правее, возврат (23–32) |
| `hero_hit` | 10 | 0,42 | нет | Отшатывается назад, фонарь дёргается |
| `hero_death` | 44 | 1,83 | нет (clamp) | Отдача, колени подламываются, падает на спину (на земле с кадра ~27), фонарь падает рядом |

Все разовые клипы начинаются и кончаются позой покоя (кадр 0 `hero_idle`), поэтому сшиваются короткой
перекрёстной сменой 0,1–0,15 с. Цепь в idle/run/dash/hit/death посчитана простой физикой (маятник с весом фонаря),
в swing/strike — по траектории; фонарь не уходит под пол.

### Заметки для встраивания

- **Свет фонаря:** настоящий `PointLight` (тёплый янтарь, ~#ffb04a) повесить на кость `lantern` в точку (0, 0.21, 0) —
  он будет качаться вместе с фонарём. Лампа каски — точка (0, 1.43, 0.22) в позе покоя (в системе three.js);
  если нужен второй свет, прицепить к кости `head` через `head.worldToLocal`. Лампы гасить яркостью, не `visible`.
- **Удар по кругу** (`hero_swing`) крутит кость `hips` на 360°: это полноценный оборот всего тела, не наложение.
  Если атака должна идти во время бега, проще проигрывать её целиком 0,8 с (как в Army of Ruin), либо
  смешивать только верхние кости (`spine`, `chest`, руки, цепь) — тогда фонарь опишет полукруг, без оборота.
- **Металл:** `hero_helmet`, `hero_brass`, `hero_iron` металлические 0,45–0,6. Без `scene.environment` металл
  в three.js темнеет — либо дать окружение (PMREM от `RoomEnvironment`, дёшево), либо после загрузки снизить
  `metalness` до ~0,2.
- **Бюджет:** 10 draw calls, 22 кости, 7 998 треугольников. Если нужно меньше вызовов — материалы можно свести
  к 4–5 (цвета вершин) вторым проходом.

## Старый Повидл — `boss`

Огромный пещерный червь из норы. Голова 4 м в ширину: валун из каменных плит, спереди круглая пасть с двумя
кольцами зубов, по краю — четыре каменные губы на шарнирах. Две пары сиреневых светящихся глаз в щели за губами
(видны сверху). Тело — 11 сегментов: кольца из 3–6 рваных каменных плит разной ширины (часть расколота надвое),
с фаской и сколами; камень холоднее и темнее пола пещеры, чтобы червь не сливался с полом. Между плитами и снизу —
тёмное глянцевое варенье; светятся только тонкие швы-трещины между плитами (на стыках сегментов, между плитами
кольца, поясами плит головы), глаза и — слабо — капли. Капли и пятна варенья тёмные (без «слизи»). Сверху в позе
покоя читаются макушка из плит, глаза, светящиеся швы и пасть.

- **Треугольники:** 17 506 (вершин 9 199).
- **Длина:** 16,15 м (голова 3,5 м + 11 сегментов по 1,15 м). Голова 4,0 × 3,7 × 3,5 м, радиус тела 1,64 м у шеи →
  0,42 м у хвоста.
- **Габариты в позе покоя клипа `boss_idle`:** червь торчит из норы, над полом ~10 м тела; центр головы на высоте
  4,75 м прямо над началом координат, макушка ~6,6 м, низ головы ~2,9 м. Нора — в точке **(0, 0, −4,6)** three.js
  (4,6 м за началом координат). В bind-позе (без анимации) червь лежит прямо вдоль −Z three.js.
- **Кости (17):** `root` → `body_11` (хвост) → … → `body_01` → `head` — цепь из 12 костей (+ `root`),
  и 4 челюсти-губы `jaw_u`, `jaw_d`, `jaw_l`, `jaw_r` (дети `head`). Кость `head` идёт от шеи к кончику пасти
  (длина 3,5): **кончик пасти — локальная точка (0, 3.5, 0) кости `head`**, центр головы — (0, 1.65, 0).
  Сегменты анимируются поворотом, сдвигом и масштабом (дыхание, «глоток» перед плевком).
- **Материалы (8):** `boss_stone` (#6F6D6A), `boss_stone_dark` (#4B4947) — плиты; `boss_jam` (#4A1A63,
  roughness 0,2, без свечения) — тело между плитами и пятна; `glow_jam` (#B57BFF, свечение 0,8 — имя и цвет из
  палитры брифа) — швы-трещины и глаза; `boss_mouth` (губа-валик), `boss_throat` (тёмная глотка, двусторонний),
  `boss_teeth`, `boss_drip` (#2E0E42, глянец, свечение 0,15 — капли).

### Действия (24 fps)

| Клип | Кадров | Секунд | Цикл | Что происходит |
|---|---|---|---|---|
| `boss_idle` | 72 | 3,00 | да, бесшовно | Высунулся из норы, покачивается вбок, по сегментам бежит волна дыхания, пасть чуть открывается |
| `boss_move` | 48 | 2,00 | да, бесшовно | Ползёт по полу боковой волной (длина волны 8 м). Хвост с ~12 м уходит под пол. Анимация на месте: волна «стоит» на земле при скорости движения **4 м/с** — с этой скоростью нет проскальзывания |
| `boss_emerge` | 48 | 2,00 | нет | Из-под земли (кадр 0 — весь под полом) вырывается пастью вверх: кончик пасти пробивает пол на **кадре 8**, голова целиком снаружи к кадру 14, рык с раскрытой пастью (22), выгибается и садится в позу покоя (48 = кадр 0 `boss_idle`) |
| `boss_burrow` | 40 | 1,67 | нет | Привстаёт (0–9), кивает вниз и уходит обратно в нору: голова скрывается к кадру ~30, целиком под полом к 36–40 |
| `boss_slam` | 48 | 2,00 | нет | Поднимается и откидывается назад (0–17), бьёт головой о землю на **кадре 22 (0,92 с)**: голова ложится на пол перед началом координат: центр головы ~1,9 м вперёд, кончик пасти ~(0; 0,4; 3,1); держит до 30, возврат к 48 |
| `boss_spit` | 36 | 1,50 | нет | Откидывается, вздутие «глотка» бежит от хвоста к голове, на **кадре 15 (0,63 с)** выпад с широко раскрытой пастью — точка вылета ≈ (0; 4,4; 2,9) = кончик пасти; возврат к 36 |
| `boss_roar` | 60 | 2,50 | нет | Голова вверх, пасть нараспашку (12–44), мотает головой; возврат к 60 |
| `boss_death` | 72 | 3,00 | нет (clamp) | Бьётся (0–26), валится вперёд на пол (26–56), лежит с открытой пастью, чуть оседает. Конец: центр головы ~(0; 1,7; 2,3) |

Все разовые клипы начинаются и кончаются кадром 0 `boss_idle` (кроме emerge — начинается под землёй,
burrow — кончается под землёй, death). `boss_move` — отдельная поза «лёжа»: между move и остальными лучше
переходить через `boss_burrow` → `boss_emerge` или перекрёстной сменой ~0,5 с.

### Заметки для встраивания

- **Нора.** Во всех клипах, кроме `boss_move`, тело уходит в пол в точке (0, 0, −4,6) — части ниже y = 0 должен
  закрывать пол. Под это место нужна декаль норы / кольцо земли ~4,5 × 6 м с центром около (0, 0, −4,0), иначе
  виден чистый срез тела о пол. При `boss_emerge` пасть пробивает пол примерно в (0, 0, −5,9) — сюда ударную волну
  и крошку камня.
- **Хитбокс.** Голова в покое висит на 4,75 м: при камере 55° её экранная позиция сдвинута вверх от точки на полу.
  Попадания удобнее считать по проекции головы на пол (позиция объекта) и по точке удара в `boss_slam`.
- **Свечение.** Эмиссия ничего не освещает: при желании — один `PointLight` сиреневого цвета (~#a650ff) на кость
  `head` и тёплый свет арены. Плиты матовые, без металла — от окружения не зависят. Глянец `boss_jam` лучше всего
  читается с картой окружения (`scene.environment`), без неё варенье просто тёмно-фиолетовое.
- **Бюджет:** 8 draw calls, 17 костей, 17 506 треугольников, GLB 0,9 МБ (ключи на каждом кадре; можно сжать
  `gltf-transform resample` вторым проходом).
- **Губы** можно открывать и кодом: шарнир у каждой губы — вокруг её локальной оси X (кость смотрит от шарнира
  к краю пасти, Z — наружу от оси пасти).

## Что получилось слабее и что можно доделать

- **Герой:** у плеча виден шов, где рукав входит в «шар» плеча; пальцев нет (перчатки-рукавицы); лицо простое
  (нос, глаза, брови, усы, борода) — на расстоянии игры читается, крупным планом проще концепта.
  Металл каски и фонаря без окружения в three.js темнеет (см. выше).
- **Босс:** плиты всё ещё мягче и округлее острых каменных глыб концепта; швы на стыках сегментов идут ровными
  кольцами (стык виден по всей окружности); при широком открытии (`roar`) губы раскрываются воронкой, как у миноги. `boss_burrow` — уход
  назад в нору хвостом вперёд, а не нырок головой в новую точку (так босс исчезает там же, где стоял).
- Оба скрипта детерминированы (фиксированный seed), пересборка даёт тот же результат.
