# Примеры продуктового ревью в lab

Локальное развитие `/lab/`: восемь отобранных примеров из трёх дополнительных проходов продуктового исследования.
Это не перенос новых механик в действующие режимы и не решение владельца «Берём».

## Состав

| № | Карточка | Что показывает |
|---|---|---|
| 31 | Мозаика бухты | Живой выбор, поворот и размещение плиток |
| 32 | Краска и Хлопок | Живой контрприём против летящего снаряда |
| 33 | Конкурсный садок | Живой выбор трёх рыб: вес против разнообразия |
| 34 | Собери свой поплавок | Живая сборка внешнего вида и проверка поклёвкой |
| 35 | Чужой билет | Иллюстрация и правила короткой социальной дедукции |
| 36 | Ринг трёх приёмов | Иллюстрация другого условия победы в Fight Club |
| 37 | Барон: спасти ворота или открыть ядро | Иллюстрация цены защитного контрприёма |
| 38 | Сценка из трёх кадров | Иллюстрация авторской покадровой сценки |

Новые карточки отмечены `New`; одноимённый фильтр показывает только этот отбор. Раскрытие «Что пробуем и как
выбирать» содержит интересный выбор, границы примера, вопрос повторного плейтеста и первичные референсы.
`research.sourceId` связывает карточку с исходной рекомендацией исследования. Поиск учитывает направление и референсы.

## Границы

- Старые 30 ID и номера сохранены, решения владельца не переназначаются.
- Новые карточки получают обычное начальное состояние: «Прототип» при наличии живой сцены, иначе «Идея».
- Сцены локальны: без настоящего улова, жетонов, наград, покупок, сетевой партии и записи профиля.
- Используется существующий stage: three.js загружается по нажатию, одновременно живут не больше двух превью.
- Прототипы используют игровой `kit3d`, собственные SVG в стиле каталога и простые геометрические объекты.
- Сцена должна останавливаться и освобождать ресурсы обычной кнопкой закрытия. Для повторной проверки есть сброс.

## Файлы и проверка

Реестр — `client/lab/experiments.ts`, описание карточки — `client/lab/types.ts`, подача и фильтр — `page.ts` / `lab.css`.
Четыре иллюстрированные идеи — `client/lab/ideas/research.ts`; живые сцены — `client/lab/proto/research-*.ts`.
Чистые правила — `shared/lab-*.ts`, их проверки — `test/lab-*.test.ts`.

Приёмка: реестр и чистые правила; затем один общий `npm run check && npm test && npm run build` на Node 24.
В собранном локальном `/lab/` с временным `DATA_DIR`: New → запуск каждого из четырёх примеров → действие мышью →
понятный результат → сброс → закрытие. Дополнительно проверить фильтр/поиск/референсы, прежний прототип и ширину 390 px.

Выкладка, изменение настоящих решений lab и запуск сетевого плейтеста в этот пакет не входят. Перед выпуском нужны
обычные проверки выпуска проекта. Сохранённые игроками вещи и прогресс не меняются.
