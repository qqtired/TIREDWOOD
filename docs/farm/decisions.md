# Ферма — решения владельца (10.10.2026)

Источник: ответы владельца на 20 вопросов в треде проекта. Документ v10 — `design-v10.md`; где расходится с этим файлом, прав этот файл.

1. **Тема:** уютная ферма, ТОЧНО без sci-fi и неона. Рабочее название «Ферма» (не «Кибер-ферма»). Сказочные культуры (кристальный цветок, лунный лотос) — в духе «сказочного» стиля игры, без неона.
2. **Локация:** отдельная, вход через калитку/ворота на площади, экран загрузки.
3. **Копии:** одна локация-инстанс (одна комната), авто-копий нет.
4. **Объём:** всё сразу (грядки, культуры, NPC, инструменты, колодец, помощь, Фургон, заказы, босс, репутация, свин, компост, пчёлы, достижения, косметика, питомцы).
5. **Валюта:** общие жетоны 🪙; числа документа слегка уменьшить единым коэффициентом K (выбор ведущего по симуляции).
6. **Уровень:** свой уровень фермы 1–13; общий уровень игрока получает немного опыта со сборов.
7. **Ранние гейты:** на усмотрение ведущего (предварительно: Лейка 2 → ур. 8, Лейка 3 → 10, Сумка 3 → 10, Компост → 12; достижения «Терпение», «Пчелиный друг» → 10, «Ботаник» → 13).
8. **Ноги/обувь:** слот «низ» — нижняя часть желейки как штаны (джинсы, комбинезон, сапоги — как окраска/надевашка нижней половины).
9–17. На усмотрение ведущего (повторы наград, мёртвые пороги 15/20, полив, помощь, грабли, сумка, посадка, «Семена», босс).
18. **Уведомления:** только внутриигровые (тост + строка при входе), без браузерного push.
19. **3D:** оптимально — на усмотрение ведущего.
20. **Питомцы:** ходячие, с анимациями idle / follow / happy.
