# Вывески набережной в стиле «Ретро-парк 2.0» (шкурка Г) — токены

Источник правды — `lab/ui/kit/tokens.css`, блок `[data-skin='retro2']` в коммите `adf75a2abe91d339e6ca9e85ff7306c06ec748e5` (бывшие ветка `mode/ui` и тег `ui-review-v2`).
Живой образец — https://tired.solutions/tech/tiredwood-ui-v2/ (карточка «Г · Ретро-парк 2.0», окна и плашки).
Владелец 11.10: «За вывески берём вариант ретропарк 2.0». Шрифт заголовков для всего UI он ещё не подтвердил —
пока это Rubik Mono One; если сменит, меняется только `title.font` ниже.

## 1. Шрифты

| Роль | Шрифт | Начертание | Регистр, трекинг |
|---|---|---|---|
| Заголовок вывески | **Rubik Mono One** | 400 (он один, он жирный сам) | ВЕРХНИЙ, `letter-spacing: .01em`, `word-spacing: -.3em` (у моноширинного широкий пробел) |
| Строка статуса, подписи | **Rubik** | 700 (числа — 800) | как есть, `font-variant-numeric: tabular-nums` |
| Надзаголовок (над названием, по желанию) | Rubik | 800 | ВЕРХНИЙ, `letter-spacing: .08em`, цвет режима |

Rubik в игре уже есть: пакет `@fontsource/rubik` 5.3.0, подключены 400/500/700/900 в `client/startup-game.ts`; 600 и 800 есть в том же пакете — достаточно добавить `import '@fontsource/rubik/800.css'`.
**Rubik Mono One в игре нет.** Чтобы вывески рисовали его, нужен файл woff2 (кириллица + латиница) в `client/assets/fonts/`.
Пакет `@fontsource/rubik-mono-one` или скачивание с Google Fonts (лицензия OFL) — только по «да» владельца.
Пока файла нет — запасной вариант: Rubik 900, ВЕРХНИЙ регистр, `letter-spacing: .02em`.
Канвас: перед отрисовкой текстуры дождаться `document.fonts.load('400 96px "Rubik Mono One"')`, иначе подставится запасной шрифт.

## 3. Форма щита

В CSS-пикселях окна UI (для текстуры — умножить по таблице в §5):
- радиус углов **12**;
- кант **2 px `cream`** + снаружи **1 px `outline`**;
- тень (если щит висит на стене, а не отдельно стоит): `0 16px 36px rgba(3,25,23,.36)` — в 3D заменить мягкой подложкой/AO, не настоящей лампой;
- **маркиза** — узкая полоса по верхнему краю щита: высота **10**, полосы шириной **22**, чередование `coral` / `cream`, без фестонов (прямой низ);
- **лампочки** — только у главных вывесок входов в режимы: тёмная кайма `outline` 7 px вокруг щита, по ней точки `lamp-dot` диаметром 3 с шагом ~14, свечение как выше. В 3D — эмиссивные точки или текстура, **не настоящие источники света** (`docs/optimization.md`). Мигание — яркостью, не `visible`.

## 4. Раскладка: иконка + название + строка статуса

```
┌▀▄▀▄▀▄▀▄▀▄▀▄▀▄▀▄▀▄▀▄▀▄▀▄▀▄▀▄▀▄▀▄┐  ← маркиза 10
│ (◉)  РЫБАЦКИЙ ПИРС            │
│      идёт клёв · 3 рыбака  ●  │  ← статус, точка цвета good/bad/gold
└───────────────────────────────┘
```
- **Иконка** слева, круг: фон `radial-gradient(circle at 35% 30%, #fff8e6, #f1dcb0 70%)`, кольца `0 0 0 2px coral, 0 0 0 4px cream`.
  Картинка — из набора `client/assets/ui/icons/<id>.webp` (88 иконок imagegen, без надписей): рыбалка `float`, ферма `farm-gate`,
  подземелье `dungeon`, картинг `kart`, регата `regatta`, аквапарк `slide`, крысиные бега `rat`, рулетка `roulette`, карты `cards`,
  маяк `lighthouse`, «Выше облаков» `bell-cloud`, прятки `hide-box`, пейнтбол `paint`, крепость `gold`/`horn`, рекорды `records`, кто онлайн `online`.
- **Название** — Rubik Mono One, `text`, тень `0 2px 0 outline`. Одна строка; длинное — сократить, а не уменьшать кегль.
- **Строка статуса** — Rubik 700, `text-dim`, одна строка: живое состояние («идёт заплыв · 2 игрока», «закрыто до 19:00»).
  Справа точка 10 px: `good` — открыто/свободно, `gold` — идёт сейчас, `bad` — закрыто. Числа — Rubik 800.
- Отступы внутри: 16 по краям, 12 между иконкой и текстом, 4 между названием и статусом.

## 5. Размеры для вывесок в мире

Пропорции в «CSS-пикселях» UI → для текстуры канваса умножать на **4** (чётко на 2K вблизи), mipmaps включить.

| Вывеска | Щит, м (ш×в) | Канвас, px | Иконка | Название | Статус |
|---|---|---|---|---|---|
| Главный вход в режим (с лампочками) | 2,4 × 0,8 | 1536 × 512 | 360 | 112 px | 56 px |
| Обычный павильон / киоск | 1,6 × 0,55 | 1024 × 352 | 240 | 80 px | 40 px |
| Табличка-указатель | 1,0 × 0,32 | 768 × 256 | 160 (или без иконки) | 64 px | — |
| Доска «Топ игроков» / «Кто онлайн» | 1,8 × 1,2 | 1024 × 683 | заголовок-плашка как у обычной вывески; строки — Rubik 700 44 px, своё место — `gold`, ник — цвета ников UI (`#ffb36b #a2f0b8 #c4ccff #ffa3b4 #ffe58c #9fe3da`) |

Масштаб кантов и радиусов в канвасе — тот же множитель (×4): кант 8 px cream + 4 px outline, радиус 48, маркиза 40 px с полосами 88.
Минимум читаемости: название ≥ 64 px на канвасе, статус ≥ 40 px.

## 6. Чего не делать
- Lobster и любые рукописные шрифты — нет (владелец против).
- Надписи на картинках imagegen — нет; текст рисуется канвасом поверх.
- Настоящие лампы в вывесках — нет; лампочки — эмиссив.
- Сине-жёлтые сочетания на вывесках, флажках, лодках — нет.
