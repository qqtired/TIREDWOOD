# «Банан за катером» — вход для следующего агента

Идея В-7 со страницы `lab/ideas/`, выбрана владельцем 31.10.2026: «Любая лодка тянет надувной банан на троих. Водитель
резко поворачивает, седоки держатся на A/D. Упал — всплеск и 5 секунд на «E — обратно». Кто дольше продержался —
строкой в чат.» Зачем: «Черноморская классика: смешно и видно с пирса. Нужна модель банана с анимациями.»

## Как включается и где смотреть

- Флаг сервера `BANANA` (нужна `ISLE`, а ей — `FISH2`): без переменной — только в `npm run dev`. На сайте флага нет.
- Стенд: `/lab/banana/` на сервере разработки — модель, анимации, правила, концепты; режим «Заезд» играется (A/D, E).
- В игре: купить лодку у Семёна (с 6-го уровня рыбалки), вызвать на стоянке за домом Семёна, сесть за штурвал,
  B — банан. Второй игрок — по мосткам к банану, E.
- Проверка (разработка): `/banana` в чате — своя «Волжанка», 6-й уровень рыбалки и на сходни стоянки (вызвать к месту 1,
  E у таблички, B); `/banana pier` — на край мостка у места 1, до банана ~5 м (E — сесть).

## Решения

- «Любая лодка» = свои лодки рыбаков (их водит игрок). Регата — гонка на одного, «Ласточка» и «Удалая» ходят сами.
- Садиться может любой, без уровня рыбалки (это не рыбалка). Банан должен стоять (≤ 1,2 м/с), до банана — 6,5 м.
- Время «продержался» идёт, пока банан быстрее 2 м/с; в итоге — лучший отрезок без падения у каждого.
- Без жетонов (иначе накрутка «сидим за медленной лодкой»); награду — только по решению владельца.
- Лодка задним ходом от стоянки толкает банан перед кормой (кранец 0,6 м в `bnStep`), а не проезжает сквозь него.
- Упавшему без тоста: плашка «Плюх! Обратно — ещё N с» и подсказка «E — обратно» уже на экране.

## Где что лежит

- `shared/banana.ts` — числа, трос (`bnStep`: инерция, вода, трос 9 м, берега через `obPushOut`), крен седока
  (`bnRiderStep`: толчок × место + волна + A/D − выпрямление, край 0,4 с — падение), строка в чат, сообщения.
  Баланс подобран симуляцией: внимательный седок (реакция ~0,45 с) на «Волжанке» и «Альбакоре» держится долго,
  на «Нортсильвере» падает изредка; без кнопок падает за 3–4 с «змейки»; медленная реакция (0,8 с) — каждые ~10 с.
- `server/lobby/banana.ts` — сервер (сделал Codex по заданию ведущего): прицеп, места, падения, вода, спасение, итог.
- `client/boat/banana.ts` — сеть, плашка равновесия, подсказки; `bananamodel.ts` — модель, трос, `bananaLook`;
  `bananapose.ts` — позы седока; `bananalab.ts` — стенд.
- Модель — `tools/banana/build_banana.py` → `client/assets/banana/banana.glb` (+ `tools/banana/banana.blend`).

## Что улучшить дальше

- Остров: у причала острова лодки стоят кормой к понтону — банан может лечь вдоль понтона; садятся на банан у стоянки.
- Телефон: на экране нет отдельных кнопок A/D для седока (режим «ride»).
- Награда и рекорд «дольше всех за день» на доске — по решению владельца.
