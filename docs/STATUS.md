# TIREDWOOD — состояние и план (на 05.10.2026, ночь)

Короткая сводка для того, кто начинает новую сессию разработки. Подробности устройства — в `README.md` и
`docs/design.md`, правила работы — в `AGENTS.md` (единственный файл правил; `CLAUDE.md` и `ASTRA.md` — ссылки на него).

## Где что

- Игра называется **TIREDWOOD** (раньше Game Opus). Папка, служба и данные на сервере по-прежнему называются
  `game-opus`. Не переименовывай их: на этих именах держатся выкладка и данные.
- Код игры — свой git-репозиторий в этой папке, на GitHub публичный `qqtired/TIREDWOOD`. Остальное
  (сайт, доска идей, `/tech`) — в приватном `qqtired/tired-solutions` уровнем выше.
- Публичный репозиторий: никаких секретов, адресов серверов, данных игроков, `data/`, `ssh/`, бэкапов.

## Как выкладывать

- Только после «да» владельца. Скрипт — `./deploy.sh`.

  - Не перезапускает сервер, пока кто-то в режиме (`busy` > 0); `FORCE=1` — только по слову владельца.
  - На сервере смоук-тест и откат при ошибке.
- Если меняются схемы профилей или миграции, сначала снимок данных и репетиция на копии. Как это делал Codex —
  в `docs/release-prep/2026-10-03/REPORT-release.md` и `REPORT-TIREDWOOD.md`.
- Перед выкладкой проверь боевую сборку под CSP сайта: `tools/release/csp-proxy.mjs` и `tools/release/csp-check.mjs`.
- После выкладки:
  - `/health`;
  - имя `index-*.js` на сайте совпадает с `dist/`;
