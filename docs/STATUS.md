# TIREDWOOD — состояние и план (на 03.10.2026, вечер)

Короткая сводка для того, кто начинает новую сессию разработки. Подробности устройства — в `README.md` и
`docs/design.md`, правила работы — в `AGENTS.md` (и `ASTRA.md` для внешних помощников).

## Где что

- Игра называется **TIREDWOOD** (раньше Game Opus). Папка, служба и данные на сервере по-прежнему называются
  `game-opus`. Не переименовывай их: на этих именах держатся выкладка и данные.
- Код игры — свой git-репозиторий в этой папке, на GitHub публичный `qqtired/TIREDWOOD`. Остальное
  (сайт, доска идей, `/tech`) — в приватном `qqtired/tired-solutions` уровнем выше.
- Публичный репозиторий: никаких секретов, адресов серверов, данных игроков, `data/`, `ssh/`, бэкапов.

## Перед выкладкой этого релиза

1. **Данные игроков.** Новые поля есть в профилях и сохранении: рюкзак, блесна, эль, залог рулетки, статистика рулетки
   (`fishing.bag/bagSeq/bagTier/lure/aleUntil`, `rouletteEscrow`, `rlSpins/rlStaked/rlWon`); слоты наряда `s r b w n`
   (питомец, удочка, поплавок, окно, значок); рекорды `rcBestLapHarbor`, `rcBestLapHills`, `brBestLapHarbor`, `skBest`,
   `skRuns`, `skMedal`, `skClean`, `skDay`; сохранение регаты (`harbor-v1`). Старые поля читаются, ничего не обнуляется.
   Всё равно: снимок данных, проверка нормализации на копии (AGENTS.md). Откат только кода опасен — старый Store выбросит
   новое.
2. **TURN.** Поднять квоту на одного пользователя с 20 до 512 (`deploy/voice-relay/CAPACITY-VOICE-CAP-REMOVAL.md`): у голоса
   больше нет лимита в шесть человек. Это изменение сервера — только с «да» владельца.
3. **nginx для `/lab/`.** Блок лежит в `deploy/game.nginx.conf`, `deploy.sh` nginx не трогает: поставить вручную. Без блока
   страница откроется без решений владельца.
4. **Ключ владельца лаборатории** создаётся на сервере сам, ссылку печатает `deploy/lab-link.sh`. В репозиторий и чат ссылку не класть.
5. **Устаревший текст** в `deploy/ENVIRONMENT.md`: там ещё «FISH2 — 32 вида» и «`LAB` на сайте не установлен». Поправить отдельно.

## Как выкладывать

- Только после «да» владельца. Скрипт — `./deploy.sh`.
  - Он проверяет типы, тесты и сборку.
  - Не перезапускает сервер, пока кто-то в режиме (`busy` > 0); `FORCE=1` — только по слову владельца.
  - На сервере смоук-тест и откат при ошибке.
- Если меняются схемы профилей или миграции, сначала снимок данных и репетиция на копии. Как это делал Codex —
  в `docs/release-prep/2026-10-03/REPORT-release.md` и `REPORT-TIREDWOOD.md`.
- Перед выкладкой проверь боевую сборку под CSP сайта: `tools/release/csp-proxy.mjs` и `tools/release/csp-check.mjs`.
- После выкладки:
  - `/health`;
  - имя `index-*.js` на сайте совпадает с `dist/`;
  - журнал службы без ошибок;
  - копия исходников в `../backups/`.
