## Производительность и границы

У деталей кассет/катера объединена геометрия по материалам. Каждый зверь — один SkinnedMesh и один материал; все животные суммарно около 30.4k треугольников. Анимации ограничены дистанцией 50 м, показ — 80 м; GLB кешируются, катера освобождают ресурсы при выходе и учитывают завершение загрузки после dispose. Независимый ревьюер перепроверил эти пути.

Наблюдались примерно 1.6–1.9 мс CPU и 4.9–5.6 мс GPU у выбранных кадров верфи/катера на этом компьютере, high, 1280×720; это короткие локальные замеры, не сравнительный бенчмарк и не гарантия FPS на другом железе. Нагрузка на production, прохождение всей полосы компанией, ручной pointer lock, субъективная громкость и мобильное управление не проверялись в этом проходе. На мобильном выполнена только проверка размещения интерфейса.
