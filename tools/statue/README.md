# Статуя у мостков — сборка модели

Фигура для `client/lobby/statue.ts`: голова по фото, тело в форме ММ-14, поза «отдаёт честь».
Скрипты собирают её из `photo.webp` и кладут результат в `client/assets/statue/`:
`statue.bin` (сетки), `head.webp` и `body.webp` (текстуры).

## Пересобрать

```bash
uv run tools/statue/build.py
```

Сборка идёт около двух минут. Для запекания текстур нужен OpenGL (moderngl, на Mac работает).
После неё — `node --test test/statue.test.ts`.

Если поменялось фото, сначала заново найти точки лица (модель MediaPipe скачивается отдельно,
ссылка — в начале скрипта):

```bash
uv run tools/statue/landmarks.py face_landmarker.task
```

## Что где

| Файл | Что делает |
|---|---|
| `photo.webp`, `landmarks.json` | фото и 478 точек лица (MediaPipe) |
| `head.py` | голова: форма по точкам и силуэту, текстура с фото, мягкие нормали для света в игре |
| `body.py` | тело: поле расстояний (SDF) из простых тел, поза, воротник, карманы, погоны |
| `paint.py` | раскраска: пиксельный камуфляж ММ-14, липучки, флаг, шеврон, пуговицы, кисти, берцы |
| `bake.py` | marching cubes → упрощение → развёртка xatlas → запекание текстуры и затенения (AO) |
| `export.py` | формат `statue.bin` (описан в начале файла) |
| `build.py` | всё вместе |

## Договорённости

- Нашивка с фамилией на груди пустая, текста на ней нет.
- glTF не используем: его загрузчик достаёт текстуры через `blob:`, а их запрещает CSP сайта.
- Сетки должны смотреть наружу (тест проверяет знак объёма): вывернутую сетку three.js отсекает,
  и снаружи видна изнанка.
